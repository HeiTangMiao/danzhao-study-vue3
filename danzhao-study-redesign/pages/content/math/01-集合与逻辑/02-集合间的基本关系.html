学习目标

  • 理解子集、真子集、集合相等的概念及符号表示
  • 掌握空集 \\(\varnothing\\) 的性质及其在解题中的重要性
  • 熟记有限集子集个数公式（\\(2^n\\)个子集、\\(2^n-1\\)个真子集、\\(2^n-2\\)个非空真子集）
  • 能判断两个集合间的包含关系

一、子集

如果集合 \\(A\\) 的任意一个元素都是集合 \\(B\\) 的元素，那么称集合 \\(A\\) 为集合 \\(B\\) 的子集。

子集

记作：\\(A \subseteq B\\) 或 \\(B \supseteq A\\)
读作："\\(A\\) 包含于 \\(B\\)" 或 "\\(B\\) 包含 \\(A\\)"

子集的性质

① 任何一个集合是它自身的子集，即 \\(A \subseteq A\\)；

② 传递性：若 \\(A \subseteq B\\)，且 \\(B \subseteq C\\)，则 \\(A \subseteq C\\)。

二、真子集

如果集合 \\(A \subseteq B\\)，但存在元素 \\(x \in B\\) 且 \\(x \notin A\\)，则称集合 \\(A\\) 是集合 \\(B\\) 的真子集。

真子集

记作：\\(A \subsetneq B\\) 或 \\(B \supsetneq A\\)

三、集合相等

如果 \\(A \subseteq B\\) 且 \\(B \subseteq A\\)，则称集合 \\(A\\) 与集合 \\(B\\) 相等。

集合相等

$$A = B \iff A \subseteq B \text{ 且 } B \subseteq A$$

四、空集

不含任何元素的集合叫做空集，记作 \\(\varnothing\\)。

空集的性质：① 空集是任何集合的子集，即 \\(\varnothing \subseteq A\\)；② 空集是任何非空集合的真子集，即若 \\(A \ne \varnothing\\)，则 \\(\varnothing \subsetneq A\\)。

空集是解题的"隐形陷阱"！凡是遇到 "\\(A \subseteq B\\)" 的条件，必须分 \\(A = \varnothing\\) 和 \\(A \ne \varnothing\\) 两种情况讨论。

子集个数公式

若集合 \\(A\\) 含有 \\(n\\) 个元素（\\(n \in \mathbb{N}^*\\)），则：
• 子集总数：\\(2^n\\) 个
• 真子集个数：\\(2^n - 1\\) 个
• 非空真子集个数：\\(2^n - 2\\) 个
• 非空子集个数：\\(2^n - 1\\) 个
记忆方法：每个元素有"取"或"不取"两种选择，\\(n\\) 个元素共有 \\(2 \times 2 \times \cdots \times 2 = 2^n\\) 种组合。

常见集合关系符号

符号含义例子
\\(\subseteq\\)子集（包含于）\\(\{1\} \subseteq \{1,2\}\\)
\\(\subsetneq\\)真子集（真包含于）\\(\{1\} \subsetneq \{1,2\}\\)
\\(\supseteq\\)包含\\(\{1,2\} \supseteq \{1\}\\)
\\(=\\)相等\\(\{1,2\} = \{2,1\}\\)

典型例题

例题1：求集合的子集个数

题目

已知集合 \\(A = \{1, 2, 3, 4\}\\)，求：
（1）集合 \\(A\\) 的子集个数；
（2）集合 \\(A\\) 的真子集个数；
（3）含有元素1的子集个数。

解析

解：
集合 \\(A\\) 有 4 个元素，即 \\(n = 4\\)。
（1）子集总数为 \\(2^4 = 16\\) 个。
（2）真子集个数为 \\(2^4 - 1 = 15\\) 个。
（3）含有元素1的子集，即1一定"取"，其余3个元素各有"取"或"不取"两种选择，共 \\(2^3 = 8\\) 个。

答案

答案：（1）16个；（2）15个；（3）8个。

例题2：判断集合间的包含关系

题目

已知集合 \\(A = \{x \mid x^2 - x = 0\}\\)，\\(B = \{x \mid x^2 + x = 0\}\\)，判断 \\(A\\) 与 \\(B\\) 的关系。

解析

解：
先化简：\\(A\\)：\\(x^2 - x = 0\\) 即 \\(x(x-1)=0\\)，解得 \\(A = \{0, 1\}\\)。
\\(B\\)：\\(x^2 + x = 0\\) 即 \\(x(x+1)=0\\)，解得 \\(B = \{0, -1\}\\)。
\\(A\\) 中元素 1 不在 \\(B\\) 中，\\(B\\) 中元素 \\(-1\\) 不在 \\(A\\) 中。
因此 \\(A \not\subseteq B\\) 且 \\(B \not\subseteq A\\)，两集合互不包含。

答案

答案：\\(A\\) 与 \\(B\\) 互不包含（无子集关系）。

例题3：列举子集与真子集（基础计算型）

题目

已知集合 \\(A = \{1, 2\}\\)，写出集合 \\(A\\) 的所有子集，并指出其中的真子集和非空真子集。

解析

解：
集合 \\(A\\) 有 2 个元素，子集总数为 \\(2^2 = 4\\) 个。
• 含 0 个元素：\\(\varnothing\\)；
• 含 1 个元素：\\(\{1\}\\)、\\(\{2\}\\)；
• 含 2 个元素：\\(\{1, 2\}\\)。
真子集（去掉本身）：\\(\varnothing\\)、\\(\{1\}\\)、\\(\{2\}\\)；
非空真子集：\\(\{1\}\\)、\\(\{2\}\\)。

答案

答案：子集为 \\(\varnothing\\)、\\(\{1\}\\)、\\(\{2\}\\)、\\(\{1,2\}\\)；真子集为 \\(\varnothing\\)、\\(\{1\}\\)、\\(\{2\}\\)；非空真子集为 \\(\{1\}\\)、\\(\{2\}\\)。

例题4：含空集讨论的子集问题（易错型）

题目

已知集合 \\(A = \{x \mid ax - 1 = 0\}\\)，\\(B = \{1, 2\}\\)，且 \\(A \subseteq B\\)，求实数 \\(a\\) 的所有可能取值。

解析

解：
因为 \\(A \subseteq B\\)，需对 \\(A\\) 是否为空集分类讨论：
情况1：当 \\(A = \varnothing\\) 时，\\(a = 0\\) 使方程 \\(0 = 1\\) 无解，符合题意。
情况2：当 \\(A \ne \varnothing\\) 时，解为 \\(x = \frac{1}{a}\\)，需 \\(\frac{1}{a} \in B\\)，即 \\(a = 1\\) 或 \\(a = \frac{1}{2}\\)。
综上，\\(a = 0\\) 或 \\(a = 1\\) 或 \\(a = \frac{1}{2}\\)。

答案

答案：\\(a = 0\\) 或 \\(a = 1\\) 或 \\(a = \frac{1}{2}\\)。

例题5：区间包含关系求参数（综合应用型）

题目

已知集合 \\(A = \{x \mid -1 \le x \le 3\}\\)，\\(B = \{x \mid m - 2 \le x \le m + 2\}\\)，若 \\(B \subseteq A\\)，求实数 \\(m\\) 的取值范围。

解析

解：
要使 \\(B \subseteq A\\)，即区间 \\([m-2, m+2]\\) 完全包含在 \\([-1, 3]\\) 内：
$$\begin{cases} m - 2 \ge -1 \\ m + 2 \le 3 \end{cases}$$
由第一个不等式解得 \\(m \ge 1\\)，由第二个解得 \\(m \le 1\\)。
取交集得 \\(m = 1\\)。
验证：当 \\(m = 1\\) 时，\\(B = [-1, 3] = A\\)，满足 \\(B \subseteq A\\)。

答案

答案：\\(m = 1\\)。

练习题

1
基础
已知集合 \\(A = \{a, b\}\\)，则集合 \\(A\\) 的非空真子集个数为（　） A. 1　　B. 2　　C. 3　　D. 4

答案：B。\\(n=2\\)，非空真子集个数为 \\(2^2-2 = 2\\) 个，分别是 \\(\{a\}\\) 和 \\(\{b\}\\)。

2
中等
已知集合 \\(M = \{0, 1\}\\)，\\(N = \{x \mid x^2 + x = 0\}\\)，则（　） A. \\(M \subsetneq N\\)　　B. \\(N \subsetneq M\\)　　C. \\(M = N\\)　　D. 互不包含

答案：D。\\(N = \{x \mid x(x+1)=0\} = \{0, -1\}\\)，而 \\(M=\{0,1\}\\)，两集合不相等，互不包含。

3
中等
已知集合 \\(A = \{x \mid -1 \le x \le 2\}\\)，\\(B = \{x \mid 0 \le x \le 3\}\\)，则 \\(A\\) 与 \\(B\\) 的关系是______。

答案：\\(A\\) 与 \\(B\\) 互不包含。\\(A\\) 中的 -1 不在 \\(B\\) 中，\\(B\\) 中的 3 不在 \\(A\\) 中。

4
进阶
设集合 \\(A = \{x \mid x^2 - 2x - 3 \le 0\}\\)，\\(B = \{x \mid x \le a\}\\)，若 \\(A \subseteq B\\)，求实数 \\(a\\) 的取值范围。

答案：\\(a \ge 3\\)。由 \\(x^2-2x-3 \le 0\\) 得 \\((x-3)(x+1) \le 0\\)，即 \\(A = [-1, 3]\\)。要使 \\([-1,3] \subseteq (-\infty, a]\\)，需要 \\(a \ge 3\\)。
