学习目标

  • 理解全称量词与全称命题、存在量词与特称命题的概念
  • 能正确判断全称命题与特称命题的真假
  • 掌握命题否定的规则：量词互换、结论否定
  • 能熟练写出全称命题与特称命题的否定

一、全称量词与全称命题

短语"所有的""任意一个""一切""每一个"等在逻辑中通常叫做全称量词，用符号"\\(\forall\\)"表示，读作"任意"。

含有全称量词的命题叫做全称命题，一般形式为：

\\(\forall x \in M\\)，\\(p(x)\\)，表示集合 \\(M\\) 中的每一个元素 \\(x\\) 都满足性质 \\(p(x)\\)。

全称命题为真，需要 \\(M\\) 中所有元素都满足 \\(p(x)\\)；只要找到一个反例，全称命题即为假。

二、存在量词与特称命题

短语"存在一个""至少有一个""有些""有一个"等在逻辑中通常叫做存在量词，用符号"\\(\exists\\)"表示，读作"存在"。

含有存在量词的命题叫做特称命题（存在性命题），一般形式为：

\\(\exists x \in M\\)，\\(p(x)\\)，表示集合 \\(M\\) 中至少存在一个元素 \\(x\\) 满足性质 \\(p(x)\\)。

特称命题为真，只需要找到一个满足条件的元素即可；若 \\(M\\) 中不存在满足条件的元素，则特称命题为假。

未知区块类型：compare

判断全称命题真假用"举反例"，判断特称命题真假用"找实例"。例如"所有质数都是奇数"是假命题（反例：2 是质数但不是奇数）；"存在一个质数是偶数"是真命题（实例：2）。

三、命题的否定

对一个命题进行否定，得到的新命题叫做原命题的否定，记作 \\(\neg p\\)。

含量词的命题的否定遵循两条规则：量词互换（全称变特称、特称变全称），结论否定。

• 全称命题 \\(\forall x \in M, p(x)\\) 的否定是 \\(\exists x \in M, \neg p(x)\\)；

• 特称命题 \\(\exists x \in M, p(x)\\) 的否定是 \\(\forall x \in M, \neg p(x)\\)。

命题否定规则

① \\(\neg\big(\forall x \in M, p(x)\big) \iff \exists x \in M, \neg p(x)\\)（全称命题的否定是特称命题）
② \\(\neg\big(\exists x \in M, p(x)\big) \iff \forall x \in M, \neg p(x)\\)（特称命题的否定是全称命题）
③ 不含量词的命题的否定：只否定结论，如"若 \\(p\\)，则 \\(q\\)"的否定是"若 \\(p\\)，则 \\(\neg q\\)"
命题的"否定"与"否命题"是两个不同的概念：命题的否定只否定结论（含量词时还要换量词），而否命题是条件、结论都否定。例如命题"若 \\(x > 0\\)，则 \\(x^2 > 0\\)"的否定是"若 \\(x > 0\\)，则 \\(x^2 \le 0\\)"，否命题是"若 \\(x \le 0\\)，则 \\(x^2 \le 0\\)"。

四、常见命题的否定形式

写命题的否定时，常需把"都是""至少有一个""至多有一个"等语言转化为规范的逻辑形式：

• "都是"的否定是"不都是"（即"至少有一个不是"），而不是"都不是"；

• "至少有一个"的否定是"一个也没有"（即"都不是"）；

• "至多有一个"的否定是"至少有两个"；

• "且"（\\(\land\\)）的否定是"或"（\\(\lor\\)），"或"（\\(\lor\\)）的否定是"且"（\\(\land\\)）。

常见否定对照

• \\(\neg(p \land q) \iff \neg p \lor \neg q\\)
• \\(\neg(p \lor q) \iff \neg p \land \neg q\\)
• "\\(a\\) 且 \\(b\\)"的否定是"\\(a\\) 或 \\(b\\) 至少有一个不成立"
• "\\(x\\) 与 \\(y\\) 都是正数"的否定是"\\(x\\) 与 \\(y\\) 不都是正数"

典型例题

例题1：判断全称命题与特称命题的真假

题目

判断下列命题的真假：
（1）\\(\forall x \in \mathbb{R}\\)，\\(x^2 \ge 0\\)；
（2）\\(\exists x \in \mathbb{R}\\)，\\(x^2 + 1 = 0\\)；
（3）\\(\forall x \in \mathbb{R}\\)，\\(x^2 > 0\\)。

解析

解：
（1）任意实数的平方都大于等于 0，为真命题。
（2）\\(x^2 + 1 = 0\\) 即 \\(x^2 = -1\\)，在实数范围内无解，不存在这样的 \\(x\\)，为假命题。
（3）当 \\(x = 0\\) 时，\\(x^2 = 0\\) 不满足 \\(x^2 > 0\\)，存在反例，为假命题。

答案

答案：（1）真；（2）假；（3）假。

例题2：写出命题的否定

题目

写出下列命题的否定：
（1）\\(\forall x \in \mathbb{R}\\)，\\(x^2 + x + 1 > 0\\)；
（2）\\(\exists x \in \mathbb{R}\\)，\\(x^2 = 2\\)；
（3）所有的质数都是奇数。

解析

解：
（1）全称命题的否定是特称命题：\\(\exists x \in \mathbb{R}\\)，\\(x^2 + x + 1 \le 0\\)。
（2）特称命题的否定是全称命题：\\(\forall x \in \mathbb{R}\\)，\\(x^2 \ne 2\\)。
（3）"所有的"是全称量词，"都是"的否定是"不都是"：存在一个质数不是奇数，即\\(\exists x\\)（\\(x\\) 为质数），\\(x\\) 不是奇数。

答案

答案：（1）\\(\exists x \in \mathbb{R}\\)，\\(x^2 + x + 1 \le 0\\)；（2）\\(\forall x \in \mathbb{R}\\)，\\(x^2 \ne 2\\)；（3）存在一个质数不是奇数。

例题3：命题否定的综合应用（易错型）

题目

写出命题"\\(\forall x \in \mathbb{R}\\)，\\(x^2 - 2x + 1 \ge 0\\)"的否定，并判断原命题及其否定的真假。

解析

解：
否定：\\(\exists x \in \mathbb{R}\\)，\\(x^2 - 2x + 1 < 0\\)。
原命题：\\(x^2 - 2x + 1 = (x - 1)^2 \ge 0\\) 对任意实数恒成立，为真命题。
否定：因为原命题为真，所以它的否定为假命题（命题与其否定真假相反）。
也可直接判断：\\((x-1)^2 < 0\\) 在实数范围内无解，故否定为假命题。

答案

答案：否定为 \\(\exists x \in \mathbb{R}\\)，\\(x^2 - 2x + 1 < 0\\)；原命题真，其否定假。

练习题

1
基础
判断命题"\\(\forall x \in \mathbb{R}\\)，\\(x^2 + 1 > 0\\)"的真假。

答案：真命题。任意实数的平方加 1 都大于 0，恒成立。

2
基础
命题"\\(\exists x \in \mathbb{R}\\)，\\(x^2 = 4\\)"的否定是______。

答案：\\(\forall x \in \mathbb{R}\\)，\\(x^2 \ne 4\\)。特称命题的否定是全称命题，量词互换、结论否定。

3
中等
写出命题"所有的矩形都是平行四边形"的否定，并判断其真假。

答案：否定为"存在一个矩形不是平行四边形"。因为所有矩形都是平行四边形（真），所以其否定为假命题。

4
进阶
写出命题"\\(\forall x \in \mathbb{R}\\)，\\(x^2 - 4x + 3 \ge 0\\)"的否定，并判断原命题的真假。

答案：否定为 \\(\exists x \in \mathbb{R}\\)，\\(x^2 - 4x + 3 < 0\\)。原命题：\\(x^2 - 4x + 3 = (x-1)(x-3)\\)，当 \\(1 < x < 3\\) 时小于 0，存在反例，故原命题为假命题，其否定为真命题。
