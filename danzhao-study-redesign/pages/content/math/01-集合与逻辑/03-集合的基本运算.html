学习目标

  • 理解并掌握交集、并集、补集的定义和运算
  • 熟记集合运算的运算律（交换律、结合律、分配律、德摩根定律）
  • 能利用数轴求解含不等式集合的交、并、补运算
  • 掌握含参数的集合运算问题的分类讨论方法

一、交集

由属于 \\(A\\) 且属于 \\(B\\) 的所有元素组成的集合，称为 \\(A\\) 与 \\(B\\) 的交集。

交集

$$A \cap B = \{x \mid x \in A \text{ 且 } x \in B\}$$

交集的性质

① \\(A \cap B \subseteq A\\)，\\(A \cap B \subseteq B\\)

② \\(A \cap A = A\\)，\\(A \cap \varnothing = \varnothing\\)

③ 若 \\(A \subseteq B\\)，则 \\(A \cap B = A\\)

二、并集

由属于 \\(A\\) 或属于 \\(B\\) 的所有元素组成的集合，称为 \\(A\\) 与 \\(B\\) 的并集。

并集

$$A \cup B = \{x \mid x \in A \text{ 或 } x \in B\}$$

并集的性质

① \\(A \subseteq A \cup B\\)，\\(B \subseteq A \cup B\\)

② \\(A \cup A = A\\)，\\(A \cup \varnothing = A\\)

③ 若 \\(A \subseteq B\\)，则 \\(A \cup B = B\\)

三、补集

设 \\(U\\) 为全集，\\(A \subseteq U\\)，由 \\(U\\) 中不属于 \\(A\\) 的所有元素组成的集合，称为 \\(A\\) 在全集 \\(U\\) 下的补集。

补集

$$\complement_U A = \{x \mid x \in U \text{ 且 } x \notin A\}$$

补集的性质

① \\(\complement_U U = \varnothing\\)，\\(\complement_U \varnothing = U\\)

② \\(A \cup \complement_U A = U\\)，\\(A \cap \complement_U A = \varnothing\\)

③ \\(\complement_U(\complement_U A) = A\\)

德摩根定律

$$\complement_U(A \cap B) = (\complement_U A) \cup (\complement_U B)$$
$$\complement_U(A \cup B) = (\complement_U A) \cap (\complement_U B)$$
口诀："交的补等于补的并，并的补等于补的交"。

运算律总结

定律交集并集
交换律\\(A \cap B = B \cap A\\)\\(A \cup B = B \cup A\\)
结合律\\((A\cap B)\cap C = A\cap(B\cap C)\\)\\((A\cup B)\cup C = A\cup(B\cup C)\\)
分配律\\(A\cap(B\cup C) = (A\cap B)\cup(A\cap C)\\)\\(A\cup(B\cap C) = (A\cup B)\cap(A\cup C)\\)

典型例题

例题1：求交集、并集、补集

题目

设全集 \\(U = \{1, 2, 3, 4, 5, 6, 7, 8\}\\)，\\(A = \{1, 2, 3, 4\}\\)，\\(B = \{3, 4, 5, 6\}\\)，求 \\(A \cap B\\)、\\(A \cup B\\)、\\(\complement_U A\\)、\\(\complement_U(A \cap B)\\)。

解析

解：
① \\(A \cap B = \{3, 4\}\\)（两集合共有的元素）
② \\(A \cup B = \{1, 2, 3, 4, 5, 6\}\\)（两集合所有元素合并）
③ \\(\complement_U A = \{5, 6, 7, 8\}\\)（全集去掉 \\(A\\) 中的元素）
④ \\(\complement_U(A \cap B) = \complement_U\{3,4\} = \{1, 2, 5, 6, 7, 8\}\\)
验证德摩根定律：\\((\complement_U A)\cup(\complement_U B) = \{5,6,7,8\}\cup\{1,2,7,8\} = \{1,2,5,6,7,8\}\\)，结果一致。

答案

答案：\\(A\cap B=\{3,4\}\\)；\\(A\cup B=\{1,2,3,4,5,6\}\\)；\\(\complement_U A=\{5,6,7,8\}\\)；\\(\complement_U(A\cap B)=\{1,2,5,6,7,8\}\\)。

例题2：含参数的集合运算

题目

设集合 \\(A = \{x \mid -2 \le x \le 5\}\\)，\\(B = \{x \mid m+1 \le x \le 2m-1\}\\)，若 \\(A \cup B = A\\)，求实数 \\(m\\) 的取值范围。

解析

解：
因为 \\(A \cup B = A\\)，所以 \\(B \subseteq A\\)。
情况1：当 \\(B = \varnothing\\) 时，即 \\(m+1 > 2m-1\\)，解得 \\(m < 2\\)。
情况2：当 \\(B \ne \varnothing\\) 时，即 \\(m \ge 2\\)，需要 \\(B \subseteq A\\)：
$$\begin{cases} m+1 \ge -2 \\ 2m-1 \le 5 \end{cases}$$
解得 \\(m \ge -3\\) 且 \\(m \le 3\\)，结合 \\(m \ge 2\\)，得 \\(2 \le m \le 3\\)。
综上，\\(m < 2\\) 或 \\(2 \le m \le 3\\)，即 \\(m \le 3\\)。

答案

答案：\\(m\\) 的取值范围是 \\(m \le 3\\)。

例题3：利用数轴求不等式解集的运算

题目

设全集 \\(U = \mathbb{R}\\)，\\(A = \{x \mid x < 1 \text{ 或 } x > 3\}\\)，\\(B = \{x \mid x \le -1 \text{ 或 } x \ge 2\}\\)，求 \\(A \cap B\\)、\\(\complement_U A\\)、\\((\complement_U A) \cap B\\)。

解析

解：
画数轴辅助分析。
① \\(A \cap B\\)：\\(A\\) 为 \\((-\infty,1)\cup(3,+\infty)\\)，\\(B\\) 为 \\((-\infty,-1]\cup[2,+\infty)\\)。公共部分为 \\((-\infty,-1] \cup (3,+\infty)\\)。
② \\(\complement_U A = \{x \mid 1 \le x \le 3\}\\)。
③ \\((\complement_U A) \cap B = [1,3] \cap \big((-\infty,-1]\cup[2,+\infty)\big) = [2,3]\\)。

答案

答案：\\(A\cap B=\{x\mid x\le -1 \text{ 或 } x>3\}\\)；\\(\complement_U A=\{x\mid 1\le x\le 3\}\\)；\\((\complement_U A)\cap B=[2,3]\\)。

例题4：德摩根定律的验证（基础计算型）

题目

设全集 \\(U = \{1, 2, 3, 4, 5, 6\}\\)，\\(A = \{1, 2, 3, 4\}\\)，\\(B = \{3, 4, 5\}\\)，求 \\(\complement_U(A \cup B)\\) 和 \\((\complement_U A) \cap (\complement_U B)\\)，并验证德摩根定律。

解析

解：
第一步：\\(A \cup B = \{1, 2, 3, 4, 5\}\\)。
第二步：\\(\complement_U(A \cup B) = U \setminus \{1,2,3,4,5\} = \{6\}\\)。
第三步：\\(\complement_U A = \{5, 6\}\\)，\\(\complement_U B = \{1, 2, 6\}\\)，两者交集为 \\(\{6\}\\)。
验证：两结果相等，德摩根定律"并的补等于补的交"成立。

答案

答案：\\(\complement_U(A \cup B) = \{6\}\\)，\\((\complement_U A) \cap (\complement_U B) = \{6\}\\)，两者相等，德摩根定律成立。

例题5：由交集条件求参数（综合应用型）

题目

已知集合 \\(A = \{1, 3, a^2\}\\)，\\(B = \{1, a+2, a-2\}\\)，若 \\(A \cap B = \{1, 4\}\\)，求实数 \\(a\\) 的值。

解析

解：
因为 \\(A \cap B = \{1, 4\}\\)，所以 4 必须同时属于 \\(A\\) 和 \\(B\\)。
第一步：由 \\(4 \in A\\)，\\(a^2 = 4\\)，解得 \\(a = \pm 2\\)。
第二步：逐一验证。
① 当 \\(a = 2\\) 时：\\(A = \{1, 3, 4\}\\)，\\(B = \{1, 4, 0\}\\)，\\(A \cap B = \{1, 4\}\\)，符合；
② 当 \\(a = -2\\) 时：\\(A = \{1, 3, 4\}\\)，\\(B = \{1, 0, -4\}\\)，\\(A \cap B = \{1\}\\)，不符合。
综上，\\(a = 2\\)。

答案

答案：\\(a = 2\\)。

练习题

1
基础
设集合 \\(A = \{1, 2, 3\}\\)，\\(B = \{2, 3, 4\}\\)，则 \\(A \cap B =\\) ______，\\(A \cup B =\\) ______。

答案：\\(A\cap B=\{2,3\}\\)；\\(A\cup B=\{1,2,3,4\}\\)。

2
基础
设全集 \\(U = \{1,2,3,4,5\}\\)，\\(A = \{1,2,3\}\\)，\\(B = \{2,3,4\}\\)，则 \\(\complement_U(A \cup B) =\\) ______。

答案：\\(\{5\}\\)。\\(A\cup B = \{1,2,3,4\}\\)，所以 \\(\complement_U(A\cup B) = \{5\}\\)。

3
中等
已知集合 \\(A = \{x \mid x < a\}\\)，\\(B = \{x \mid 1 \le x \le 3\}\\)，若 \\(A \cap B = \varnothing\\)，求实数 \\(a\\) 的取值范围。

答案：\\(a \le 1\\)。\\(A\cap B = \varnothing\\) 表示 \\((-\infty, a)\\) 与 \\([1,3]\\) 无公共部分，需 \\(a \le 1\\)。

4
中等
已知全集 \\(U = \mathbb{R}\\)，\\(A = \{x \mid x^2-3x+2 < 0\}\\)，\\(B = \{x \mid x \ge 0\}\\)，求 \\(A \cap B\\) 和 \\(\complement_U A\\)。

答案：\\(A = \{x \mid 1 < x < 2\}\\)。\\(A\cap B = \{x \mid 1 < x < 2\}\\)。\\(\complement_U A = \{x \mid x \le 1 \text{ 或 } x \ge 2\}\\)。

5
进阶
设 \\(A = \{x \mid x^2-4x+3 \le 0\}\\)，\\(B = \{x \mid x-a > 0\}\\)，若 \\(A \cap B \ne \varnothing\\)，求实数 \\(a\\) 的取值范围。

答案：\\(a < 3\\)。\\(A=[1,3]\\)，\\(B=(a,+\infty)\\)。\\(A\cap B \ne \varnothing\\) 要求 \\(a < 3\\)。
