学习目标

  • 理解集合的概念，掌握集合的三个特性：确定性、互异性、无序性
  • 掌握元素与集合的关系符号 \\(\in\\)、\\(\notin\\) 的使用
  • 熟记常用数集的符号表示（\\(\mathbb{N}\\)、\\(\mathbb{N}^*\\)、\\(\mathbb{Z}\\)、\\(\mathbb{Q}\\)、\\(\mathbb{R}\\)）
  • 熟练运用列举法、描述法、韦恩图法表示集合

核心概念

集合的概念

把一些能够确定的不同的对象看成一个整体，就说这个整体是由这些对象的全体构成的集合。

集合中的每个对象叫做这个集合的元素。

集合的三个特性

确定性：对于任何一个对象，都能明确判断它是否属于给定集合，即"非此即彼"。

互异性：集合中的元素互不相同，相同元素只写一次。

无序性：集合中的元素没有先后顺序，如 \\(\{1,2,3\}\\) 与 \\(\{3,2,1\}\\) 表示同一集合。

互异性是常考考点！遇到含参数的集合（如 \\(\{a, a^2, 1\}\\)），必须检验元素是否互异。

元素与集合关系

\\(a \in A\\)：元素 \\(a\\) 属于集合 \\(A\\)
\\(a \notin A\\)：元素 \\(a\\) 不属于集合 \\(A\\)
记忆口诀：\\(\mathbb{N}\\) 包含 0，\\(\mathbb{N}^*\\) 不含 0，关系为 \\(\mathbb{N}^* \subsetneq \mathbb{N} \subsetneq \mathbb{Z} \subsetneq \mathbb{Q} \subsetneq \mathbb{R}\\)。

常用数集及符号

符号名称含义
\\(\mathbb{N}\\)非负整数集（自然数集）\\(0, 1, 2, 3, \cdots\\)
\\(\mathbb{N}^*\\) 或 \\(\mathbb{N}^+\\)正整数集\\(1, 2, 3, 4, \cdots\\)
\\(\mathbb{Z}\\)整数集\\(\cdots, -2, -1, 0, 1, 2, \cdots\\)
\\(\mathbb{Q}\\)有理数集所有可以写成 \\(\frac{p}{q}\\)（\\(p,q\in\mathbb{Z}, q\ne 0\\)）的数
\\(\mathbb{R}\\)实数集所有实数

集合的表示方法

三种表示方法

1. 列举法：把集合的元素一一列举出来，写在大括号内。例：\\(A = \{1, 2, 3, 4\}\\)

2. 描述法：用集合所含元素的共同特征表示。一般形式 \\(A = \{x \in I \mid p(x)\}\\)。

3. 韦恩图法（Venn图）：用封闭曲线的内部表示集合，常用于直观展示集合间关系。

描述法中代表元素的形式很重要：\\(\{(x,y) \mid y = x^2\}\\) 表示点集，而 \\(\{y \mid y = x^2\}\\) 表示数集（值域）。

快速检测

1
基础
判断：\\(\{1, 1, 2\}\\) 是一个合法的集合表示。

错误。根据集合的互异性，集合中的元素不能重复。\\(\{1, 1, 2\}\\) 应化简为 \\(\{1, 2\}\\)。

2
基础
判断：\\(0 \in \mathbb{N}^*\\)。

错误。\\(\mathbb{N}^*\\) 表示正整数集 \\(\{1, 2, 3, \cdots\}\\)，不包含 0。而 \\(\mathbb{N}\\)（自然数集）包含 0。

3
中等
判断：集合 \\(\{x \mid x > 2\}\\) 与 \\(\{(x, y) \mid x > 2\}\\) 表示同一集合。

错误。前者代表元素是数（数集），后者代表元素是点（点集）。描述法中代表元素的形式决定了集合的类型。

典型例题

例题1：判断对象能否构成集合

题目

判断下列各组对象能否构成集合，并说明理由。
（1）我校高一年级身高较高的同学；
（2）方程 \\(x^2 - 3x + 2 = 0\\) 的所有实数解；
（3）大于0且小于10的偶数。

解析

解：
（1）不能构成集合。"身高较高"标准不明确，缺乏确定性。
（2）能构成集合。方程 \\(x^2-3x+2=0\\) 的解为 \\(x=1\\) 和 \\(x=2\\)，元素确定且互异。该集合为 \\(\{1, 2\}\\)。
（3）能构成集合。大于0且小于10的偶数为 2, 4, 6, 8，元素确定。该集合为 \\(\{2, 4, 6, 8\}\\)。

答案

答案：（1）不能；（2）能，\\(\{1, 2\}\\)；（3）能，\\(\{2, 4, 6, 8\}\\)。

例题2：用描述法表示集合

题目

用描述法表示下列集合：
（1）所有3的倍数组成的集合；
（2）函数 \\(y = \frac{1}{x}\\) 图像上的所有点组成的集合。

解析

解：
（1）3的倍数即能被3整除的整数，可表示为 \\(x = 3k\\)（\\(k \in \mathbb{Z}\\)）。所以集合为 \\(A = \{x \in \mathbb{Z} \mid x = 3k, k \in \mathbb{Z}\}\\)。
（2）函数图像上的点用有序数对 \\((x, y)\\) 表示，且满足 \\(y = \frac{1}{x}\\)（注意 \\(x \ne 0\\)）。所以集合为 \\(B = \{(x, y) \mid y = \frac{1}{x}, x \ne 0\}\\)。

答案

答案：（1）\\(A = \{x \in \mathbb{Z} \mid x = 3k, k \in \mathbb{Z}\}\\)；（2）\\(B = \{(x, y) \mid y = \frac{1}{x}, x \ne 0\}\\)。

例题3：列举法与元素归属判断（基础计算型）

题目

已知集合 \\(A = \{x \in \mathbb{N} \mid -2 < x \le 4\}\\)。
（1）用列举法表示集合 \\(A\\)；
（2）判断元素 \\(0\\)、\\(-1\\)、\\(\sqrt{3}\\)、\\(4\\) 是否属于集合 \\(A\\)。

解析

解：
（1）集合 \\(A\\) 的代表元素 \\(x\\) 需同时满足：是自然数（\\(x \in \mathbb{N}\\)），且 \\(-2 < x \le 4\\)。在范围内的自然数为 0, 1, 2, 3, 4，所以 \\(A = \{0, 1, 2, 3, 4\}\\)。
（2）逐一判断：\\(0 \in A\\)（满足 \\(-2 < 0 \le 4\\)）；\\(-1 \notin A\\)（不是自然数）；\\(\sqrt{3} \notin A\\)（不是整数）；\\(4 \in A\\)（满足条件）。

答案

答案：（1）\\(A = \{0, 1, 2, 3, 4\}\\)；（2）\\(0 \in A\\)，\\(-1 \notin A\\)，\\(\sqrt{3} \notin A\\)，\\(4 \in A\\)。

例题4：含参数集合的互异性检验（易错型）

题目

已知集合 \\(A = \{1, a, a+1\}\\)，若集合 \\(A\\) 中元素满足互异性，求实数 \\(a\\) 不能取的值。

解析

解：
根据集合元素的互异性，三个元素 1、\\(a\\)、\\(a+1\\) 必须互不相同。
① 若 \\(a = 1\\)，则集合为 \\(\{1, 1, 2\}\\)，元素 1 重复，舍去；
② 若 \\(a + 1 = 1\\)，即 \\(a = 0\\)，则集合为 \\(\{1, 0, 1\}\\)，元素 1 重复，舍去；
③ 若 \\(a = a + 1\\)，无解。
综上，\\(a\\) 不能取 0 和 1。

答案

答案：\\(a\\) 不能取 \\(0\\) 和 \\(1\\)。

例题5：方程解集与集合元素个数（综合应用型）

题目

已知集合 \\(A = \{x \mid ax^2 - 2x + 1 = 0\}\\)。
（1）若 \\(A\\) 中只有一个元素，求实数 \\(a\\) 的值；
（2）若 \\(A\\) 中至多有一个元素，求实数 \\(a\\) 的取值范围。

解析

解：
（1）需对 \\(a\\) 分类讨论：① 当 \\(a = 0\\) 时为一元一次方程 \\(-2x + 1 = 0\\)，\\(x = \frac{1}{2}\\)，符合；② 当 \\(a \ne 0\\) 时，唯一实数解需 \\(\Delta = 4 - 4a = 0\\)，得 \\(a = 1\\)。所以 \\(a = 0\\) 或 \\(a = 1\\)。
（2）"至多一个元素"包括空集和单元素。① \\(a = 0\\) 符合；② \\(a \ne 0\\) 时需 \\(\Delta \le 0\\)，即 \\(a \ge 1\\)。综上 \\(a = 0\\) 或 \\(a \ge 1\\)。

答案

答案：（1）\\(a = 0\\) 或 \\(a = 1\\)；（2）\\(a = 0\\) 或 \\(a \ge 1\\)。

练习题

1
基础
下列各组对象能构成集合的是（　） A. 我校高一的"帅哥" B. 接近于0的数 C. 方程 \\(x^2+1=0\\) 的实数解 D. 比3大的数

答案：C。A中"帅哥"、B中"接近于0"、D中"比3大的数"均表述模糊。C中方程 \\(x^2+1=0\\) 无实数解，构成空集 \\(\varnothing\\)，是合法集合。

2
中等
已知集合 \\(A = \{1, 3, a\}\\)，且 \\(a^2 - 3 \in A\\)，求实数 \\(a\\) 的值。

答案：\\(a = -2\\)。因为 \\(a^2-3 \in A\\)，所以 \\(a^2-3\\) 等于1、3或\\(a\\)。逐一讨论并检验互异性，常见答案为 \\(a=-2\\)。

3
中等
用适当的方法表示"被4除余1的正整数"组成的集合。

答案：用描述法表示为 \\(A = \{x \in \mathbb{N}^* \mid x = 4k+1, k \in \mathbb{N}\}\\)，即 \\(\{1, 5, 9, 13, \cdots\}\\)。

4
进阶
已知集合 \\(M = \{x \mid x = 2k+1, k \in \mathbb{Z}\}\\)，\\(N = \{x \mid x = 4k\pm1, k \in \mathbb{Z}\}\\)，判断集合 \\(M\\) 与 \\(N\\) 的关系。

答案：\\(M = N\\)。\\(M\\) 表示所有奇数。任取奇数 \\(x=2k+1\\)，当 \\(k=2m\\) 时 \\(x=4m+1\\)；当 \\(k=2m+1\\) 时 \\(x=4m+3=4(m+1)-1\\)。故 \\(M \subseteq N\\)，反之亦然，所以 \\(M = N\\)。

一页速记

  • •集合三特性：确定性（非此即彼）、互异性（元素不重复）、无序性（与顺序无关）
  • •元素与集合的关系只有两种：\\(a \in A\\) 或 \\(a \notin A\\)
  • •描述法 \\(A = \{x \in I \mid p(x)\}\\) 中，代表元素的形式决定集合类型：\\(\{x \mid \cdots\}\\) 是数集，\\(\{(x,y) \mid \cdots\}\\) 是点集
  • •三种表示法：列举法（元素少）、描述法（元素有共同特征）、韦恩图法（直观展示关系）
\mathbb{N}^* \subsetneq \mathbb{N} \subsetneq \mathbb{Z} \subsetneq \mathbb{Q} \subsetneq \mathbb{R}
  • !含参数的集合必须检验互异性：如 \\(\{a, a^2, 1\}\\) 要先排除元素重复的 \\(a\\) 值
