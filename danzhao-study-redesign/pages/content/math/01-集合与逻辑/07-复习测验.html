客观题部分

一、选择题（每题 5 分，共 40 分）

1
基础
下列各组对象能构成集合的是（　） A. 我国著名的数学家 B. 2024年浙江省参加单招考试的学生 C. 与3接近的实数 D. 使人心情愉快的音乐

B。"参加考试的学生"是确定的对象，具有确定性。A中"著名"、C中"接近"、D中"心情愉快"均表述模糊。

2
基础
已知集合 \\(A = \{1, 2, 3\}\\)，则集合 \\(A\\) 的非空真子集个数为（　） A. 4　　B. 6　　C. 8　　D. 7

B。\\(n=3\\)，非空真子集个数 \\(= 2^3 - 2 = 6\\) 个。

3
基础
设全集 \\(U = \{1, 2, 3, 4, 5\}\\)，\\(A = \{1, 3, 5\}\\)，\\(B = \{3, 4\}\\)，则 \\(\complement_U(A \cup B) =\\)（　） A. \\(\{2\}\\)　　B. \\(\{1, 2, 5\}\\)　　C. \\(\{2, 5\}\\)　　D. \\(\{1, 2\}\\)

A。\\(A \cup B = \{1,3,4,5\}\\)，\\(\complement_U(A\cup B) = \{2\}\\)。

4
基础
设集合 \\(A = \{x \mid -1 < x < 3\}\\)，\\(B = \{x \mid x \ge 0\}\\)，则 \\(A \cap B =\\)（　） A. \\(\{x \mid 0 \le x < 3\}\\)　　B. \\(\{x \mid x < 3\}\\) C. \\(\{x \mid x \ge 0\}\\)　　D. \\(\{x \mid -1 < x < 0\}\\)

A。\\(A = (-1,3)\\)，\\(B = [0,+\infty)\\)，\\(A\cap B = [0,3)\\)。

5
基础
设 \\(A = \{x \mid x^2 - 2x - 3 = 0\}\\)，\\(B = \{x \mid x+1=0\}\\)，则 \\(A \cup B =\\)（　） A. \\(\{-1\}\\)　　B. \\(\{3\}\\)　　C. \\(\{-1, 3\}\\)　　D. \\(\{-1, -1, 3\}\\)

C。\\(A = \{3, -1\}\\)（由 \\((x-3)(x+1)=0\\)），\\(B = \{-1\}\\)，\\(A\cup B = \{-1, 3\}\\)。

6
中等
"\\(x = 2\\)" 是 "\\(x^2 - 3x + 2 = 0\\)" 的（　） A. 充分不必要条件　　B. 必要不充分条件 C. 充要条件　　D. 既不充分也不必要条件

A。\\(x=2 \Rightarrow x^2-3x+2=0\\) 成立，但反方向 \\(x^2-3x+2=0\\) 时 \\(x=1\\) 或 \\(x=2\\)，不一定 \\(x=2\\)。

7
中等
已知集合 \\(A = \{a, 2\}\\)，\\(B = \{1, 2, a\}\\)，若 \\(A \subseteq B\\)，则实数 \\(a\\) 的值为（　） A. 1　　B. 0　　C. 1或0　　D. 任意实数

C。当 \\(a=1\\) 时 \\(A=\{1,2\}\subseteq B\\) 满足；当 \\(a=0\ne 1,2\\) 时 \\(0\in B\\) 满足。所以 \\(a=1\\) 或 \\(a=0\\)。

8
中等
设 \\(p: x < 1\\)，\\(q: x < 2\\)，则 \\(p\\) 是 \\(q\\) 的（　） A. 充分不必要条件　　B. 必要不充分条件 C. 充要条件　　D. 既不充分也不必要条件

A。\\(x<1 \Rightarrow x<2\\)（充分），但 \\(x<2\\) 时 \\(x\\) 不一定 \\(<1\\)（如 \\(x=1.5\\)）。集合 \\((-\infty,1) \subsetneq (-\infty,2)\\)，小充分。

二、填空题（每题 5 分，共 20 分）

1
中等
设全集 \\(U = \mathbb{R}\\)，\\(A = \{x \mid x \ge 2\}\\)，则 \\(\complement_U A =\\) ______。

\\(\{x \mid x < 2\}\\)，即 \\((-\infty, 2)\\)。

2
中等
已知集合 \\(A = \{0, 1, 2\}\\)，则含有元素0且不含有元素2的子集有______个。

2个。0固定取，2固定不取，1可取可不取，共 \\(2^1=2\\) 个：\\(\{0\}\\)、\\(\{0,1\}\\)。

3
中等
设集合 \\(A = \{x \mid x^2 - x - 6 < 0\}\\)，则 \\(A =\\) ______。

由 \\(x^2-x-6<0\\) 即 \\((x-3)(x+2)<0\\)，解得 \\(-2 < x < 3\\)，即 \\(A = \{x \mid -2 < x < 3\}\\)。

4
中等
已知 "\\((a+1)(b-1) = 0\\)" 的一个充分不必要条件是 ______（写出一个即可）。

答案不唯一，如 "\\(a = -1\\)" 或 "\\(b = 1\\)"。因为 \\(a=-1 \Rightarrow (a+1)(b-1)=0\\)，但反之不成立。

三、解答题（共 40 分）

第1题（12分）

题目

设全集 \\(U = \mathbb{R}\\)，集合 \\(A = \{x \mid x^2 - 4 \le 0\}\\)，\\(B = \{x \mid x > a\}\\)。
（1）求 \\(A\\) 和 \\(\complement_U A\\)；
（2）若 \\(A \cap B \ne \varnothing\\)，求实数 \\(a\\) 的取值范围。

解析

解：
（1）由 \\(x^2-4 \le 0\\) 得 \\((x-2)(x+2) \le 0\\)，解得 \\(-2 \le x \le 2\\)，所以 \\(A = [-2, 2]\\)。
\\(\complement_U A = (-\infty, -2) \cup (2, +\infty) = \{x \mid x < -2 \text{ 或 } x > 2\}\\)。
（2）\\(A = [-2, 2]\\)，\\(B = (a, +\infty)\\)。\\(A \cap B \ne \varnothing\\) 要求 \\([-2,2]\\) 与 \\((a,+\infty)\\) 有交集，即 \\(a < 2\\)。
所以 \\(a\\) 的取值范围是 \\(a < 2\\)。

答案

（1）\\(A = [-2, 2]\\)，\\(\complement_U A = (-\infty,-2)\cup(2,+\infty)\\)；（2）\\(a < 2\\)。

第2题（13分）

题目

已知集合 \\(A = \{x \mid -2 \le x \le 4\}\\)，\\(B = \{x \mid m-1 \le x \le m+1\}\\)。
（1）若 \\(A \cup B = A\\)，求实数 \\(m\\) 的取值范围；
（2）若 \\(A \cap B = \varnothing\\)，求实数 \\(m\\) 的取值范围。

解析

解：
（1）\\(A \cup B = A\\) 即 \\(B \subseteq A\\)，即 \\([m-1, m+1] \subseteq [-2, 4]\\)。
需要：\\(m-1 \ge -2\\) 且 \\(m+1 \le 4\\)，解得 \\(m \ge -1\\) 且 \\(m \le 3\\)，即 \\(-1 \le m \le 3\\)。
（2）\\(A \cap B = \varnothing\\) 即 \\([m-1,m+1]\\) 与 \\([-2,4]\\) 不相交。
需要 \\(m+1 < -2\\) 或 \\(m-1 > 4\\)，即 \\(m < -3\\) 或 \\(m > 5\\)。
所以 \\(m\\) 的取值范围是 \\(m < -3\\) 或 \\(m > 5\\)。

答案

（1）\\(-1 \le m \le 3\\)；（2）\\(m < -3\\) 或 \\(m > 5\\)。

第3题（15分）

题目

已知 \\(p: x^2 - 3x + 2 \le 0\\)，\\(q: x^2 - (a+1)x + a \le 0\\)。
（1）若 \\(a = 2\\)，判断 \\(p\\) 是 \\(q\\) 的什么条件；
（2）若 \\(p\\) 是 \\(q\\) 的充分不必要条件，求实数 \\(a\\) 的取值范围。

解析

解：
先求集合范围：
\\(p: x^2-3x+2 \le 0\\)，即 \\((x-1)(x-2) \le 0\\)，解得 \\(1 \le x \le 2\\)，对应集合 \\(P = [1, 2]\\)。
\\(q: x^2-(a+1)x+a \le 0\\)，即 \\((x-a)(x-1) \le 0\\)。
（1）当 \\(a=2\\) 时，\\((x-2)(x-1) \le 0\\)，解得 \\(1 \le x \le 2\\)。此时 \\(P = Q = [1,2]\\)，所以 \\(p\\) 是 \\(q\\) 的充要条件。
（2）\\(p\\) 是 \\(q\\) 的充分不必要条件，即 \\(P \subsetneq Q\\)。
当 \\(a > 1\\) 时，\\(Q = [1, a]\\)，需 \\([1,2] \subsetneq [1,a]\\)，即 \\(a > 2\\)。
当 \\(a < 1\\) 或 \\(a = 1\\) 时，\\(Q\\) 无法包含 \\(P = [1,2]\\)。
所以 \\(a\\) 的取值范围是 \\(a > 2\\)。

答案

（1）充要条件；（2）\\(a > 2\\)。
