一、侧面积与表面积公式

几何体侧面积表面积
棱柱（直）\\(S_{侧} = Ch\\)（C为底面周长，h为高）\\(S = Ch + 2S_{底}\\)
圆柱\\(S_{侧} = 2\pi rh\\)\\(S = 2\pi r^2 + 2\pi rh\\)
圆锥\\(S_{侧} = \pi rl\\)（l为母线长）\\(S = \pi r^2 + \pi rl\\)
球—\\(S = 4\pi R^2\\)
注意单位统一。面积单位为平方单位（如 cm²），体积单位为立方单位（如 cm³）。

二、体积公式

几何体体积公式说明
棱柱\\(V = Sh\\)S为底面积，h为高
圆柱\\(V = \pi r^2 h\\)r为底面半径
棱锥\\(V = \dfrac{1}{3}Sh\\)锥体体积是柱体的三分之一
圆锥\\(V = \dfrac{1}{3}\pi r^2 h\\)—
球\\(V = \dfrac{4}{3}\pi R^3\\)R为球半径

典型例题

例题1：求表面积

题目

已知圆锥的底面半径 \\(r = 3\\)，母线长 \\(l = 5\\)，求该圆锥的侧面积和表面积。

解析

解：

侧面积：\\(S_{侧} = \pi r l = \pi \times 3 \times 5 = 15\pi\\)。

底面积：\\(S_{底} = \pi r^2 = \pi \times 9 = 9\pi\\)。

表面积：\\(S = S_{侧} + S_{底} = 15\pi + 9\pi = 24\pi\\)。

答案

答：侧面积为 \\(15\pi\\)，表面积为 \\(24\pi\\)。

例题2：求体积

题目

已知球的表面积为 \\(16\pi\\)，求该球的体积。

解析

解：由 \\(S = 4\pi R^2 = 16\pi\\)，得 \\(R^2 = 4\\)，即 \\(R = 2\\)。

体积：\\(V = \dfrac{4}{3}\pi R^3 = \dfrac{4}{3}\pi \times 8 = \dfrac{32\pi}{3}\\)。

答案

答：球的体积为 \\(\dfrac{32\pi}{3}\\)。

例题3：组合体计算

题目

一个几何体由一个圆柱和一个圆锥组成（圆锥放在圆柱上方，共底面），圆柱底面半径为 2，高为 4，圆锥高为 3。求该组合体的体积。

解析

解：圆柱底面半径 \\(r = 2\\)，高 \\(h_1 = 4\\)。

圆柱体积：\\(V_1 = \pi r^2 h_1 = \pi \times 4 \times 4 = 16\pi\\)。

圆锥与圆柱共底面，半径 \\(r = 2\\)，高 \\(h_2 = 3\\)。

圆锥体积：\\(V_2 = \dfrac{1}{3}\pi r^2 h_2 = \dfrac{1}{3}\pi \times 4 \times 3 = 4\pi\\)。

组合体体积：\\(V = V_1 + V_2 = 16\pi + 4\pi = 20\pi\\)。

答案

答：组合体体积为 \\(20\pi\\)。

例题4：圆锥母线与高的易错辨析（易错型）

题目

已知圆锥的底面半径 \\(r = 3\\)，高 \\(h = 4\\)，求该圆锥的侧面积。

某同学的解答如下："侧面积 \\(S_{侧} = \pi r h = \pi \times 3 \times 4 = 12\pi\\)。"请判断是否正确。

解析

解：该解答错误。

圆锥侧面积公式为 \\(S_{侧} = \pi r l\\)，其中 \\(l\\) 是母线长，不是高 \\(h\\)。

母线 \\(l\\)、底面半径 \\(r\\)、高 \\(h\\) 之间的关系为：\\(l^2 = r^2 + h^2\\)。

正确解法：

由 \\(l^2 = r^2 + h^2 = 9 + 16 = 25\\)，得母线 \\(l = 5\\)。

侧面积：\\(S_{侧} = \pi r l = \pi \times 3 \times 5 = 15\pi\\)。

而错误解法中用高 \\(h = 4\\) 代替了母线 \\(l = 5\\)，导致结果偏小。

易错提醒：圆锥的侧面积公式 \\(S_{侧} = \pi r l\\) 中的 \\(l\\) 是母线长（从顶点到底面圆周上一点的距离），不是圆锥的高（从顶点到底面圆心的垂直距离）。两者通过勾股定理 \\(l^2 = r^2 + h^2\\) 联系。务必先由 \\(r\\) 和 \\(h\\) 求出母线 \\(l\\)，再代入侧面积公式。

答案

答：不正确。母线 \\(l = \sqrt{3^2 + 4^2} = 5\\)，正确侧面积为 \\(\pi \times 3 \times 5 = 15\pi\\)。

例题5：球的内接正方体问题（综合应用型）

题目

已知一个球的内接正方体的棱长为 \\(2\\)（正方体的八个顶点都在球面上），求：

（1）该球的半径；

（2）该球的表面积和体积。

解析

解：

（1）当正方体内接于球时，正方体的体对角线等于球的直径。

正方体棱长 \\(a = 2\\)，体对角线长为 \\(\sqrt{a^2 + a^2 + a^2} = \sqrt{3} \times a = 2\sqrt{3}\\)。

所以球的直径 \\(2R = 2\sqrt{3}\\)，半径 \\(R = \sqrt{3}\\)。

（2）球的表面积：

$$S = 4\pi R^2 = 4\pi \times 3 = 12\pi$$

球的体积：

$$V = \frac{4}{3}\pi R^3 = \frac{4}{3}\pi \times 3\sqrt{3} = 4\sqrt{3}\pi$$

分析说明：正方体的体对角线（从一个顶点到空间对角的另一个顶点的连线）长度为 \\(\sqrt{3}a\\)。当正方体内接于球时，体对角线的中点即为球心，体对角线的一半即为球的半径。因此 \\(R = \frac{\sqrt{3}}{2}a = \frac{\sqrt{3}}{2} \times 2 = \sqrt{3}\\)。

答案

答：（1）球的半径 \\(R = \sqrt{3}\\)；（2）表面积为 \\(12\pi\\)，体积为 \\(4\sqrt{3}\pi\\)。

中等
正三棱锥底面边长为 2，高为 \\(\sqrt{3}\\)，求其体积。

解：底面积 \\(S=\dfrac{\sqrt{3}}{4}\times4=\sqrt{3}\\)；体积 \\(V=\dfrac{1}{3}\times\sqrt{3}\times\sqrt{3}=1\\)。

进阶
