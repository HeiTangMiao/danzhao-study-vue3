三、异面直线所成角

已知两条异面直线 \\(a, b\\)，经过空间任一点 \\(O\\)，分别作直线 \\(a', b'\\) 平行于 \\(a, b\\)，则 \\(a'\\) 与 \\(b'\\) 所成的锐角（或直角）叫做异面直线 \\(a\\) 与 \\(b\\) 所成的角。

典型例题

例题1：判断位置关系

题目

在正方体 \\(ABCD\text{-}A_1B_1C_1D_1\\) 中，判断下列各对直线的位置关系：（1）\\(AB\\) 与 \\(CC_1\\)；（2）\\(AB\\) 与 \\(A_1D_1\\)；（3）\\(AB\\) 与 \\(CD\\)。

解析

解：

（1）\\(AB\\) 与 \\(CC_1\\)：不在同一平面内，没有公共点，是异面直线。

（2）\\(AB\\) 与 \\(A_1D_1\\)：不在同一平面内，没有公共点，是异面直线。

（3）\\(AB\\) 与 \\(CD\\)：在同一平面内（底面），没有公共点，是平行直线。

答案

答：（1）异面；（2）异面；（3）平行。

例题2：求异面直线所成角

题目

在正方体 \\(ABCD\text{-}A_1B_1C_1D_1\\) 中，求异面直线 \\(A_1B\\) 与 \\(AD_1\\) 所成角的大小。

解析

分析：将两条异面直线平移到同一三角形中求角。连接 \\(D_1C\\) 与 \\(BC\\)。

解：在正方体中，\\(A_1D_1 \parallel BC\\)，所以 \\(\angle BA_1D_1\\) 不便直接用。改用：

连接 \\(D_1C\\)，因为 \\(AB \parallel D_1C_1\\)（需借助平行）。更简便的方法：

平移 \\(A_1B\\)：取 \\(A_1B\\) 的方向。连接 \\(D_1C\\)，因为 \\(AB \parallel DC\\)，\\(A_1D_1 \parallel BC_1\\)……这里用三角形法：

连接 \\(BC_1\\)，则 \\(BC_1 \parallel AD_1\\)（因为 \\(AB \parallel C_1D_1\\)，\\(AD_1 \parallel BC_1\\)）。

所以 \\(\angle A_1BC_1\\) 就是异面直线 \\(A_1B\\) 与 \\(AD_1\\) 所成的角。

设正方体棱长为 1，则 \\(A_1B = BC_1 = \sqrt{2}\\)，\\(A_1C_1 = \sqrt{2}\\)。

在 \\(\triangle A_1BC_1\\) 中，三边都是 \\(\sqrt{2}\\)，为等边三角形，所以 \\(\angle A_1BC_1 = 60^\circ\\)。

答案

答：异面直线 \\(A_1B\\) 与 \\(AD_1\\) 所成角为 \\(60^\circ\\)。

例题3：确定平面的条件判断（基础计算型）

题目

下列说法是否正确？并说明理由。

（1）空间三点确定一个平面；

（2）一条直线和直线外一点确定一个平面；

（3）两条平行直线确定一个平面。

解析

解：

（1）不完全正确。由公理2，过不在同一直线上的三点有且只有一个平面。若三点共线（在同一直线上），则过这三点有无数个平面，不能确定唯一的平面。因此必须强调"不共线"这一条件。

（2）正确。这是公理2的推论之一。在直线上取两点，加上直线外一点，共三点且不共线，由公理2可确定唯一一个平面。

（3）正确。这也是公理2的推论之一。两条平行直线在同一平面内，且该平面唯一确定。

答案

答：（1）不完全正确（需三点不共线）；（2）正确；（3）正确。

例题4：异面直线判断的易错辨析（易错型）

题目

判断下列命题是否正确，并说明理由：

（1）没有公共点的两条直线一定平行；

（2）分别在两个不同平面内的两条直线一定是异面直线；

（3）两条直线既不相交也不平行，则它们是异面直线。

解析

解：

（1）错误。空间中没有公共点的两条直线可能是平行直线，也可能是异面直线。平行直线在同一平面内且无公共点，而异面直线不在任何同一平面内且无公共点。

（2）错误。分别在两个不同平面内的两条直线可能是相交的、平行的或异面的。例如，两个相交平面的交线同时属于两个平面；又如两个平行平面内方向相同的两条直线是平行的。

（3）正确。空间两条直线的位置关系只有三种：相交、平行、异面。既不相交也不平行，则必然是异面直线。这正是异面直线的定义：不同在任何一个平面内（即既不相交也不平行）的两条直线。

易错提醒：判断异面直线时，不能仅凭"没有公共点"或"在不同平面内"就下结论。"没有公共点"也可能是平行；"在不同平面内"也可能平行或相交。正确的判断方法是：确认两条直线既不相交也不平行，才是异面直线。

答案

答：（1）错误（也可能是异面）；（2）错误（可能相交或平行）；（3）正确。

例题5：正方体中异面直线所成角的综合求解（综合应用型）

题目

在正方体 \\(ABCD\text{-}A_1B_1C_1D_1\\) 中，棱长为 2，求异面直线 \\(BD_1\\) 与 \\(A_1C_1\\) 所成角的余弦值。

解析

分析：求异面直线所成角，需要将两条直线平移到同一顶点处，构造三角形求角。或利用线面垂直关系来证明垂直。

解：

平移 \\(A_1C_1\\)：因为 \\(A_1C_1 \parallel AC\\)（上下底面对应对角线平行），所以将 \\(A_1C_1\\) 平移到 \\(AC\\) 的位置。

现在求 \\(BD_1\\) 与 \\(AC\\) 所成的角。

连接 \\(BD\\)，设 \\(AC\\) 与 \\(BD\\) 交于点 \\(O\\)（底面中心）。

在底面正方形 \\(ABCD\\) 中，对角线 \\(AC \perp BD\\)（正方形对角线互相垂直）。

又因为 \\(DD_1 \perp\\) 平面 \\(ABCD\\)（侧棱垂直于底面），所以 \\(DD_1 \perp AC\\)。

因为 \\(BD \cap DD_1 = D\\)，且 \\(BD \subset\\) 平面 \\(BDD_1\\)，\\(DD_1 \subset\\) 平面 \\(BDD_1\\)，

由线面垂直判定定理：\\(AC \perp\\) 平面 \\(BDD_1\\)。

而 \\(BD_1 \subset\\) 平面 \\(BDD_1\\)，由线面垂直的性质：\\(AC \perp BD_1\\)。

因此 \\(BD_1\\) 与 \\(AC\\) 所成角为 \\(90^\circ\\)，即异面直线 \\(BD_1\\) 与 \\(A_1C_1\\) 所成角为 \\(90^\circ\\)。

余弦值 \\(\cos 90^\circ = 0\\)。

总结：本题利用了"通过线面垂直证明线线垂直"的方法。先证明 \\(AC\\) 垂直于 \\(BD_1\\) 所在的平面 \\(BDD_1\\)（因为 \\(AC \perp BD\\) 且 \\(AC \perp DD_1\\)，两条相交直线），再由线面垂直的性质得出 \\(AC \perp BD_1\\)。这是立体几何中的典型技巧。

答案

答：异面直线 \\(BD_1\\) 与 \\(A_1C_1\\) 所成角为 \\(90^\circ\\)，余弦值为 \\(0\\)。

过不在同一直线上的三点，可以确定几个平面？

中等
异面直线所成角的范围是什么？

解：大于 0° 且小于等于 90°，即 \\(0^\circ < \theta \leq 90^\circ\\)。

直线与平面的位置关系有哪几种？
