一、函数的概念

设 \\(A, B\\) 是非空的数集，如果按照某种确定的对应关系 \\(f\\)，使对于集合 \\(A\\) 中的任意一个数 \\(x\\)，在集合 \\(B\\) 中都有唯一确定的数 \\(f(x)\\) 和它对应，那么就称 \\(f: A \to B\\) 为从集合 \\(A\\) 到集合 \\(B\\) 的一个函数。

记作：\\(y = f(x)\\)，\\(x \in A\\)。

函数三要素

两个函数相同当且仅当定义域和对应法则都相同（值域随之确定）。

三、定义域的求法

求函数定义域时，需要考虑以下限制条件：

① 分式的分母不为零：\\(\frac{1}{f(x)}\\) 要求 \\(f(x) \ne 0\\)

② 偶次根号下非负：\\(\sqrt[2n]{f(x)}\\) 要求 \\(f(x) \ge 0\\)

③ 对数的真数为正：\\(\log_a f(x)\\) 要求 \\(f(x) > 0\\)（且 \\(a > 0, a \ne 1\\)）

④ 零次幂的底数不为零：\\(f(x)^0\\) 要求 \\(f(x) \ne 0\\)

⑤ 实际问题要符合实际意义

多个条件同时存在时，取各条件的交集作为定义域。

四、单调性

判断单调性的方法（定义法）：

① 取值：任取 \\(x_1, x_2 \in D\\)，且 \\(x_1 < x_2\\)。② 作差：计算 \\(f(x_1) - f(x_2)\\)；

③ 变形：因式分解、通分等；

④ 定号：判断 \\(f(x_1) - f(x_2)\\) 的正负；

⑤ 结论：若 \\(f(x_1) - f(x_2) < 0\\)，则减。

推导过程（作差法的原理）：

由增函数定义，\\(x_1 < x_2\\) 时 \\(f(x_1) < f(x_2)\\)，即 \\(f(x_1) - f(x_2) > 0\\)。因此判断 \\(f(x_1) - f(x_2)\\) 的符号等价于比较两个函数值的大小，这正是"作差比较法"的理论依据。

关键在于因式分解：以 \\(f(x) = x + \dfrac{1}{x}\\) 为例，作差后提取公因式 \\((x_1 - x_2)\\)：

$$f(x_1) - f(x_2) = \left(x_1 + \frac{1}{x_1}\right) - \left(x_2 + \frac{1}{x_2}\right) = (x_1 - x_2) + \frac{x_2 - x_1}{x_1 x_2} = (x_1 - x_2)\left(1 - \frac{1}{x_1 x_2}\right)$$

由 \\(x_1 < x_2\\) 知 \\(x_1 - x_2 < 0\\) 已确定符号，只需再判定第二个因子 \\(\left(1 - \dfrac{1}{x_1 x_2}\right)\\) 的符号即可"定号"，从而化繁为简得出 \\(f(x_1) - f(x_2)\\) 的正负。

五、奇偶性

推导过程：

① 为何定义域必须关于原点对称？奇偶性要求对定义域内每个 \\(x\\)，\\(-x\\) 也在定义域内（否则 \\(f(-x)\\) 无意义）。即若 \\(x \in D\\) 则 \\(-x \in D\\)，这正是"定义域关于原点对称"的含义，是判断奇偶性的前提。

② 奇偶性的代数本质：偶函数 \\(f(-x) = f(x)\\)，把 \\(x\\) 换成 \\(-x\\) 函数值不变，对应图像关于 \\(y\\) 轴对称；奇函数 \\(f(-x) = -f(x)\\)，点 \\((x, f(x))\\) 与 \\((-x, -f(x))\\) 成对出现，这两点关于原点对称，故图像关于原点对称。

③ 判定的三种结果：计算 \\(f(-x)\\) 后与 \\(f(x)\\)、\\(-f(x)\\) 比较，有三种情况。以常见幂函数为例：

$$f(x) = x^2 \Rightarrow f(-x) = (-x)^2 = x^2 = f(x) \quad \Rightarrow \text{偶函数}$$

$$f(x) = x^3 \Rightarrow f(-x) = (-x)^3 = -x^3 = -f(x) \quad \Rightarrow \text{奇函数}$$

而 \\(f(x) = x^2 + x\\)，\\(f(-x) = x^2 - x\\)，既不等于 \\(f(x)\\) 也不等于 \\(-f(x)\\)，故非奇非偶。

奇函数

判断奇偶性步骤：① 先看定义域是否关于原点对称；② 再计算 \\(f(-x)\\) 并与 \\(f(x)\\) 和 \\(-f(x)\\) 比较。
判断奇偶性的前提是定义域关于原点对称！如果定义域不关于原点对称，则函数既不是奇函数也不是偶函数。

六、分段函数

在定义域的不同部分，有不同的对应法则的函数称为分段函数。

例：\\(f(x) = \begin{cases} x+1, & x \ge 0 \\ -x, & x < 0 \end{cases}\\) 分段函数是一个函数，不是几个函数。求值时需根据自变量的范围选择对应的解析式。

典型例题

例题1：求函数的定义域

题目

求函数 \\(f(x) = \frac{\sqrt{x+2}}{x-1} + \ln(3-x)\\) 的定义域。

解析

解：

需要满足以下条件：

① 偶次根号下非负：\\(x + 2 \ge 0 \Rightarrow x \ge -2\\)

② 分母不为零：\\(x - 1 \ne 0 \Rightarrow x \ne 1\\)

③ 对数真数为正：\\(3 - x > 0 \Rightarrow x < 3\\)。取三个条件的交集：

$$\begin{cases} x \ge -2 \\ x \ne 1 \\ x < 3 \end{cases}$$

所以定义域为 \\(\{x \mid -2 \le x < 3 \text{ 且 } x \ne 1\}\\)，即 \\([-2, 1) \cup (1, 3)\\)。

答案

答案：定义域为 \\([-2, 1) \cup (1, 3)\\)。

例题2：判断奇偶性

题目

判断下列函数的奇偶性：

（1）\\(f(x) = x^3 + x\\)；

（2）\\(f(x) = x^4 - 2x^2\\)；

（3）\\(f(x) = x^2 + x\\)。

解析

解：

（1）定义域为 \\(\mathbb{R}\\)，关于原点对称。

\\(f(-x) = (-x)^3 + (-x) = -x^3 - x = -(x^3 + x) = -f(x)\\)。

所以 \\(f(x)\\) 是奇函数。

（2）定义域为 \\(\mathbb{R}\\)，关于原点对称。

\\(f(-x) = (-x)^4 - 2(-x)^2 = x^4 - 2x^2 = f(x)\\)。

所以 \\(f(x)\\) 是偶函数。

（3）定义域为 \\(\mathbb{R}\\)，关于原点对称。

\\(f(-x) = (-x)^2 + (-x) = x^2 - x\\)。

\\(f(-x) = x^2 - x \ne f(x) = x^2 + x\\)，且 \\(f(-x) = x^2 - x \ne -f(x) = -x^2 - x\\)。

所以 \\(f(x)\\) 既不是奇函数也不是偶函数。

答案

答案：（1）奇函数；（2）偶函数；（3）非奇非偶。

例题3：证明单调性

题目

用定义法证明函数 \\(f(x) = x + \frac{1}{x}\\) 在 \\((0, 1)\\) 上是减函数。

解析

证明：

任取 \\(x_1, x_2 \in (0, 1)\\)，且 \\(x_1 < x_2\\)。作差：

$$f(x_1) - f(x_2) = \left(x_1 + \frac{1}{x_1}\right) - \left(x_2 + \frac{1}{x_2}\right)$$

$$= (x_1 - x_2) + \left(\frac{1}{x_1} - \frac{1}{x_2}\right) = (x_1 - x_2) + \frac{x_2 - x_1}{x_1 x_2}$$

$$= (x_1 - x_2)\left(1 - \frac{1}{x_1 x_2}\right) = (x_1 - x_2) \cdot \frac{x_1 x_2 - 1}{x_1 x_2}$$

因为 \\(0 < x_1 < x_2 < 1\\)：① \\(x_1 - x_2 < 0\\)（负），② \\(x_1 x_2 > 0\\)（正），且 \\(x_1 x_2 < 1\\)，故 \\(x_1 x_2 - 1 < 0\\)。因此 \\(f(x_1) - f(x_2) = \text{负} \times \text{负} > 0\\)，即 \\(f(x_1) > f(x_2)\\)。

所以 \\(f(x)\\) 在 \\((0, 1)\\) 上是减函数。

答案

答案：证明完毕，\\(f(x)\\) 在 \\((0,1)\\) 上是减函数。

例题4：定义域不对称导致非奇非偶（易错型）

题目

判断函数 \\(f(x) = \frac{x^2(x-1)}{x-1}\\) 的奇偶性。

解析

解：

第一步：确定定义域。分母 \\(x - 1 \ne 0\\)，即定义域为 \\(\{x \mid x \ne 1\}\\)。

第二步：检查定义域是否关于原点对称。

因为 \\(1\\) 不在定义域内，但 \\(-1\\) 在定义域内，所以定义域 \\(\{x \mid x \ne 1\}\\) 不关于原点对称。

因此 \\(f(x)\\) 既不是奇函数也不是偶函数。

易错提醒：本题容易犯的错误是先化简 \\(f(x) = \frac{x^2(x-1)}{x-1} = x^2\\)（当 \\(x \ne 1\\) 时），然后误判 \\(f(-x) = f(x)\\) 为偶函数。实际上化简不改变定义域，定义域仍不含 \\(x = 1\\)，不关于原点对称，因此非奇非偶。判断奇偶性前，必须先检查定义域是否关于原点对称。

答案

答案：既不是奇函数也不是偶函数（定义域不关于原点对称）。

例题5：利用奇偶性求解析式（综合应用型）

题目

已知 \\(f(x)\\) 是定义在 \\(\mathbb{R}\\) 上的奇函数，当 \\(x > 0\\) 时，\\(f(x) = x^2 - 2x\\)。

（1）求 \\(x < 0\\) 时 \\(f(x)\\) 的解析式；（2）求 \\(f(0)\\) 的值。

解析

解：

（1）当 \\(x < 0\\) 时，\\(-x > 0\\)，可利用 \\(x > 0\\) 的解析式计算 \\(f(-x)\\)：

$$f(-x) = (-x)^2 - 2(-x) = x^2 + 2x$$

因为 \\(f(x)\\) 是奇函数，满足 \\(f(-x) = -f(x)\\)，所以：

$$-f(x) = x^2 + 2x \Rightarrow f(x) = -x^2 - 2x$$

所以当 \\(x < 0\\) 时 \\(f(x) = -x^2 - 2x\\)。（2）因为 \\(f(x)\\) 是定义在 \\(\mathbb{R}\\) 上的奇函数，所以 \\(f(0) = 0\\)（奇函数在原点处若有定义，则函数值必为0）。

综上：\\(f(x) = \begin{cases} x^2 - 2x, & x > 0 \\ 0, & x = 0 \\ -x^2 - 2x, & x < 0 \end{cases}\\)

答案

答案：（1）\\(x < 0\\) 时 \\(f(x) = -x^2 - 2x\\)；（2）\\(f(0) = 0\\)。

练习题

1
基础
函数 \\(f(x) = \sqrt{x-1} + \frac{1}{x-2}\\) 的定义域是______。

答案：\\([1, 2) \cup (2, +\infty)\\)。需 \\(x-1 \ge 0\\) 且 \\(x-2 \ne 0\\)，即 \\(x \ge 1\\) 且 \\(x \ne 2\\)。

2
基础
下列函数中，既是奇函数又是增函数的是（　） A. \\(y = x^2\\)　　B. \\(y = -x\\)　　C. \\(y = x^3\\)　　D. \\(y = \frac{1}{x}\\)

答案：C。\\(y=x^2\\) 是偶函数。\\(y=-x\\) 是奇函数但是减函数。\\(y=x^3\\) 是奇函数且在 \\(\mathbb{R}\\) 上单调递增。\\(y=\frac{1}{x}\\) 是奇函数但在 \\((0,+\infty)\\) 上递减。

3
中等
已知 \\(f(x)\\) 是奇函数，\\(f(2) = 5\\)，则 \\(f(-2) =\\) ______。

答案：\\(-5\\)。奇函数 \\(f(-x) = -f(x)\\)，所以 \\(f(-2) = -f(2) = -5\\)。

4
中等
已知函数 \\(f(x) = \begin{cases} x+1, & x \ge 0 \\ x-1, & x < 0 \end{cases}\\)，求 \\(f(2)\\) 和 \\(f(-3)\\)。

答案：\\(f(2) = 2+1 = 3\\)（因为 \\(2 \ge 0\\)，用第一段）；\\(f(-3) = -3-1 = -4\\)（因为 \\(-3 < 0\\)，用第二段）。

5
进阶
已知偶函数 \\(f(x)\\) 在 \\([0, +\infty)\\) 上是增函数，且 \\(f(2) = 1\\)，比较 \\(f(-3)\\) 与 \\(f(2)\\) 的大小。

答案：\\(f(-3) > f(2)\\)。因为 \\(f(x)\\) 是偶函数，\\(f(-3) = f(3)\\)。又因为 \\(f(x)\\) 在 \\([0,+\infty)\\) 上是增函数，且 \\(3 > 2\\)，所以 \\(f(3) > f(2)\\)，即 \\(f(-3) > f(2)\\)。
