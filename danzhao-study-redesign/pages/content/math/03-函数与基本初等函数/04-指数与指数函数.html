一、指数幂的推广

正整数指数幂：\\(a^n = \underbrace{a \cdot a \cdots a}_{n个}\\)（\\(n \in \mathbb{N}^*\\)）

零指数幂：\\(a^0 = 1\\)（\\(a \ne 0\\)）

负整数指数幂：\\(a^{-n} = \frac{1}{a^n}\\)（\\(a \ne 0, n \in \mathbb{N}^*\\)）

分数指数幂

规定 \\(a > 0\\) 是为了保证分数指数幂有意义且运算法则成立。

运算法则（a > 0, b > 0）

注意：\\(a^m + a^n \ne a^{m+n}\\)（加法不能用指数法则）；\\((a+b)^n \ne a^n + b^n\\)（一般情况）。

五、比较大小的方法

同底数比较：利用指数函数的单调性。底数 \\(a > 1\\) 时，指数大的函数值大；\\(0 < a < 1\\) 时，指数大的函数值小。同指数比较：利用幂函数的性质或图像比较。

不同底不同指数：找中间值（如0或1）作桥梁。

典型例题

例题1：指数运算

题目

计算：\\((2^{\frac{1}{2}})^4 \times 8^{\frac{1}{3}} \div 4^{-\frac{1}{2}}\\)。

解析

解：

原式 \\(= 2^{\frac{1}{2} \times 4} \times (2^3)^{\frac{1}{3}} \div (2^2)^{-\frac{1}{2}}\\)

\\(= 2^2 \times 2^1 \div 2^{-1}\\)

\\(= 4 \times 2 \times 2\\)

\\(= 16\\)

逐步解析：

① \\((2^{\frac{1}{2}})^4 = 2^{\frac{1}{2} \times 4} = 2^2 = 4\\)（幂的乘方）

② \\(8^{\frac{1}{3}} = (2^3)^{\frac{1}{3}} = 2^1 = 2\\)（化为同底数）

③ \\(4^{-\frac{1}{2}} = (2^2)^{-\frac{1}{2}} = 2^{-1} = \frac{1}{2}\\)（化为同底数）

④ \\(4 \times 2 \div \frac{1}{2} = 8 \times 2 = 16\\)

答案

答案：16。

例题2：比较大小

题目

比较下列各组数的大小：

（1）\\(2^{0.3}\\) 与 \\(2^{0.5}\\)；

（2）\\(0.3^{-0.2}\\) 与 \\(0.3^{-0.5}\\)；

（3）\\(3^{0.5}\\) 与 \\(0.5^3\\)。

解析

解：

（1）底数 \\(a = 2 > 1\\)，指数函数 \\(y = 2^x\\) 在 \\(\mathbb{R}\\) 上单调递增。

因为 \\(0.3 < 0.5\\)，所以 \\(2^{0.3} < 2^{0.5}\\)。

（2）底数 \\(a = 0.3\\)，\\(0 < 0.3 < 1\\)，指数函数 \\(y = 0.3^x\\) 在 \\(\mathbb{R}\\) 上单调递减。

因为 \\(-0.2 > -0.5\\)，所以 \\(0.3^{-0.2} < 0.3^{-0.5}\\)。

（3）\\(3^{0.5} = \sqrt{3} \approx 1.732 > 1\\)。

\\(0.5^3 = 0.125 < 1\\)，所以 \\(3^{0.5} > 0.5^3\\)（以1为桥梁比较）。

答案

答案：（1）\\(2^{0.3} < 2^{0.5}\\)；（2）\\(0.3^{-0.2} < 0.3^{-0.5}\\)；（3）\\(3^{0.5} > 0.5^3\\)。

例题3：指数函数性质应用

题目

已知函数 \\(f(x) = 2^{x^2 - 2x}\\)，求 \\(f(x)\\) 的最小值。

解析

解：

设 \\(t = x^2 - 2x\\)，则 \\(f(x) = 2^t\\)。

因为底数 \\(a = 2 > 1\\)，\\(y = 2^t\\) 是关于 \\(t\\) 的增函数。

所以 \\(f(x)\\) 的最小值取决于 \\(t = x^2 - 2x\\) 的最小值。

对于 \\(t = x^2 - 2x = (x-1)^2 - 1\\)：

当 \\(x = 1\\) 时，\\(t_{\min} = -1\\)。

所以 \\(f(x)_{\min} = 2^{-1} = \frac{1}{2}\\)。

答案

答案：\\(f(x)\\) 的最小值为 \\(\frac{1}{2}\\)，当 \\(x = 1\\) 时取得。

例题4：指数式的化简与因式分解（易错型）

题目

化简：\\(\frac{a^2 - a^{-2}}{a - a^{-1}}\\)（\\(a > 0, a \ne 1\\)）。

解析

解：

观察分子 \\(a^2 - a^{-2}\\) 的结构，利用平方差公式因式分解：

$$a^2 - a^{-2} = (a)^2 - (a^{-1})^2 = (a - a^{-1})(a + a^{-1})$$

代入原式：

$$\frac{a^2 - a^{-2}}{a - a^{-1}} = \frac{(a - a^{-1})(a + a^{-1})}{a - a^{-1}} = a + a^{-1} = a + \frac{1}{a}$$

易错提醒：不能错误地将分子分母直接"约去" \\(a\\)，误得 \\(a - a^{-1}\\)。必须先对分子进行因式分解，再约去公因式 \\((a - a^{-1})\\)。

答案

答案：\\(a + \frac{1}{a}\\)。

例题5：指数型函数求最值（综合应用型）

题目

求函数 \\(y = 2^x + 2^{-x}\\) 的最小值。

解析

解：

将函数变形：\\(y = 2^x + 2^{-x} = 2^x + \frac{1}{2^x}\\)。

设 \\(t = 2^x\\)，因为对任意实数 \\(x\\) 都有 \\(2^x > 0\\)，所以 \\(t > 0\\)。

原函数化为：\\(y = t + \frac{1}{t}\\)（\\(t > 0\\)）。

由均值不等式（满足"一正"：\\(t > 0\\)，\\(\frac{1}{t} > 0\\)；"二定"：\\(t \cdot \frac{1}{t} = 1\\) 为定值）：

$$y = t + \frac{1}{t} \ge 2\sqrt{t \cdot \frac{1}{t}} = 2\sqrt{1} = 2$$

当且仅当 \\(t = \frac{1}{t}\\)，即 \\(t^2 = 1\\)，\\(t = 1\\)（因 \\(t > 0\\)）时等号成立。

由 \\(t = 2^x = 1\\) 得 \\(x = 0\\)，此时 \\(y = 1 + 1 = 2\\)。

所以函数的最小值为 2，当 \\(x = 0\\) 时取得。

答案

答案：最小值为 2，当 \\(x = 0\\) 时取得。

练习题

1
基础
计算：\\(27^{\frac{2}{3}} - (\frac{1}{2})^{-2} + 16^{\frac{3}{4}}\\)。

答案：21。\\(27^{\frac{2}{3}} = (3^3)^{\frac{2}{3}} = 3^2 = 9\\)；\\((\frac{1}{2})^{-2} = 2^2 = 4\\)；\\(16^{\frac{3}{4}} = (2^4)^{\frac{3}{4}} = 2^3 = 8\\)。原式 \\(= 9 - 4 + 8 = 13\\)。注意：\\((\frac{1}{2})^{-2} = \frac{1}{(\frac{1}{2})^2} = 4\\)。所以 \\(9 - 4 + 8 = 13\\)。

2
基础
函数 \\(y = 3^{x-1}\\) 的图像恒过定点（　） A. \\((0, 0)\\)　　B. \\((0, 1)\\)　　C. \\((1, 1)\\)　　D. \\((1, 3)\\)

答案：C。令指数 \\(x-1 = 0\\)，即 \\(x = 1\\)，此时 \\(y = 3^0 = 1\\)。所以过定点 \\((1, 1)\\)。

3
中等
比较大小：\\(a = 0.7^{1.5}\\)，\\(b = 0.7^{1.8}\\)，则 \\(a\\) ______ \\(b\\)。

答案：\\(>\\)。底数 \\(a = 0.7 \in (0,1)\\)，指数函数递减。因为 \\(1.5 < 1.8\\)，所以 \\(0.7^{1.5} < 0.7^{1.8}\\)，即 \\(a < b\\)。

4
中等
若 \\(2^x = 3\\)，\\(2^y = 5\\)，求 \\(2^{x+y}\\) 的值。

答案：15。\\(2^{x+y} = 2^x \cdot 2^y = 3 \times 5 = 15\\)（同底数幂相乘，指数相加）。

5
进阶
求函数 \\(f(x) = (\frac{1}{3})^{x^2 - 4x + 3}\\) 的单调递增区间。

答案：\\([2, +\infty)\\)。设 \\(t = x^2-4x+3 = (x-2)^2-1\\)，\\(t\\) 在 \\((-\infty, 2]\\) 上递减，在 \\([2,+\infty)\\) 上递增。因底数 \\(\frac{1}{3} \in (0,1)\\)，\\(f = (\frac{1}{3})^t\\) 关于 \\(t\\) 递减。由"同增异减"，\\(f(x)\\) 递增需要 \\(t\\) 递减，即 \\(x \in (-\infty, 2]\\)。但需确认：\\(f\\) 递增区间为 \\(t\\) 的递减区间 \\((-\infty, 2]\\)。所以答案为 \\((-\infty, 2]\\)。
