三、最值问题

闭区间 \\([m, n]\\) 上二次函数最值的求法（\\(a > 0\\)）：

设对称轴 \\(x = -\frac{b}{2a}\\)：

① 若对称轴在区间左侧（\\(-\frac{b}{2a} \le m\\)）：最小值在 \\(x = m\\) 处，最大值在 \\(x = n\\) 处

② 若对称轴在区间内（\\(m < -\frac{b}{2a} < n\\)）：最小值在 \\(x = -\frac{b}{2a}\\) 处。③ 若对称轴在区间右侧（\\(-\frac{b}{2a} \ge n\\)）：最小值在 \\(x = n\\) 处，最大值在 \\(x = m\\) 处

五、"三个二次"的关系

二次函数 \\(y = ax^2+bx+c\\)、一元二次方程 \\(ax^2+bx+c=0\\)、一元二次不等式 \\(ax^2+bx+c > 0\\)（或 \\(ax^2+bx+c < 0\\)）。

• 方程的解 \\(\Leftrightarrow\\) 函数图像与 \\(x\\) 轴交点的横坐标

• 不等式的解集 \\(\Leftrightarrow\\) 函数图像在 \\(x\\) 轴上方（或下方）对应的 \\(x\\) 范围

典型例题

例题1：求二次函数解析式

题目

已知二次函数图像过点 \\((0, 3)\\)，顶点为 \\((1, 2)\\)，求其解析式。

解析

解：

已知顶点为 \\((1, 2)\\)，设顶点式：

$$y = a(x - 1)^2 + 2$$

代入点 \\((0, 3)\\)：

$$3 = a(0-1)^2 + 2 \Rightarrow 3 = a + 2 \Rightarrow a = 1$$

所以解析式为 \\(y = (x-1)^2 + 2 = x^2 - 2x + 3\\)。

验证：\\(a = 1 > 0\\)，开口向上，顶点 \\((1, 2)\\)，\\(y\\) 轴截距 \\(c = 3\\)，符合条件。

答案

答案：\\(y = (x-1)^2 + 2\\)，即 \\(y = x^2 - 2x + 3\\)。

例题2：求闭区间最值

题目

求函数 \\(f(x) = x^2 - 4x + 3\\) 在区间 \\([0, 3]\\) 上的最大值和最小值。

解析

解：

函数 \\(f(x) = x^2 - 4x + 3\\)，\\(a = 1 > 0\\)，开口向上。

对称轴：\\(x = -\frac{-4}{2 \times 1} = 2\\)。

顶点在 \\(x = 2\\) 处，\\(2 \in [0, 3]\\)，所以最小值在顶点处：

$$f(2) = 4 - 8 + 3 = -1$$

最大值在区间端点处，比较 \\(f(0)\\) 和 \\(f(3)\\)：

\\(f(0) = 0 - 0 + 3 = 3\\)

\\(f(3) = 9 - 12 + 3 = 0\\)

因为 \\(f(0) > f(3)\\)，所以最大值在 \\(x = 0\\) 处，最大值为 3。

（也可判断：\\(x=0\\) 离对称轴 \\(x=2\\) 的距离为2，\\(x=3\\) 离对称轴距离为1，距离远的端点函数值更大）

答案

答案：最小值为 \\(-1\\)（在 \\(x=2\\) 处），最大值为 3（在 \\(x=0\\) 处）。

例题3：含参数最值讨论

题目

求函数 \\(f(x) = x^2 - 2ax + 1\\) 在 \\([0, 2]\\) 上的最小值。

解析

解：

\\(f(x) = x^2 - 2ax + 1\\)，\\(a = 1 > 0\\)，开口向上。

对称轴：\\(x = -\frac{-2a}{2} = a\\)。

需分三种情况讨论对称轴与区间 \\([0, 2]\\) 的关系：

情况1：当 \\(a < 0\\)（对称轴在区间左侧）时：

函数在 \\([0, 2]\\) 上单调递增，最小值在 \\(x = 0\\) 处：\\(f(0) = 1\\)。

情况2：当 \\(0 \le a \le 2\\)（对称轴在区间内）时：

最小值在顶点处：\\(f(a) = a^2 - 2a \cdot a + 1 = 1 - a^2\\)。

情况3：当 \\(a > 2\\)（对称轴在区间右侧）时：

函数在 \\([0, 2]\\) 上单调递减，最小值在 \\(x = 2\\) 处：\\(f(2) = 4 - 4a + 1 = 5 - 4a\\)。

答案

答案：最小值 \\(g(a) = \begin{cases} 1, & a < 2\\1 - a^2, & 0 \le a \le 2\\5 - 4a, & a > 2 \end{cases}\\)。

例题4：用零点式求二次函数解析式（基础计算型）

题目

已知二次函数图像与 \\(x\\) 轴交于 \\((-1, 0)\\) 和 \\((3, 0)\\) 两点，且过点 \\((1, 4)\\)，求其解析式。

解析

解：

已知函数图像与 \\(x\\) 轴的两个交点，设零点式（交点式）：

$$y = a(x + 1)(x - 3)$$

代入点 \\((1, 4)\\)：

$$4 = a(1 + 1)(1 - 3) = a \times 2 \times (-2) = -4a$$

解得 \\(a = -1\\)。

所以解析式为 \\(y = -(x+1)(x-3)\\)。

展开为一般式：\\(y = -(x^2 - 2x - 3) = -x^2 + 2x + 3\\)。

验证：\\(a = -1 < 0\\) 开口向下，对称轴 \\(x = 1\\)，顶点 \\((1, 4)\\)，过 \\((-1,0)\\) 和 \\((3,0)\\)，符合条件。

答案

答案：\\(y = -(x+1)(x-3)\\)，即 \\(y = -x^2 + 2x + 3\\)。

例题5：含参数二次函数与不等式（综合应用型）

题目

已知二次函数 \\(f(x) = x^2 - (a-1)x - a\\)（\\(a \in \mathbb{R}\\)）。

（1）若方程 \\(f(x) = 0\\) 的两根之和为 2，求 \\(a\\) 的值；

（2）求不等式 \\(f(x) < 0\\) 的解集。

解析

解：

（1）将 \\(f(x)\\) 因式分解：

$$f(x) = x^2 - (a-1)x - a = (x - a)(x + 1)$$

所以方程 \\(f(x) = 0\\) 的两根为 \\(x_1 = a\\)，\\(x_2 = -1\\)。

由韦达定理，两根之和 \\(x_1 + x_2 = a - 1\\)。

由题意 \\(a - 1 = 2\\)，解得 \\(a = 3\\)。

（2）不等式 \\(f(x) < 0\\)，即 \\((x - a)(x + 1) < 0\\)。

因为二次项系数为 1（开口向上），\\(a\\) 与 \\(-1\\) 需分类讨论：

① 当 \\(a > -1\\) 时，解集为 \\((-1, a)\\)；

② 当 \\(a = -1\\) 时，\\(f(x) = (x+1)^2 \ge 0\\) 恒成立，解集为 \\(\varnothing\\)；

③ 当 \\(a < -1\\) 时，解集为 \\((a, -1)\\)。

答案

答案：（1）\\(a = 3\\)；（2）当 \\(a > -1\\) 时解集为 \\((-1, a)\\)；当 \\(a = -1\\) 时解集为 \\(\varnothing\\)；当 \\(a < -1\\) 时解集为 \\((a, -1)\\)。

练习题

1
基础
二次函数 \\(y = -x^2 + 4x - 1\\) 的顶点坐标是______。

答案：\\((2, 3)\\)。对称轴 \\(x = -\frac{4}{2 \times (-1)} = 2\\)，顶点纵坐标 \\(y = \frac{4 \times (-1) \times (-1) - 16}{4 \times (-1)} = \frac{4-16}{-4} = 3\\)。所以顶点为 \\((2, 3)\\)。

2
基础
已知二次函数 \\(y = ax^2 + bx + c\\) 的图像如图所示（开口向下，对称轴 \\(x=1\\)，过原点），则下列正确的是（　） A. \\(a > 0, b > 0, c = 0\\) B. \\(a < 0, b > 0, c = 0\\) C. \\(a < 0, b < 0, c = 0\\) D. \\(a < 0, b = 0, c = 0\\)

答案：B。开口向下 \\(\Rightarrow a < 0\\)，对称轴 \\(x = -\frac{b}{2a} = 1 \Rightarrow b > 0\\)，过原点 \\(\Rightarrow c = 0\\)。

3
中等
函数 \\(f(x) = x^2 - 2x + 2\\) 在区间 \\([0, 3]\\) 上的值域是______。

答案：\\([1, 5]\\)。对称轴 \\(x = 1 \in [0,3]\\)，最小值 \\(f(1) = 1-2+2 = 1\\)。比较端点：\\(f(0) = 2\\)，\\(f(3) = 9-6+2 = 5\\)。最大值为5。值域 \\([1, 5]\\)。

4
中等
已知二次函数 \\(f(x) = x^2 + bx + c\\) 的对称轴为 \\(x = 1\\)，且过点 \\((2, 3)\\)，求 \\(b\\) 和 \\(c\\)。

答案：\\(b = -2\\)，\\(c = 3\\)。对称轴 \\(x = -\frac{b}{2} = 1 \Rightarrow b = -2\\)。代入点 \\((2,3)\\)：\\(4 + (-2)(2) + c = 3 \Rightarrow 4-4+c=3 \Rightarrow c=3\\)。

5
进阶
若函数 \\(f(x) = x^2 - 2ax + 2\\) 在 \\((-\infty, 1]\\) 上单调递减，求 \\(a\\) 的取值范围。

答案：\\(a \ge 1\\)。开口向上，对称轴 \\(x = a\\)。函数在 \\((-\infty, a]\\) 上递减。要使在 \\((-\infty, 1]\\) 上递减，需要 \\((-\infty, 1] \subseteq (-\infty, a]\\)，即 \\(a \ge 1\\)。
