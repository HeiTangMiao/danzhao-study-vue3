典型例题

例题1：对数运算

题目

计算：\\(\log_2 8 + \log_2 \frac{1}{4} - \log_3 27 + \lg 100\\)。

解析

解：

① \\(\log_2 8 = \log_2 2^3 = 3\\)（因为 \\(2^3 = 8\\)）

② \\(\log_2 \frac{1}{4} = \log_2 2^{-2} = -2\\)（因为 \\(2^{-2} = \frac{1}{4}\\)）

③ \\(\log_3 27 = \log_3 3^3 = 3\\)（因为 \\(3^3 = 27\\)）

④ \\(\lg 100 = \log_{10} 100 = 2\\)（因为 \\(10^2 = 100\\)）

原式 \\(= 3 + (-2) - 3 + 2 = 0\\)

答案

答案：0。

例题2：换底公式应用

题目

已知 \\(\log_{18} 9 = a\\)，\\(18^b = 5\\)，求 \\(\log_{36} 45\\) 的值（用 \\(a, b\\) 表示）。

解析

解：

由 \\(18^b = 5\\) 得 \\(\log_{18} 5 = b\\)。

\\(\log_{36} 45 = \frac{\log_{18} 45}{\log_{18} 36}\\)（换底公式，换成以18为底）

计算 \\(\log_{18} 45\\)：

\\(\log_{18} 45 = \log_{18}(9 \times 5) = \log_{18} 9 + \log_{18} 5 = a + b\\)

计算 \\(\log_{18} 36\\)：

\\(\log_{18} 36 = \log_{18}(18 \times 2) = \log_{18} 18 + \log_{18} 2 = 1 + \log_{18} 2\\)

又 \\(\log_{18} 2 = \log_{18}\frac{18}{9} = \log_{18} 18 - \log_{18} 9 = 1 - a\\)

所以 \\(\log_{18} 36 = 1 + (1 - a) = 2 - a\\)

因此：\\(\log_{36} 45 = \frac{a + b}{2 - a}\\)

答案

答案：\\(\log_{36} 45 = \frac{a+b}{2-a}\\)。

例题3：比较大小

题目

比较下列各组数的大小：

（1）\\(\log_2 3\\) 与 \\(\log_2 5\\)；

（2）\\(\log_{0.5} 3\\) 与 \\(\log_{0.5} 5\\)；

（3）\\(\log_2 3\\) 与 \\(\log_3 2\\)。

解析

解：

（1）底数 \\(a = 2 > 1\\)，对数函数 \\(y = \log_2 x\\) 递增。

因为 \\(3 < 5\\)，所以 \\(\log_2 3 < \log_2 5\\)。

（2）底数 \\(a = 0.5\\)，\\(0 < 0.5 < 1\\)，对数函数 \\(y = \log_{0.5} x\\) 递减。

因为 \\(3 < 5\\)，所以 \\(\log_{0.5} 3 > \log_{0.5} 5\\)。

（3）\\(\log_2 3\\)：底数 \\(2 > 1\\)，真数 \\(3 > 2 = 2^1\\)，所以 \\(\log_2 3 > 1\\)。

\\(\log_3 2\\)：底数 \\(3 > 1\\)，真数 \\(2 < 3 = 3^1\\)，所以 \\(\log_3 2 < 1\\)。

因此 \\(\log_2 3 > \log_3 2\\)（以1为桥梁）。

答案

答案：（1）\\(\log_2 3 < \log_2 5\\)；（2）\\(\log_{0.5} 3 > \log_{0.5} 5\\)；（3）\\(\log_2 3 > \log_3 2\\)。

例题4：对数运算的常见错误辨析（易错型）

题目

判断下列运算是否正确，并说明理由：

（1）\\(\log_2(4 + 4) = \log_2 4 + \log_2 4\\)；

（2）\\((\log_2 3)^2 = \log_2 3^2\\)；

（3）\\(\log_2(-8) = -3\\)。

解析

解：

（1）错误。左边 \\(\log_2(4+4) = \log_2 8 = 3\\)，右边 \\(\log_2 4 + \log_2 4 = 2 + 2 = 4\\)，两边不等。对数运算法则只有 \\(\log_a(M \cdot N) = \log_a M + \log_a N\\)（积的对数等于对数之和），不存在 \\(\log_a(M + N) = \log_a M + \log_a N\\)。

（2）错误。\\((\log_2 3)^2\\) 是 \\(\log_2 3\\) 这个数的平方，而 \\(\log_2 3^2 = 2\log_2 3\\) 是把幂指数提到对数前面。两者含义不同，数值也不同。

（3）错误。对数的真数必须为正数，而 \\(-8 < 0\\)，所以 \\(\log_2(-8)\\) 无意义。不能因为 \\(2^{-3} = \frac{1}{8} \ne -8\\) 就认为 \\(\log_2(-8) = -3\\)。

答案

答案：（1）错误；（2）错误；（3）错误。

例题5：对数型复合函数的定义域与单调性（综合应用型）

题目

已知函数 \\(f(x) = \log_{\frac{1}{2}}(x^2 - 2x - 3)\\)。

（1）求函数的定义域；

（2）求函数的单调递增区间。

解析

解：

（1）对数的真数必须为正：

$$x^2 - 2x - 3 > 0$$

因式分解：\\((x - 3)(x + 1) > 0\\)。

两根为 \\(x = -1\\) 和 \\(x = 3\\)，开口向上，"\\(> 0\\) 取两边"：\\(x < -1\\) 或 \\(x > 3\\)。

所以定义域为 \\((-\infty, -1) \cup (3, +\infty)\\)。

（2）设内层函数 \\(t = x^2 - 2x - 3 = (x - 1)^2 - 4\\)。

\\(t\\) 在 \\((-\infty, 1]\\) 上单调递减，在 \\([1, +\infty)\\) 上单调递增。

外层函数 \\(y = \log_{\frac{1}{2}} t\\)，因为底数 \\(\frac{1}{2} \in (0, 1)\\)，所以 \\(y\\) 关于 \\(t\\) 单调递减。

由复合函数"同增异减"法则，\\(f(x)\\) 递增需要 \\(t\\) 递减，即 \\(x \in (-\infty, 1]\\)。

结合定义域 \\((-\infty, -1) \cup (3, +\infty)\\)，取交集得单调递增区间为 \\((-\infty, -1)\\)。

答案

答案：（1）定义域为 \\((-\infty, -1) \cup (3, +\infty)\\)；（2）单调递增区间为 \\((-\infty, -1)\\)。

练习题

1
基础
计算：\\(\log_5 25 + \log_5 \frac{1}{5} - \log_5 5\\)。

答案：0。\\(\log_5 25 = 2\\)，\\(\log_5 \frac{1}{5} = -1\\)，\\(\log_5 5 = 1\\)。原式 \\(= 2 + (-1) - 1 = 0\\)。

2
基础
函数 \\(y = \log_2(x - 3)\\) 的定义域是______。

答案：\\((3, +\infty)\\)。需要真数 \\(x-3 > 0\\)，即 \\(x > 3\\)。

3
中等
函数 \\(y = \log_a(x+1)\\)（\\(a > 1\\)）的图像恒过定点______。

答案：\\((0, 0)\\)。令 \\(x+1 = 1\\)，即 \\(x = 0\\)，此时 \\(y = \log_a 1 = 0\\)。所以过定点 \\((0, 0)\\)。

4
中等
比较大小：\\(\log_{0.3} 0.7\\) ______ \\(\log_{0.3} 0.5\\)。

答案：\\(>\\)。底数 \\(a = 0.3 \in (0,1)\\)，函数递减。因为 \\(0.7 > 0.5\\)，所以 \\(\log_{0.3} 0.7 < \log_{0.3} 0.5\\)。注意：递减时真数大的对数值反而小。所以 \\(\log_{0.3} 0.7 < \log_{0.3} 0.5\\)。答案应为 \\(<\\)。

5
进阶
若 \\(\lg 2 = a\\)，\\(\lg 3 = b\\)，求 \\(\log_5 12\\) 的值（用 \\(a, b\\) 表示）。

答案：\\(\frac{2a+b}{1-a}\\)。用换底公式：\\(\log_5 12 = \frac{\lg 12}{\lg 5}\\)。\\(\lg 12 = \lg(4 \times 3) = \lg 4 + \lg 3 = 2\lg 2 + \lg 3 = 2a + b\\)。\\(\lg 5 = \lg \frac{10}{2} = \lg 10 - \lg 2 = 1 - a\\)。所以 \\(\log_5 12 = \frac{2a+b}{1-a}\\)。
