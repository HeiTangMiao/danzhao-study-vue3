一、一次函数

图像：一条直线，过点 \\((0, b)\\) 和 \\((-\frac{b}{k}, 0)\\)。

截距 \\(b\\) 的作用：

• \\(b > 0\\)：直线与 \\(y\\) 轴交于正半轴

• \\(b = 0\\)：直线过原点

• \\(b < 0\\)：直线与 \\(y\\) 轴交于负半轴

未知区块类型：diagram

一次函数定义

一、一次函数

条件单调性图像走向
\\(k > 0\\)增函数从左下到右上（上升）
\\(k < 0\\)减函数从左上到右下（下降）

二、反比例函数

图像：双曲线，位于第一、三象限或第二、四象限。

反比例函数的性质：

① 图像关于原点对称，是奇函数（\\(f(-x) = -f(x)\\)）

② 图像无限接近 \\(x\\) 轴和 \\(y\\) 轴，但永不相交

③ \\(|k|\\) 越大，图像离原点越远

未知区块类型：diagram

反比例函数定义

反比例函数在 \\((0,+\infty)\\) 和 \\((-\infty,0)\\) 上分别单调，但不能说在整个定义域上单调！因为 \\(x=0\\) 处函数无定义，图像断开。

二、反比例函数

条件图像所在象限单调性
\\(k > 0\\)第一、三象限在 \\((0,+\infty)\\) 和 \\((-\infty,0)\\) 上分别递减
\\(k < 0\\)第二、四象限在 \\((0,+\infty)\\) 和 \\((-\infty,0)\\) 上分别递增

典型例题

例题1：一次函数性质应用

题目

已知一次函数 \\(y = (2m-1)x + 3 - m\\)。

（1）若 \\(y\\) 随 \\(x\\) 的增大而增大，求 \\(m\\) 的取值范围；

（2）若函数图像过原点，求 \\(m\\) 的值。

解析

解：

（1）\\(y\\) 随 \\(x\\) 增大而增大，即函数为增函数，需要斜率 \\(k > 0\\)：

$$2m - 1 > 0 \Rightarrow m > \frac{1}{2}$$

（2）函数图像过原点 \\((0, 0)\\)，即 \\(x = 0\\) 时 \\(y = 0\\)：

$$3 - m = 0 \Rightarrow m = 3$$

此时函数为 \\(y = 5x\\)，验证：\\(k = 2 \times 3 - 1 = 5 \ne 0\\)，满足条件。

答案

答案：（1）\\(m > \frac{1}{2}\\)；（2）\\(m = 3\\)。

例题2：反比例函数与实际应用

题目

已知反比例函数 \\(y = \frac{k}{x}\\) 的图像过点 \\((2, -3)\\)。

（1）求 \\(k\\) 的值及函数解析式；

（2）判断函数在各象限的单调性；

（3）当 \\(x > 0\\) 时，求 \\(y\\) 的取值范围。

解析

解：

（1）图像过点 \\((2, -3)\\)，代入 \\(y = \frac{k}{x}\\)：

\\(-3 = \frac{k}{2}\\)，所以 \\(k = -6\\)。

函数解析式为 \\(y = \frac{-6}{x}\\)。

（2）因为 \\(k = -6 < 0\\)，所以函数在 \\((0, +\infty)\\) 上是增函数，在 \\((-\infty, 0)\\) 上也是增函数。

（3）当 \\(x > 0\\) 时（第四象限部分），\\(y = \frac{-6}{x} < 0\\)。因为 \\(x > 0\\) 时 \\(y\\) 从 \\(-\infty\\) 递增趋近于 0，所以 \\(y\\) 的取值范围是 \\((-\infty, 0)\\)。

答案

答案：（1）\\(k = -6\\)，\\(y = \frac{-6}{x}\\)；（2）在 \\((0,+\infty)\\) 和 \\((-\infty,0)\\) 上分别递增；（3）\\(y \in (-\infty, 0)\\)。

例题3：待定系数法求一次函数（基础计算型）

题目

已知一次函数 \\(y = kx + b\\) 的图像过点 \\((2, 5)\\) 和 \\((-1, -1)\\)，求 \\(k\\) 和 \\(b\\) 的值，并写出函数解析式。

解析

解：

将两个点的坐标分别代入 \\(y = kx + b\\)，得方程组：

$$\begin{cases} 2k + b = 5 \quad \cdots① \\ -k + b = -1 \quad \cdots② \end{cases}$$

① - ② 得：\\(3k = 6\\)，所以 \\(k = 2\\)。

将 \\(k = 2\\) 代入 ②：\\(-2 + b = -1\\)，得 \\(b = 1\\)。

所以函数解析式为 \\(y = 2x + 1\\)。

验证：当 \\(x = 2\\) 时 \\(y = 5\\) ✓；当 \\(x = -1\\) 时 \\(y = -1\\) ✓。

答案

答案：\\(k = 2\\)，\\(b = 1\\)，解析式为 \\(y = 2x + 1\\)。

例题4：反比例函数单调性的误区（易错型）

题目

判断命题"反比例函数 \\(y = \frac{2}{x}\\) 在定义域上是减函数"是否正确，并说明理由。

解析

解：该命题错误。

反比例函数 \\(y = \frac{2}{x}\\) 的定义域为 \\(\{x \mid x \ne 0\}\\)，图像在 \\(x = 0\\) 处断开。

虽然 \\(k = 2 > 0\\)，函数在 \\((0, +\infty)\\) 上递减，在 \\((-\infty, 0)\\) 上也递减，但不能说在整个定义域上递减。

反例：取 \\(x_1 = -1\\)，\\(x_2 = 1\\)，满足 \\(x_1 < x_2\\)。但 \\(f(-1) = \frac{2}{-1} = -2\\)，\\(f(1) = \frac{2}{1} = 2\\)，即 \\(f(x_1) = -2 < 0 < 2 = f(x_2)\\)。若为减函数应 \\(f(x_1) > f(x_2)\\)，而此处 \\(f(x_1) < f(x_2)\\)。正确说法：\\(y = \frac{2}{x}\\) 在 \\((0, +\infty)\\) 和 \\((-\infty, 0)\\) 上分别单调递减。

答案

答案：错误。函数在 \\((0,+\infty)\\) 和 \\((-\infty,0)\\) 上分别递减，但不能说在整个定义域上递减。

例题5：一次函数与反比例函数的交点（综合应用型）

题目

已知直线 \\(y = 2x + 1\\) 与反比例函数 \\(y = \frac{k}{x}\\) 的图像相交于点 \\((1, m)\\)。

（1）求 \\(k\\) 和 \\(m\\) 的值；

（2）求直线与反比例函数图像的另一个交点坐标。

解析

解：

（1）点 \\((1, m)\\) 在直线 \\(y = 2x + 1\\) 上，代入得：

$$m = 2 \times 1 + 1 = 3$$

点 \\((1, 3)\\) 又在反比例函数 \\(y = \frac{k}{x}\\) 上，代入得：

$$k = 1 \times 3 = 3$$

（2）联立两个函数方程：

$$2x + 1 = \frac{3}{x}$$

两边乘以 \\(x\\)（\\(x \ne 0\\)）：\\(2x^2 + x = 3\\)，即 \\(2x^2 + x - 3 = 0\\)。

因式分解：\\((2x + 3)(x - 1) = 0\\)，解得 \\(x = 1\\) 或 \\(x = -\frac{3}{2}\\)。

\\(x = 1\\) 对应已知交点；当 \\(x = -\frac{3}{2}\\) 时：

$$y = 2 \times \left(-\frac{3}{2}\right) + 1 = -3 + 1 = -2$$

所以另一个交点为 \\(\left(-\frac{3}{2}, -2\right)\\)。

答案

答案：（1）\\(k = 3\\)，\\(m = 3\\)；（2）另一个交点为 \\(\left(-\frac{3}{2}, -2\right)\\)。

练习题

1
基础
一次函数 \\(y = -2x + 5\\) 的图像不经过（　） A. 第一象限　　B. 第二象限　　C. 第三象限　　D. 第四象限

答案：C。\\(k=-2 < 0\\)，\\(b=1 > 0\\)（交 \\(y\\) 轴正半轴，过一象限）。所以过一、二、四象限，不过第三象限。

2
中等
反比例函数 \\(y = \frac{3}{x}\\) 的图像位于______象限。

答案：第一、三象限。因为 \\(k = 3 > 0\\)，图像位于第一、三象限。

3
中等
已知一次函数 \\(y = kx + b\\) 的图像过点 \\((1, 3)\\) 和 \\((-1, -1)\\)，求 \\(k\\) 和 \\(b\\)。

答案：\\(k = 2\\)，\\(b = 1\\)。代入两点：\\(\begin{cases} 3 = k+b \\ -1 = -k+b \end{cases}\\)，两式相加得 \\(2 = 2b\\)，\\(b = 1\\)；代入得 \\(k = 2\\)。

4
进阶
若反比例函数 \\(y = \frac{k}{x}\\) 在 \\((0, +\infty)\\) 上是减函数，则 \\(k\\) 的取值范围是______。

答案：\\(k > 0\\)。反比例函数在 \\((0,+\infty)\\) 上递减，需要 \\(k > 0\\)（此时图像在一、三象限，在第一象限部分递减）。
