学习目标

  • 理解等比数列的定义，掌握等比中项的概念
  • 熟练运用等比数列的通项公式和前 \\(n\\) 项和公式
  • 掌握等比数列的重要性质，能灵活运用解题
  • 注意公式中 \\(q = 1\\) 和 \\(q \neq 1\\) 的分类讨论

一、等比数列的定义

如果一个数列从第二项起，每一项与它的前一项的比等于同一个非零常数，即 \\(\frac{a_n}{a_{n-1}} = q\\)（常数，\\(q \neq 0\\)），则这个数列称为等比数列，常数 \\(q\\) 称为公比。

等比数列中，任何一项都不能为 \\(0\\)，即 \\(a_n \neq 0\\)。公比 \\(q \neq 0\\)。

等比中项

只有 \\(a\\) 和 \\(c\\) 同号时，才有实数等比中项 \\(b = \pm\sqrt{ac}\\)。

三、通项公式

推广形式：\\(a_n = a_m \cdot q^{n-m}\\)（\\(m, n \in \mathbb{N}^*\\)）

四、前n项和公式

推导过程（错位相减法，\\(q \neq 1\\)）：

设 \\(S_n = a_1 + a_1 q + a_1 q^2 + \cdots + a_1 q^{n-1}\\)，即：

$$S_n = a_1(1 + q + q^2 + \cdots + q^{n-1}) \quad \cdots (*)$$

两边同乘公比 \\(q\\)（\\(q \neq 0\\)）：

$$qS_n = a_1(q + q^2 + q^3 + \cdots + q^n) \quad \cdots (**)$$

用 \\((*)\\) 减去 \\((**)\\)，中间项全部抵消，只剩首尾两项：

$$S_n - qS_n = a_1(1 - q^n)$$

即 \\((1 - q)S_n = a_1(1 - q^n)\\)，当 \\(q \neq 1\\) 时两边除以 \\(1 - q\\)：

$$S_n = \frac{a_1(1 - q^n)}{1 - q}$$

将 \\(a_n = a_1 q^{n-1}\\) 即 \\(a_1 q^n = a_n q\\) 代入，得另一形式 \\(S_n = \dfrac{a_1 - a_n q}{1 - q}\\)。

当 \\(q = 1\\) 时，数列各项均为 \\(a_1\\)，故 \\(S_n = na_1\\)（此时公式分母为 0 不适用，需单独讨论）。

关键思想：利用等比数列相邻项之比为常数 \\(q\\)，通过"乘 \\(q\\) 错位相减"使中间项抵消。这是处理"等差×等比"型数列求和的通用技巧。

前n项和公式（需分类讨论）

求和时必须注意 \\(q = 1\\) 和 \\(q \neq 1\\) 的分类讨论！

五、核心性质

• 性质1：若 \\(m + n = p + q\\)（\\(m, n, p, q \in \mathbb{N}^*\\)），则 \\(a_m \cdot a_n = a_p \cdot a_q\\)。特别地，\\(a_1 \cdot a_n = a_2 \cdot a_{n-1} = \cdots\\)

• 性质2：等比数列中，每隔相同项数取出的项仍构成等比数列

• 性质3：\\(S_n, S_{2n} - S_n, S_{3n} - S_{2n}, \ldots\\) 仍构成等比数列（当 \\(q \neq -1\\) 时），公比为 \\(q^n\\)

• 性质4：若等比数列有 \\(2n\\) 项，则奇数项之积与偶数项之积的比为 \\(\frac{1}{q}\\)

典型例题

例题1：求通项

题目

在等比数列 \\(\{a_n\}\\) 中，\\(a_2 = 6\\)，\\(a_5 = 162\\)，求通项公式 \\(a_n\\)。

解析

解：

由 \\(a_2 = a_1 q = 6\\) ... ①

\\(a_5 = a_1 q^4 = 162\\) ... ②

② ÷ ①：\\(q^3 = 27\\)，\\(q = 3\\)

代入①：\\(a_1 \times 3 = 6\\)，\\(a_1 = 2\\)

所以 \\(a_n = 2 \times 3^{n-1}\\)

答案

\\(a_n = 2 \times 3^{n-1}\\)。

例题2：求和

题目

在等比数列 \\(\{a_n\}\\) 中，\\(a_1 = 1\\)，\\(q = 2\\)，求 \\(S_5\\) 和 \\(S_n\\)。

解析

解：

因为 \\(q = 2 \neq 1\\)，用求和公式：

\\(S_5 = \frac{a_1(1 - q^5)}{1 - q} = \frac{1 \times (1 - 32)}{1 - 2} = \frac{-31}{-1} = 31\\)

一般地：\\(S_n = \frac{1 \times (1 - 2^n)}{1 - 2} = \frac{1 - 2^n}{-1} = 2^n - 1\\)

答案

\\(S_5 = 31\\)，\\(S_n = 2^n - 1\\)。

例题3：利用性质

题目

在等比数列 \\(\{a_n\}\\) 中，\\(a_1 \cdot a_5 = 16\\)，\\(a_3 = 4\\)，求 \\(a_1\\) 和 \\(a_5\\) 的值。

解析

解：

由性质：\\(a_1 \cdot a_5 = a_3 \cdot a_3 = a_3^2\\)（因为 \\(1 + 5 = 3 + 3\\)）

所以 \\(a_3^2 = 16\\)，\\(a_3 = \pm 4\\)

但已知 \\(a_3 = 4\\)，符合。

设公比为 \\(q\\)，则 \\(a_1 = \frac{a_3}{q^2} = \frac{4}{q^2}\\)，\\(a_5 = a_3 \cdot q^2 = 4q^2\\)

\\(a_1 \cdot a_5 = \frac{4}{q^2} \times 4q^2 = 16\\) ✓（恒成立）

所以 \\(a_1\\) 和 \\(a_5\\) 的值不唯一，满足 \\(a_1 \cdot a_5 = 16\\) 且 \\(a_1, a_3, a_5\\) 成等比即可。

例如：\\(q = 2\\) 时，\\(a_1 = 1\\)，\\(a_5 = 16\\)；\\(q = -2\\) 时，\\(a_1 = 1\\)，\\(a_5 = 16\\)；\\(q = \frac{1}{2}\\) 时，\\(a_1 = 16\\)，\\(a_5 = 1\\)。

答案

\\(a_1, a_5\\) 满足 \\(a_1 \cdot a_5 = 16\\)，值不唯一（如 \\(a_1 = 1, a_5 = 16\\)）。

例题4：等比数列求和的分类讨论（易错型）

题目

已知等比数列 \\(\{a_n\}\\) 中，\\(a_1 = 3\\)，公比 \\(q\\) 满足 \\(q^2 = 1\\)，求 \\(S_{10}\\)。

解析

解：

由 \\(q^2 = 1\\) 得 \\(q = 1\\) 或 \\(q = -1\\)，需要分类讨论。

情况一：当 \\(q = 1\\) 时，数列各项均为 \\(a_1 = 3\\)（常数列）。

此时求和公式 \\(S_n = \frac{a_1(1-q^n)}{1-q}\\) 的分母为 \\(1 - 1 = 0\\)，不能使用！

应使用 \\(q = 1\\) 时的专用公式：\\(S_{10} = 10 \times a_1 = 10 \times 3 = 30\\)。

情况二：当 \\(q = -1\\) 时，\\(q \ne 1\\)，可以使用求和公式：

$$S_{10} = \frac{a_1(1 - q^{10})}{1 - q} = \frac{3 \times (1 - (-1)^{10})}{1 - (-1)} = \frac{3 \times (1 - 1)}{2} = \frac{3 \times 0}{2} = 0$$

也可以直接理解：\\(q = -1\\) 时数列为 \\(3, -3, 3, -3, \ldots\\)，相邻两项互为相反数，10 项（偶数项）正好两两抵消，和为 0。

易错提醒：等比数列求和时，必须先判断 \\(q\\) 是否等于 1。当 \\(q = 1\\) 时不能用公式 \\(\frac{a_1(1-q^n)}{1-q}\\)（分母为 0 无意义），此时 \\(S_n = na_1\\)。本题 \\(q\\) 有两个可能值，必须分别讨论，不能默认 \\(q = 1\\) 而遗漏 \\(q = -1\\) 的情况。

答案

当 \\(q = 1\\) 时 \\(S_{10} = 30\\)；当 \\(q = -1\\) 时 \\(S_{10} = 0\\)。

例题5：等比数列的实际应用——细胞分裂（综合应用型）

题目

某种细菌每小时分裂一次（每个细菌分裂为 2 个）。若培养皿中初始有 3 个细菌：

（1）经过 8 小时后，有多少个细菌？

（2）从初始时刻到第 8 小时结束时，各时刻的细菌数之和是多少？（即 \\(n = 0\\) 到 \\(n = 8\\) 共 9 个时刻的细菌数累加）

解析

解：

细菌数量构成等比数列 \\(\{a_n\}\\)，其中 \\(a_0 = 3\\)（初始），每小时翻倍即公比 \\(q = 2\\)。

第 \\(n\\) 小时后的细菌数为 \\(a_n = 3 \times 2^n\\)（\\(n = 0, 1, 2, \ldots\\)）。

（1）经过 8 小时：\\(a_8 = 3 \times 2^8 = 3 \times 256 = 768\\)。

所以 8 小时后有 768 个细菌。

（2）从初始到第 8 小时结束，共有 9 个时刻（\\(n = 0\\) 到 \\(n = 8\\)）的细菌数。

总和 \\(= a_0 + a_1 + a_2 + \cdots + a_8 = 3 + 3 \times 2 + 3 \times 2^2 + \cdots + 3 \times 2^8\\)

\\(= 3(1 + 2 + 2^2 + \cdots + 2^8) = 3 \times \frac{1 \times (1 - 2^9)}{1 - 2} = 3 \times \frac{1 - 512}{-1} = 3 \times 511 = 1533\\)。

所以各时刻细菌数之和为 1533。

分析说明：等比数列求和公式 \\(S_n = \frac{a_1(1-q^n)}{1-q}\\) 中，\\(n\\) 是项数。这里括号内 \\(1 + 2 + 2^2 + \cdots + 2^8\\) 共有 9 项（从 \\(2^0\\) 到 \\(2^8\\)），首项 \\(a_1 = 1\\)，公比 \\(q = 2\\)，故代入 \\(n = 9\\)。

答案

（1）\\(768\\) 个细菌；（2）细菌数之和为 \\(1533\\)。

练习题

1
基础
在等比数列 \\(\{a_n\}\\) 中，\\(a_3 = 12\\)，\\(a_5 = 48\\)，求 \\(a_1\\) 和 \\(q\\)。

\\(\frac{a_5}{a_3} = q^2 = 4\\)，\\(q = \pm 2\\)。当 \\(q = 2\\) 时，\\(a_1 = \frac{a_3}{q^2} = \frac{12}{4} = 3\\)；当 \\(q = -2\\) 时，\\(a_1 = 3\\)。所以 \\(a_1 = 3\\)，\\(q = 2\\) 或 \\(q = -2\\)。

2
基础
求等比数列 \\(1, -2, 4, -8, \ldots\\) 的前 \\(6\\) 项和。

\\(a_1 = 1\\)，\\(q = -2\\)。\\(S_6 = \frac{1 \times (1-(-2)^6)}{1-(-2)} = \frac{1-64}{3} = \frac{-63}{3} = -21\\)。

3
中等
在等比数列中，\\(a_2 \cdot a_8 = 36\\)，求 \\(a_5\\)。

由性质 \\(a_2 \cdot a_8 = a_5^2 = 36\\)（因为 \\(2+8 = 5+5\\)），所以 \\(a_5 = \pm 6\\)。

4
中等
已知等比数列 \\(\{a_n\}\\) 的前 \\(n\\) 项和 \\(S_n = 3^n - 1\\)，求 \\(a_n\\)。

\\(a_1 = S_1 = 3 - 1 = 2\\)。当 \\(n \geq 2\\)：\\(a_n = S_n - S_{n-1} = (3^n-1)-(3^{n-1}-1) = 3^n - 3^{n-1} = 3^{n-1}(3-1) = 2 \times 3^{n-1}\\)。验证 \\(n=1\\)：\\(2 \times 3^0 = 2 = a_1\\)。故 \\(a_n = 2 \times 3^{n-1}\\)。

5
进阶
三个数成等比数列，其积为 \\(64\\)，其和为 \\(14\\)，求这三个数。

设三个数为 \\(\frac{a}{q}, a, aq\\)。积：\\(\frac{a}{q} \cdot a \cdot aq = a^3 = 64\\)，\\(a = 4\\)。和：\\(\frac{4}{q} + 4 + 4q = 14\\)，\\(\frac{4}{q} + 4q = 10\\)，\\(4 + 4q^2 = 10q\\)，\\(2q^2 - 5q + 2 = 0\\)，\\(q = 2\\) 或 \\(q = \frac{1}{2}\\)。当 \\(q=2\\) 时，三个数为 \\(2, 4, 8\\)；当 \\(q=\frac{1}{2}\\) 时，三个数为 \\(8, 4, 2\\)。
