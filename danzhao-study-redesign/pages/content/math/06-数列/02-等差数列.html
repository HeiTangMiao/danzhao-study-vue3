学习目标

  • 理解等差数列的定义，掌握等差中项的概念
  • 熟练运用等差数列的通项公式和前 \\(n\\) 项和公式
  • 掌握等差数列的重要性质，能灵活运用解题
  • 能解决等差数列的实际应用问题

一、等差数列的定义

如果一个数列从第二项起，每一项与它的前一项的差等于同一个常数，即 \\(a_n - a_{n-1} = d\\)（常数），则这个数列称为等差数列，常数 \\(d\\) 称为公差。

等差中项

三、通项公式

推广形式：\\(a_n = a_m + (n - m)d\\)（\\(m, n \in \mathbb{N}^*\\)）

四、前n项和公式

推导过程（倒序相加法）：

设 \\(S_n = a_1 + a_2 + \cdots + a_n\\)，由通项公式展开：

$$S_n = a_1 + (a_1 + d) + (a_1 + 2d) + \cdots + [a_1 + (n-1)d] \quad \cdots (*)$$

将各项倒序排列（利用 \\(a_n = a_1 + (n-1)d\\)，\\(a_{n-1} = a_n - d\\) 等）：

$$S_n = a_n + (a_n - d) + (a_n - 2d) + \cdots + [a_n - (n-1)d] \quad \cdots (**)$$

将 \\((*)\\) 与 \\((**)\\) 两式相加，对应项之和恰为 \\(a_1 + a_n\\)：

$$2S_n = \underbrace{(a_1 + a_n) + (a_1 + a_n) + \cdots + (a_1 + a_n)}_{n \text{ 个}} = n(a_1 + a_n)$$

所以 \\(S_n = \dfrac{n(a_1 + a_n)}{2}\\)。再将 \\(a_n = a_1 + (n-1)d\\) 代入，得另一形式：

$$S_n = \frac{n[a_1 + a_1 + (n-1)d]}{2} = na_1 + \frac{n(n-1)}{2}d$$

关键思想：利用等差数列"首末两项等距项之和相等"的性质 \\(a_1 + a_n = a_2 + a_{n-1} = \cdots\\)，通过倒序相加消去公差 \\(d\\)，把 \\(n\\) 个不同项求和转化为 \\(n\\) 个相同项求和。

第一个公式已知 \\(a_1\\)、\\(a_n\\) 时使用；第二个公式已知 \\(a_1\\)、\\(d\\) 时使用。

五、核心性质

• 性质1：若 \\(m + n = p + q\\)（\\(m, n, p, q \in \mathbb{N}^*\\)），则 \\(a_m + a_n = a_p + a_q\\)。特别地，\\(a_1 + a_n = a_2 + a_{n-1} = \cdots\\)

• 性质2：等差数列中，每隔相同项数取出的项仍构成等差数列

• 性质3：\\(S_n, S_{2n} - S_n, S_{3n} - S_{2n}, \ldots\\) 仍构成等差数列，公差为 \\(n^2 d\\)

• 性质4：若等差数列有 \\(2n\\) 项，则 \\(S_{2n} = n(a_1 + a_{2n}) = n(a_n + a_{n+1})\\)；奇数项之和与偶数项之和的差为 \\(nd\\)

六、等差数列的判定方法

• 定义法：\\(a_n - a_{n-1} = d\\)（常数）

• 中项法：\\(2a_{n+1} = a_n + a_{n+2}\\)（\\(n \in \mathbb{N}^*\\)）

• 通项法：\\(a_n = an + b\\)（\\(a, b\\) 为常数，\\(a \neq 0\\)）

• 求和法：\\(S_n = an^2 + bn\\)（\\(a, b\\) 为常数，\\(a \neq 0\\)）

典型例题

例题1：求通项

题目

已知等差数列 \\(\{a_n\}\\) 中，\\(a_3 = 9\\)，\\(a_9 = -3\\)，求通项公式 \\(a_n\\)。

解析

解：

设首项为 \\(a_1\\)，公差为 \\(d\\)。

由 \\(a_3 = a_1 + 2d = 9\\) ... ①

\\(a_9 = a_1 + 8d = -3\\) ... ②

② - ①：\\(6d = -12\\)，\\(d = -2\\)

代入①：\\(a_1 - 4 = 9\\)，\\(a_1 = 13\\)

所以 \\(a_n = 13 + (n-1)(-2) = 13 - 2n + 2 = 15 - 2n\\)

答案

\\(a_n = 15 - 2n\\)。

例题2：求和

题目

在等差数列 \\(\{a_n\}\\) 中，已知 \\(a_1 = 3\\)，\\(d = 2\\)，求 \\(S_{10}\\) 和 \\(S_n\\)。

解析

解：

由通项公式：\\(a_{10} = 3 + 9 \times 2 = 21\\)

\\(S_{10} = 10a_1 + \frac{10 \times 9}{2}d = 10 \times 3 + 45 \times 2 = 30 + 90 = 120\\)

或 \\(S_{10} = \frac{10(a_1 + a_{10})}{2} = \frac{10 \times (3 + 21)}{2} = \frac{240}{2} = 120\\)

一般地：\\(S_n = na_1 + \frac{n(n-1)}{2}d = 3n + \frac{n(n-1)}{2} \times 2 = 3n + n(n-1) = 3n + n^2 - n = n^2 + 2n\\)

答案

\\(S_{10} = 120\\)，\\(S_n = n^2 + 2n\\)。

例题3：利用性质

题目

在等差数列 \\(\{a_n\}\\) 中，\\(S_{10} = 100\\)，\\(S_{20} = 400\\)，求 \\(S_{30}\\)。

解析

解：

由性质3：\\(S_{10}, S_{20} - S_{10}, S_{30} - S_{20}\\) 构成等差数列。

设 \\(S_{10} = A\\)，\\(S_{20} - S_{10} = B\\)，\\(S_{30} - S_{20} = C\\)

\\(A = 100\\)，\\(B = 400 - 100 = 300\\)

因为 \\(A, B, C\\) 成等差数列，所以 \\(2B = A + C\\)，即 \\(C = 2B - A = 600 - 100 = 500\\)

\\(S_{30} = S_{20} + C = 400 + 500 = 900\\)

答案

\\(S_{30} = 900\\)。

例题4：等差数列判定的易错辨析（易错型）

题目

判断下列命题是否正确，并说明理由：

（1）若数列 \\(\{a_n\}\\) 的前 \\(n\\) 项和 \\(S_n = 2n^2 + 3n\\)，则 \\(\{a_n\}\\) 是等差数列；

（2）若数列 \\(\{a_n\}\\) 的前 \\(n\\) 项和 \\(S_n = 2n^2 + 3n + 1\\)，则 \\(\{a_n\}\\) 是等差数列。

解析

解：

（1）正确。

当 \\(n = 1\\) 时：\\(a_1 = S_1 = 2 + 3 = 5\\)。

当 \\(n \geq 2\\) 时：\\(a_n = S_n - S_{n-1} = (2n^2 + 3n) - [2(n-1)^2 + 3(n-1)]\\)

\\(= 2n^2 + 3n - (2n^2 - 4n + 2 + 3n - 3) = 2n^2 + 3n - 2n^2 + 4n - 2 - 3n + 3 = 4n + 1\\)。

验证 \\(n = 1\\)：\\(4 \times 1 + 1 = 5 = a_1\\)，符合。

所以 \\(a_n = 4n + 1\\)，是关于 \\(n\\) 的一次函数（一次项系数不为零），\\(\{a_n\}\\) 是等差数列，公差 \\(d = 4\\)。

（2）错误。

当 \\(n = 1\\) 时：\\(a_1 = S_1 = 2 + 3 + 1 = 6\\)。

当 \\(n \geq 2\\) 时：\\(a_n = S_n - S_{n-1} = (2n^2 + 3n + 1) - [2(n-1)^2 + 3(n-1) + 1]\\)

\\(= 2n^2 + 3n + 1 - 2n^2 + 4n - 2 - 3n + 3 - 1 = 4n + 1\\)。

验证 \\(n = 1\\)：\\(4 \times 1 + 1 = 5 \ne 6 = a_1\\)，不满足！

所以 \\(a_n = \begin{cases} 6, & n = 1 \\ 4n + 1, & n \geq 2 \end{cases}\\)，首项不满足 \\(n \geq 2\\) 的通项公式，\\(\{a_n\}\\) 不是等差数列。

易错提醒：判定数列是否为等差数列时，若 \\(S_n = an^2 + bn + c\\)（\\(a \ne 0\\)），只有当 \\(c = 0\\) 时 \\(\{a_n\}\\) 才是等差数列。\\(c \ne 0\\) 时首项会"断裂"，不构成等差数列。

答案

（1）正确，\\(a_n = 4n + 1\\)，是等差数列；（2）错误，\\(a_1 = 6\\) 不满足 \\(n \geq 2\\) 的通项，\\(\{a_n\}\\) 不是等差数列。

例题5：等差数列的实际应用（综合应用型）

题目

某剧场共有 25 排座位，后一排比前一排多 2 个座位，最后一排有 70 个座位。

（1）第一排有多少个座位？

（2）该剧场共有多少个座位？

解析

解：

将各排座位数按从前到后的顺序排列，构成等差数列 \\(\{a_n\}\\)，其中：

• 排数 \\(n = 25\\)（项数）

• 公差 \\(d = 2\\)（后一排比前一排多 2 个）

• 最后一排 \\(a_{25} = 70\\)

（1）由通项公式 \\(a_n = a_1 + (n-1)d\\)：

$$a_{25} = a_1 + 24 \times 2 = a_1 + 48 = 70$$

解得 \\(a_1 = 70 - 48 = 22\\)。

所以第一排有 22 个座位。

（2）由前 \\(n\\) 项和公式 \\(S_n = \frac{n(a_1 + a_n)}{2}\\)：

$$S_{25} = \frac{25 \times (22 + 70)}{2} = \frac{25 \times 92}{2} = 25 \times 46 = 1150$$

所以该剧场共有 1150 个座位。

验证：用另一公式验证：\\(S_{25} = 25 \times 22 + \frac{25 \times 24}{2} \times 2 = 550 + 600 = 1150\\)，结果一致。

答案

（1）第一排有 \\(22\\) 个座位；（2）剧场共有 \\(1150\\) 个座位。

练习题

1
基础
在等差数列 \\(\{a_n\}\\) 中，\\(a_2 + a_5 = 12\\)，\\(a_4 = 8\\)，求 \\(a_1\\) 和 \\(d\\)。

由性质 \\(a_2 + a_5 = a_1 + d + a_1 + 4d = 2a_1 + 5d = 12\\)，\\(a_4 = a_1 + 3d = 8\\)。解方程组：\\(2a_1 + 5d = 12\\)，\\(a_1 + 3d = 8\\)，得 \\(a_1 = 4\\)，\\(d = \frac{4}{3}\\)... 实际上，更简单：\\(a_2 + a_5 = a_4 + a_3 = 12\\)，\\(a_4 = 8\\)，所以 \\(a_3 = 4\\)，\\(d = a_4 - a_3 = 4\\)，\\(a_1 = a_3 - 2d = 4 - 8 = -4\\)。验证：\\(a_2 = 0\\)，\\(a_5 = 12\\)，\\(a_2+a_5 = 12\\) ✓。\\(a_1 = -4\\)，\\(d = 4\\)。

2
基础
求等差数列 \\(1, 4, 7, 10, \ldots\\) 的前 \\(20\\) 项和。

\\(a_1 = 1\\)，\\(d = 3\\)。\\(S_{20} = 20 \times 1 + \frac{20 \times 19}{2} \times 3 = 20 + 570 = 590\\)。

3
中等
在等差数列中，\\(a_1 + a_4 + a_7 = 15\\)，\\(a_3 + a_6 + a_9 = 21\\)，求 \\(a_5\\)。

由性质：\\(a_1 + a_4 + a_7 = 3a_4 = 15\\)，\\(a_4 = 5\\)；\\(a_3 + a_6 + a_9 = 3a_6 = 21\\)，\\(a_6 = 7\\)。\\(a_5 = \frac{a_4 + a_6}{2} = \frac{5+7}{2} = 6\\)。

4
中等
已知等差数列 \\(\{a_n\}\\) 的前 \\(n\\) 项和 \\(S_n = 2n^2 - n\\)，求 \\(a_n\\)。

\\(a_1 = S_1 = 2 - 1 = 1\\)。当 \\(n \geq 2\\)：\\(a_n = S_n - S_{n-1} = (2n^2-n) - (2(n-1)^2-(n-1)) = 2n^2 - n - 2n^2 + 4n - 2 + n - 1 = 4n - 3\\)。验证 \\(n=1\\)：\\(4(1)-3 = 1 = a_1\\)。故 \\(a_n = 4n - 3\\)。

5
进阶
三个数成等差数列，其和为 \\(12\\)，其积为 \\(48\\)，求这三个数。

设三个数为 \\(a-d, a, a+d\\)。和：\\(3a = 12\\)，\\(a = 4\\)。积：\\((4-d) \times 4 \times (4+d) = 4(16-d^2) = 48\\)，\\(16 - d^2 = 12\\)，\\(d^2 = 4\\)，\\(d = \pm 2\\)。当 \\(d=2\\) 时，三个数为 \\(2, 4, 6\\)；当 \\(d=-2\\) 时，三个数为 \\(6, 4, 2\\)。
