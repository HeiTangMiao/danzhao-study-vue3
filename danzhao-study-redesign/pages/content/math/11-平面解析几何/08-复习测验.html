一、选择题（每题 5 分，共 40 分）

1
基础
过两点 \\(A(1, 1)\\)、\\(B(3, 5)\\) 的直线的斜率为（　） A. \\(1\\)　　B. \\(2\\)　　C. \\(\dfrac{1}{2}\\)　　D. \\(-2\\)

B。\\(k = \dfrac{5 - 1}{3 - 1} = \dfrac{4}{2} = 2\\)。

2
基础
过点 \\((1, 1)\\) 且与直线 \\(y = 3x + 2\\) 平行的直线方程为（　） A. \\(3x - y - 2 = 0\\)　　B. \\(3x - y + 2 = 0\\)　　C. \\(x - 3y - 2 = 0\\)　　D. \\(y = 3x + 1\\)

A。平行则斜率相同 \\(k = 3\\)，点斜式 \\(y - 1 = 3(x - 1)\\)，即 \\(3x - y - 2 = 0\\)。

3
中等
直线 \\(y = x - 1\\) 被椭圆 \\(\dfrac{x^2}{4} + \dfrac{y^2}{2} = 1\\) 截得的弦长为（　） A. \\(\dfrac{4\sqrt{5}}{3}\\)　　B. \\(\dfrac{2\sqrt{5}}{3}\\)　　C. \\(\dfrac{4}{3}\\)　　D. \\(\sqrt{5}\\)

A。代入得 \\(3x^2 - 4x - 2 = 0\\)，韦达定理 \\(x_1 + x_2 = \dfrac{4}{3}\\)，\\(x_1x_2 = -\dfrac{2}{3}\\)。
弦长 \\(= \sqrt{1+k^2}\sqrt{(x_1+x_2)^2 - 4x_1x_2} = \sqrt{2} \times \dfrac{\sqrt{40}}{3} = \dfrac{4\sqrt{5}}{3}\\)。

4
基础
圆 \\((x-1)^2 + (y+2)^2 = 9\\) 的圆心和半径分别是（　） A. \\((1, -2)\\)，\\(r = 3\\)　　B. \\((-1, 2)\\)，\\(r = 3\\)　　C. \\((1, -2)\\)，\\(r = 9\\)　　D. \\((-1, 2)\\)，\\(r = 9\\)

A。由标准方程 \\((x - a)^2 + (y - b)^2 = r^2\\) 直接读出圆心 \\((1, -2)\\)，半径 \\(r = 3\\)。

5
中等
直线 \\(x - y + 1 = 0\\) 与圆 \\(x^2 + y^2 = 2\\) 的位置关系是（　） A. 相离　　B. 相切　　C. 相交　　D. 无法判断

C。圆心 \\((0,0)\\)，半径 \\(r = \sqrt{2}\\)。圆心到直线距离 \\(d = \dfrac{|1|}{\sqrt{2}} = \dfrac{\sqrt{2}}{2} < r\\)，所以直线与圆相交。

6
基础
椭圆 \\(\dfrac{x^2}{25} + \dfrac{y^2}{16} = 1\\) 的焦距为（　） A. \\(4\\)　　B. \\(6\\)　　C. \\(8\\)　　D. \\(9\\)

B。\\(a = 5\\)，\\(b = 4\\)，\\(c = \sqrt{a^2 - b^2} = \sqrt{25 - 16} = 3\\)，焦距 \\(2c = 6\\)。

7
中等
双曲线 \\(\dfrac{x^2}{16} - \dfrac{y^2}{9} = 1\\) 的渐近线方程为（　） A. \\(y = \pm \dfrac{3}{4} x\\)　　B. \\(y = \pm \dfrac{4}{3} x\\)　　C. \\(y = \pm x\\)　　D. \\(y = \pm \dfrac{16}{9} x\\)

A。\\(a = 4\\)，\\(b = 3\\)，渐近线 \\(y = \pm \dfrac{b}{a} x = \pm \dfrac{3}{4} x\\)。

8
基础
抛物线 \\(y^2 = 12x\\) 的焦点坐标为（　） A. \\((3, 0)\\)　　B. \\((6, 0)\\)　　C. \\((-3, 0)\\)　　D. \\((0, 3)\\)

A。\\(2p = 12\\)，\\(p = 6\\)。开口向右，焦点 \\(\left(\dfrac{p}{2}, 0\right) = (3, 0)\\)。

二、填空题（每题 5 分，共 20 分）

1
中等
点 \\((0, 0)\\) 到直线 \\(x + y - 4 = 0\\) 的距离为 ______。

\\(2\sqrt{2}\\)。\\(d = \dfrac{|0 + 0 - 4|}{\sqrt{1^2 + 1^2}} = \dfrac{4}{\sqrt{2}} = 2\sqrt{2}\\)。

2
中等
圆 \\(x^2 + y^2 = 4\\) 被直线 \\(x + y - 2 = 0\\) 截得的弦长为 ______。

\\(2\sqrt{2}\\)。圆心 \\((0,0)\\)，半径 \\(r = 2\\)。圆心到直线距离 \\(d = \dfrac{|-2|}{\sqrt{2}} = \sqrt{2}\\)，
弦长 \\(= 2\sqrt{r^2 - d^2} = 2\sqrt{4 - 2} = 2\sqrt{2}\\)。

3
中等
双曲线 \\(\dfrac{x^2}{9} - \dfrac{y^2}{16} = 1\\) 的焦点坐标为 ______。

\\((\pm 5, 0)\\)。\\(a = 3\\)，\\(b = 4\\)，\\(c = \sqrt{a^2 + b^2} = 5\\)，焦点在 \\(x\\) 轴上。

4
中等
抛物线 \\(x^2 = 8y\\) 上一点到焦点的距离为 5，则该点的纵坐标为 ______。

\\(3\\)。\\(\dfrac{p}{2} = 2\\)，准线 \\(y = -2\\)。点到焦点距离等于到准线距离 \\(= y + 2 = 5\\)，得 \\(y = 3\\)。

三、解答题（共 40 分）

第1题（12分）

题目

已知圆 \\(C\\) 经过点 \\(A(0, 0)\\) 和 \\(B(4, 0)\\)，且圆心在直线 \\(x + y - 3 = 0\\) 上。求圆 \\(C\\) 的标准方程。

解析

解：
设圆心为 \\(C(a, b)\\)。
求弦 \\(AB\\) 的垂直平分线：\\(AB\\) 在 \\(x\\) 轴上且中点为 \\((2, 0)\\)，故垂直平分线为 \\(x = 2\\)，即 \\(a = 2\\)。
又圆心在直线 \\(x + y - 3 = 0\\) 上，代入得 \\(2 + b - 3 = 0\\)，所以 \\(b = 1\\)，圆心为 \\(C(2, 1)\\)。
半径 \\(r = |CA| = \sqrt{(2-0)^2 + (1-0)^2} = \sqrt{5}\\)。
圆的标准方程：\\((x - 2)^2 + (y - 1)^2 = 5\\)。

答案

答：圆的标准方程为 \\((x - 2)^2 + (y - 1)^2 = 5\\)。

第2题（13分）

题目

已知椭圆的中心在原点，焦点在 \\(x\\) 轴上，长轴长为 6，且过点 \\(P(2, \dfrac{5}{3})\\)。
（1）求椭圆的标准方程；
（2）求椭圆的离心率。

解析

解：
（1）设椭圆方程为 \\(\dfrac{x^2}{a^2} + \dfrac{y^2}{b^2} = 1\\)。
长轴长 \\(2a = 6\\)，所以 \\(a = 3\\)，\\(a^2 = 9\\)。
过点 \\(P(2, \dfrac{5}{3})\\)：\\(\dfrac{4}{9} + \dfrac{25}{9b^2} = 1\\)，即 \\(\dfrac{25}{9b^2} = \dfrac{5}{9}\\)，所以 \\(b^2 = 5\\)。
椭圆标准方程：\\(\dfrac{x^2}{9} + \dfrac{y^2}{5} = 1\\)。
（2）\\(c = \sqrt{a^2 - b^2} = \sqrt{9 - 5} = 2\\)，离心率 \\(e = \dfrac{c}{a} = \dfrac{2}{3}\\)。

答案

答：（1）\\(\dfrac{x^2}{9} + \dfrac{y^2}{5} = 1\\)；（2）\\(e = \dfrac{2}{3}\\)。

第3题（15分）

题目

已知抛物线 \\(C: y^2 = 4x\\)，直线 \\(l\\) 过焦点且斜率为 1。
（1）求直线 \\(l\\) 的方程；
（2）求直线 \\(l\\) 被抛物线 \\(C\\) 截得的弦长。

解析

解：
（1）抛物线 \\(y^2 = 4x\\)，\\(2p = 4\\)，\\(p = 2\\)，焦点 \\(F(1, 0)\\)。
直线 \\(l\\) 过 \\(F(1, 0)\\) 且斜率 1：\\(y = x - 1\\)。
（2）将 \\(y = x - 1\\) 代入 \\(y^2 = 4x\\)：\\((x-1)^2 = 4x\\)，即 \\(x^2 - 6x + 1 = 0\\)。
由韦达定理：\\(x_1 + x_2 = 6\\)，\\(x_1 x_2 = 1\\)。
弦长 \\(= \sqrt{1 + k^2} \cdot \sqrt{(x_1+x_2)^2 - 4x_1x_2} = \sqrt{2} \cdot \sqrt{36 - 4} = \sqrt{2} \cdot 4\sqrt{2} = 8\\)。

答案

答：（1）\\(y = x - 1\\)；（2）弦长为 8。
