学习目标

  • 理解曲线与方程的对应关系，掌握曲线方程的概念
  • 掌握求轨迹方程的直译法、定义法、代入法（相关点法）
  • 能根据题意选择合适的方法求动点的轨迹方程
  • 会检验轨迹方程的完备性与纯粹性（注意去杂补漏）

一、曲线与方程的对应关系

在平面直角坐标系中，如果曲线 \\(C\\) 与方程 \\(F(x, y) = 0\\) 满足以下两个条件：

① 曲线上点的坐标都是方程的解（曲线上的点都满足方程，即"曲线上的点都在方程上"）；

② 以方程的解为坐标的点都在曲线上（方程的每个解对应的点都在曲线上，即"方程上的点都在曲线上"）；

那么，方程 \\(F(x, y) = 0\\) 叫做曲线 \\(C\\) 的方程，曲线 \\(C\\) 叫做方程 \\(F(x, y) = 0\\) 的曲线。

这两个条件缺一不可，它们分别保证了轨迹的纯粹性（不多）与完备性（不漏）。

判断"曲线 C 是方程 F(x,y)=0 的曲线"时，必须同时验证两个条件：既不能"多"（方程的解对应不在曲线上的点），也不能"漏"（曲线上的点不满足方程）。例如圆 \\(x^2 + y^2 = 1\\) 与方程 \\(x^2 + y^2 = 1\\)（\\(y \ge 0\\)）就不等价，后者只表示上半圆。

二、求轨迹方程的常用方法

求动点轨迹方程的一般步骤（直译法）：建系、设点、列式、化简、检验。

① 建系：建立适当的平面直角坐标系；

② 设点：设动点 \\(P(x, y)\\)，并写出相关点的坐标；

③ 列式：根据题设条件列出关于 \\(x, y\\) 的等量关系式；

④ 化简：化简整理得到轨迹方程；

⑤ 检验：检查是否有多余的点或遗漏的点，确定变量的取值范围。

三种常用方法

• 直译法：直接把动点满足的几何条件翻译成坐标关系式（最常用）
• 定义法：若动点的轨迹符合某圆锥曲线的定义（如椭圆、双曲线、抛物线），直接写出标准方程
• 代入法（相关点法）：动点 \\(P\\) 随已知曲线上的点 \\(Q\\) 运动，用 \\(P\\) 的坐标表示 \\(Q\\) 的坐标，代入 \\(Q\\) 满足的方程
方法选择技巧：题目给出"距离""垂直""夹角"等可直接翻译的条件时用直译法；条件符合"到两定点距离之和/差为定值"等圆锥曲线定义时用定义法；动点与已知曲线上的点有确定关系（如中点、定比分点）时用代入法。

三、轨迹方程的检验

求得的轨迹方程要注意完备性与纯粹性：

• 若动点轨迹只是曲线的一部分（如圆的一部分、线段），要注明 \\(x, y\\) 的取值范围；

• 化简过程中若进行了"两边平方""去分母"等可能产生增解或漏解的变形，要检验并去掉不满足条件的点。

例如求"到原点的距离等于 2 的点的轨迹"，方程为 \\(x^2 + y^2 = 4\\)，若题目限定动点在 \\(x\\) 轴上方，则还要加上 \\(y > 0\\)。

典型例题

例题1：直译法求轨迹方程

题目

求到定点 \\(A(2, 0)\\) 的距离等于 3 的动点 \\(P\\) 的轨迹方程。

解析

解：
设动点 \\(P(x, y)\\)。
由题意，\\(P\\) 到 \\(A\\) 的距离为 3，即 \\(|PA| = 3\\)。
由两点间距离公式：\\(\sqrt{(x - 2)^2 + y^2} = 3\\)。
两边平方化简：\\((x - 2)^2 + y^2 = 9\\)。
所以轨迹方程为 \\((x - 2)^2 + y^2 = 9\\)，表示以 \\((2, 0)\\) 为圆心、半径为 3 的圆。
检验：两边平方未产生增解，方程表示整圆，无需限制范围。

答案

答案：\\((x - 2)^2 + y^2 = 9\\)。

例题2：定义法求轨迹方程

题目

已知两定点 \\(F_1(-3, 0)\\)、\\(F_2(3, 0)\\)，求到 \\(F_1\\)、\\(F_2\\) 的距离之和为 10 的动点 \\(P\\) 的轨迹方程。

解析

解：
设动点 \\(P(x, y)\\)。
由题意 \\(|PF_1| + |PF_2| = 10\\)。
因为 \\(|F_1F_2| = 6 < 10\\)，符合椭圆的定义（到两定点距离之和为定值且大于两定点间距离），所以轨迹是椭圆。
椭圆中 \\(2a = 10\\)，得 \\(a = 5\\)；焦距 \\(2c = 6\\)，得 \\(c = 3\\)。
\\(b^2 = a^2 - c^2 = 25 - 9 = 16\\)，\\(b = 4\\)。
焦点在 \\(x\\) 轴上，所以轨迹方程为 \\(\dfrac{x^2}{25} + \dfrac{y^2}{16} = 1\\)。
检验：椭圆上每一点都满足距离之和为 10，且方程的解对应的点也都在椭圆上，无需限制范围。

答案

答案：\\(\dfrac{x^2}{25} + \dfrac{y^2}{16} = 1\\)。

例题3：代入法（相关点法）求轨迹方程

题目

已知点 \\(A\\) 在圆 \\(x^2 + y^2 = 4\\) 上运动，点 \\(P\\) 是线段 \\(OA\\) 的中点（\\(O\\) 为坐标原点），求动点 \\(P\\) 的轨迹方程。

解析

解：
设动点 \\(P(x, y)\\)，圆上的点 \\(A(x_0, y_0)\\)。
因为 \\(P\\) 是 \\(OA\\) 的中点，由中点坐标公式：\\(x = \dfrac{x_0}{2}\\)，\\(y = \dfrac{y_0}{2}\\)。
所以 \\(x_0 = 2x\\)，\\(y_0 = 2y\\)。
因为 \\(A\\) 在圆上，所以 \\(x_0^2 + y_0^2 = 4\\)。
代入得：\\((2x)^2 + (2y)^2 = 4\\)，即 \\(4x^2 + 4y^2 = 4\\)，化简得 \\(x^2 + y^2 = 1\\)。
所以 \\(P\\) 的轨迹方程为 \\(x^2 + y^2 = 1\\)，表示以原点为圆心、半径为 1 的圆。

答案

答案：\\(x^2 + y^2 = 1\\)。

练习题

1
基础
判断点 \\((1, 2)\\) 是否在曲线 \\(x^2 + y^2 = 5\\) 上。

答案：在。\\(1^2 + 2^2 = 1 + 4 = 5\\)，满足方程，所以点在曲线上。

2
基础
求到定点 \\(B(0, 1)\\) 的距离等于 2 的动点 \\(P\\) 的轨迹方程。

答案：\\(x^2 + (y - 1)^2 = 4\\)。设 \\(P(x, y)\\)，由 \\(\sqrt{x^2 + (y-1)^2} = 2\\) 两边平方化简得。

3
中等
已知两定点 \\(F_1(-2, 0)\\)、\\(F_2(2, 0)\\)，求到 \\(F_1\\)、\\(F_2\\) 的距离之和为 8 的动点 \\(P\\) 的轨迹方程。

答案：\\(\dfrac{x^2}{16} + \dfrac{y^2}{12} = 1\\)。\\(2a = 8\\)，\\(a = 4\\)；\\(2c = 4\\)，\\(c = 2\\)；\\(b^2 = a^2 - c^2 = 16 - 4 = 12\\)，焦点在 \\(x\\) 轴，为椭圆。

4
进阶
已知点 \\(A\\) 在圆 \\((x - 1)^2 + y^2 = 1\\) 上运动，点 \\(P\\) 是线段 \\(OA\\) 的中点（\\(O\\) 为坐标原点），求动点 \\(P\\) 的轨迹方程。

答案：\\((x - \dfrac{1}{2})^2 + y^2 = \dfrac{1}{4}\\)。设 \\(P(x, y)\\)、\\(A(x_0, y_0)\\)，由中点公式 \\(x_0 = 2x\\)、\\(y_0 = 2y\\)，代入 \\((x_0 - 1)^2 + y_0^2 = 1\\) 得 \\((2x - 1)^2 + (2y)^2 = 1\\)，即 \\((x - \dfrac{1}{2})^2 + y^2 = \dfrac{1}{4}\\)。
