韦达定理

韦达定理可用于：求弦长、求中点坐标 \\(\left(\dfrac{x_1+x_2}{2}, \dfrac{y_1+y_2}{2}\right)\\)、求面积等，避免直接求交点坐标。

典型例题

例题1：求交点

题目

求直线 \\(y = x + 1\\) 与抛物线 \\(y^2 = 4x\\) 的交点坐标。

解析

解：将 \\(y = x + 1\\) 代入 \\(y^2 = 4x\\)：

$$(x+1)^2 = 4x \Rightarrow x^2 + 2x + 1 = 4x \Rightarrow x^2 - 2x + 1 = 0$$

$$(x - 1)^2 = 0 \Rightarrow x = 1$$

代入 \\(y = x + 1\\)：\\(y = 2\\)。

所以交点为 \\((1, 2)\\)。由于 \\(\Delta = 0\\)，直线与抛物线相切。

答案

答：交点为 \\((1, 2)\\)（相切）。

例题2：求弦长

题目

求直线 \\(y = x - 1\\) 被椭圆 \\(\dfrac{x^2}{4} + \dfrac{y^2}{2} = 1\\) 截得的弦长。

解析

解：将 \\(y = x - 1\\) 代入椭圆方程：

$$\frac{x^2}{4} + \frac{(x-1)^2}{2} = 1$$

两边乘 4：\\(x^2 + 2(x-1)^2 = 4 \Rightarrow x^2 + 2x^2 - 4x + 2 = 4 \Rightarrow 3x^2 - 4x - 2 = 0\\)。

设两根为 \\(x_1, x_2\\)，由韦达定理：\\(x_1 + x_2 = \dfrac{4}{3}\\)，\\(x_1 x_2 = -\dfrac{2}{3}\\)。

弦长 \\(= \sqrt{1+k^2} \cdot \sqrt{(x_1+x_2)^2 - 4x_1 x_2} = \sqrt{1+1} \cdot \sqrt{\dfrac{16}{9} + \dfrac{8}{3}}\\)。

\\(\dfrac{16}{9} + \dfrac{8}{3} = \dfrac{16}{9} + \dfrac{24}{9} = \dfrac{40}{9}\\)。

弦长 \\(= \sqrt{2} \times \dfrac{\sqrt{40}}{3} = \sqrt{2} \times \dfrac{2\sqrt{10}}{3} = \dfrac{2\sqrt{20}}{3} = \dfrac{4\sqrt{5}}{3}\\)。

答案

答：弦长为 \\(\dfrac{4\sqrt{5}}{3}\\)。

例题3：中点弦问题

题目

已知椭圆 \\(\dfrac{x^2}{4} + y^2 = 1\\)，求以点 \\(P(1, \dfrac{1}{2})\\) 为中点的弦所在直线的方程。

解析

分析：设弦两端点为 \\(A(x_1, y_1)\\)、\\(B(x_2, y_2)\\)，中点为 \\(P\\)。利用"点差法"。

解：由中点公式：\\(x_1 + x_2 = 2\\)，\\(y_1 + y_2 = 1\\)。

两点在椭圆上：\\(\dfrac{x_1^2}{4} + y_1^2 = 1\\)，\\(\dfrac{x_2^2}{4} + y_2^2 = 1\\)。

两式相减：\\(\dfrac{x_1^2 - x_2^2}{4} + (y_1^2 - y_2^2) = 0\\)。

即 \\(\dfrac{(x_1+x_2)(x_1-x_2)}{4} + (y_1+y_2)(y_1-y_2) = 0\\)。

代入中点：\\(\dfrac{2(x_1-x_2)}{4} + 1 \cdot (y_1-y_2) = 0\\)，即 \\(\dfrac{x_1-x_2}{2} + (y_1-y_2) = 0\\)。

所以斜率 \\(k = \dfrac{y_1-y_2}{x_1-x_2} = -\dfrac{1}{2}\\)。

直线方程（点斜式）：\\(y - \dfrac{1}{2} = -\dfrac{1}{2}(x - 1)\\)，即 \\(x + 2y - 2 = 0\\)。

答案

答：弦所在直线方程为 \\(x + 2y - 2 = 0\\)。

练习题

1
基础
直线 \\(y = 2x + 1\\) 与抛物线 \\(y^2 = 2x\\) 联立后，求 \\(\Delta\\) 的值并判断位置关系。

解：代入得 \\(4x^2+2x+1=0\\)，\\(\Delta=4-16=-12<0\\)，相离。

2
基础
直线 \\(y = x\\) 与椭圆 \\(x^2 + 2y^2 = 3\\) 相交，求交点坐标。

解：代入得 \\(3x^2=3\\)，\\(x=\pm1\\)。交点为 \\((1,1)\\) 和 \\((-1,-1)\\)。

3
中等
直线 \\(y = x + 1\\) 与圆 \\(x^2 + y^2 = 5\\) 相交于 \\(A, B\\)，利用弦长公式求 \\(|AB|\\)。

解：代入得 \\(2x^2+2x-4=0\\)，\\(x^2+x-2=0\\)，\\(x_1+x_2=-1, x_1x_2=-2\\)。弦长 \\(=\sqrt{2}\times\sqrt{1+8}=\sqrt{2}\times3=3\sqrt{2}\\)。

4
中等
抛物线 \\(y^2 = 8x\\) 的弦 \\(AB\\) 中点为 \\((2, 2)\\)，用点差法求直线 \\(AB\\) 的方程。

解：点差法，\\(y_1^2-y_2^2=8(x_1-x_2)\\)，\\((y_1+y_2)(y_1-y_2)=8(x_1-x_2)\\)，\\(4k=8\\)，\\(k=2\\)。方程 \\(y-2=2(x-2)\\)，即 \\(2x-y-2=0\\)。

5
进阶
韦达定理中，若方程 \\(2x^2 - 6x + 1 = 0\\) 的两根为 \\(x_1, x_2\\)，求 \\(x_1 + x_2\\) 和 \\(x_1 x_2\\)。

解：\\(x_1+x_2=\dfrac{6}{2}=3\\)，\\(x_1 x_2=\dfrac{1}{2}\\)。
