一、实数大小的比较

实数的大小关系通过它们的差来判定，这是不等式的理论基础。

作差比较法

作差比较法的步骤：作差 \\(\rightarrow\\) 变形（因式分解、配方等）\\(\rightarrow\\) 判断符号 \\(\rightarrow\\) 得出结论。

性质1：对称性

性质2：传递性

性质3：加法保号性

性质4：乘法性质（注意变号）

乘法性质是易错点！不等式两边同乘或同除一个数时，必须先判断该数的正负。若不确定符号，需分类讨论。

同向不等式相加

同向正数不等式相乘

乘方性质

倒数性质

典型例题

例题1：比较大小（作差法）

题目

已知 \\(a, b\\) 均为正数，比较 \\(a^2 + b^2\\) 与 \\(2ab\\) 的大小。

解析

解：用作差比较法。

$$a^2 + b^2 - 2ab = (a - b)^2$$

因为对任意实数 \\(a, b\\)，都有 \\((a-b)^2 \ge 0\\)，

当且仅当 \\(a = b\\) 时，\\((a-b)^2 = 0\\)。

所以 \\(a^2 + b^2 \ge 2ab\\)，当且仅当 \\(a = b\\) 时取等号。

答案

答案：\\(a^2 + b^2 \ge 2ab\\)，当且仅当 \\(a = b\\) 时等号成立。

例题2：利用性质判断

题目

已知 \\(a > b > 0\\)，\\(c < 0\\)，比较：

（1）\\(a + c\\) 与 \\(b + c\\)；

（2）\\(ac\\) 与 \\(bc\\)；

（3）\\(\frac{1}{a}\\) 与 \\(\frac{1}{b}\\)。

解析

解：

（1）因为 \\(a > b\\)，由加法保号性，两边同加 \\(c\\)，不等号方向不变：

$$a + c > b + c$$

（2）因为 \\(a > b\\) 且 \\(c < 0\\)，由乘法性质（同乘负数，方向改变）：

$$ac < bc$$

（3）因为 \\(a > b > 0\\)，由倒数性质（正数取倒数，方向改变）：

$$\frac{1}{a} < \frac{1}{b}$$

答案

答案：（1）\\(a+c > b+c\\)；（2）\\(ac < bc\\)；（3）\\(\frac{1}{a} < \frac{1}{b}\\)。

例题3：利用性质求范围（基础计算型）

题目

已知 \\(-2 < a < 3\\)，\\(-1 < b < 2\\)，求 \\(a + b\\) 和 \\(a - b\\) 的取值范围。

解析

解：

求 \\(a + b\\) 的范围：

由 \\(-2 < a < 3\\)，\\(-1 < b < 2\\)，同向相加：

$$-2 + (-1) < a + b < 3 + 2$$

即 \\(-3 < a + b < 5\\)。

求 \\(a - b\\) 的范围：

由 \\(-1 < b < 2\\)，得 \\(-2 < -b < 1\\)（方向改变）。

再与 \\(-2 < a < 3\\) 同向相加：

$$-2 + (-2) < a - b < 3 + 1$$

即 \\(-4 < a - b < 4\\)。

注意：不能先求 \\(a\\) 和 \\(b\\) 各自的范围再相减，同向不等式只能相加不能相减。

答案

答案：\\(-3 < a+b < 5\\)；\\(-4 < a-b < 4\\)。

例题4：不等式性质的常见错误辨析（易错型）

题目

判断下列命题是否正确，并说明理由：

（1）若 \\(a > b\\)，则 \\(a^2 > b^2\\)；

（2）若 \\(a > b\\)，则 \\(\frac{1}{a} < \frac{1}{b}\\)；

（3）若 \\(ac^2 > bc^2\\)，则 \\(a > b\\)。

解析

解：

（1）错误。反例：\\(a = 1, b = -2\\)，此时 \\(a > b\\)，但 \\(a^2 = 1 < b^2 = 4\\)。只有当 \\(a > b > 0\\)（两边均为正）时，\\(a^2 > b^2\\) 才成立。

（2）错误。反例：\\(a = 1, b = -1\\)，此时 \\(a > b\\)，但 \\(\frac{1}{a} = 1 > -1 = \frac{1}{b}\\)。取倒数需要 \\(a, b\\) 同号且不为零。

（3）正确。由 \\(ac^2 > bc^2\\) 可知 \\(c^2 \ne 0\\)（若 \\(c = 0\\)，则 \\(ac^2 = bc^2 = 0\\)，不可能大于）。所以 \\(c^2 > 0\\)，两边同除以正数 \\(c^2\\)（方向不变），得 \\(a > b\\)。

易错提醒：不等式两边乘除一个数时，必须先确定该数的正负。若不确定符号，需分类讨论。

答案

答案：（1）错误；（2）错误；（3）正确。

例题5：作差法比较三式大小（综合应用型）

题目

已知 \\(a, b, c\\) 为实数，比较 \\(a^2 + b^2 + c^2\\) 与 \\(ab + bc + ca\\) 的大小。

解析

解：用作差比较法。

$$a^2 + b^2 + c^2 - (ab + bc + ca)$$

将表达式配凑成完全平方的形式：

$$= \frac{1}{2}\left[(a^2 - 2ab + b^2) + (b^2 - 2bc + c^2) + (c^2 - 2ca + a^2)\right]$$

$$= \frac{1}{2}\left[(a-b)^2 + (b-c)^2 + (c-a)^2\right]$$

因为对任意实数，\\((a-b)^2 \ge 0\\)，\\((b-c)^2 \ge 0\\)，\\((c-a)^2 \ge 0\\)，

所以 \\(\frac{1}{2}\left[(a-b)^2 + (b-c)^2 + (c-a)^2\right] \ge 0\\)。

当且仅当 \\(a - b = 0\\)，\\(b - c = 0\\)，\\(c - a = 0\\) 同时成立，即 \\(a = b = c\\) 时等号成立。

所以 \\(a^2 + b^2 + c^2 \ge ab + bc + ca\\)，当且仅当 \\(a = b = c\\) 时等号成立。

答案

答案：\\(a^2 + b^2 + c^2 \ge ab + bc + ca\\)，当且仅当 \\(a = b = c\\) 时等号成立。

练习题

1
基础
若 \\(a > b\\)，则下列不等式中一定成立的是（　） A. \\(a^2 > b^2\\)　　B. \\(\frac{1}{a} < \frac{1}{b}\\) C. \\(a - 3 > b - 3\\)　　D. \\(ac > bc\\)（\\(c \ne 0\\)）

答案：C。A错误，如 \\(a=1, b=-2\\) 时 \\(a>b\\) 但 \\(a^2=1 < b^2=4\\)；B错误，如 \\(a=1, b=-2\\) 时 \\(\frac{1}{a}=1 > \frac{1}{b}=-\frac{1}{2}\\)，但 \\(a>b\\)；C正确，\\(a>b \Rightarrow a-3>b-3\\)；D错误，\\(c<0\\) 时方向改变。

2
中等
比较 \\((x+1)(x+5)\\) 与 \\((x+3)^2\\) 的大小。

答案：\\((x+1)(x+5) \le (x+3)^2\\)。作差：\\((x+1)(x+5)-(x+3)^2 = (x^2+6x+5)-(x^2+6x+9) = -4 < 0\\)。所以 \\((x+1)(x+5) < (x+3)^2\\) 恒成立。

3
中等
已知 \\(a < b < 0\\)，比较 \\(a^2\\) 与 \\(b^2\\) 的大小。

答案：\\(a^2 > b^2\\)。因为 \\(a < b < 0\\)，取相反数方向改变：\\(-a > -b > 0\\)（正数）。由乘方性质，\\((-a)^2 > (-b)^2\\)，即 \\(a^2 > b^2\\)。

4
进阶
已知 \\(-1 < a < 2\\)，求 \\(2a - 1\\) 的取值范围。

答案：\\(-3 < 2a-1 < 3\\)。由 \\(-1 < a < 2\\)，两边同乘2（正数，方向不变）：\\(-2 < 2a < 4\\)。两边同减1：\\(-3 < 2a-1 < 3\\)。
