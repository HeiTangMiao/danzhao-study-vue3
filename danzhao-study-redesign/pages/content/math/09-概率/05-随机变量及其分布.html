学习目标

  • 理解离散型随机变量的概念，掌握分布列的定义与性质
  • 掌握两点分布、二项分布、超几何分布及其概率计算
  • 掌握数学期望与方差的计算公式，了解正态分布与 3σ 原则

一、离散型随机变量与分布列

随机变量：如果随机试验的结果可以用一个变量 \\(X\\) 来表示，且 \\(X\\) 的取值随试验结果的不同而变化，则称 \\(X\\) 为随机变量。

离散型随机变量：取值可以一一列举出来的随机变量。例如掷骰子出现的点数、抽取次品的件数等。

分布列：设离散型随机变量 \\(X\\) 的所有可能取值为 \\(x_1, x_2, \ldots, x_n\\)，\\(X\\) 取各值的概率为 \\(p_i = P(X = x_i)\\)，则称表格为 \\(X\\) 的分布列。

分布列的两条性质：① \\(p_i \ge 0\\)（i = 1, 2, ..., n）；② \\(p_1 + p_2 + \cdots + p_n = 1\\)。

分布列的性质

二、两点分布与二项分布

两点分布：如果随机变量 \\(X\\) 只取两个值 0 和 1，且 \\(P(X = 1) = p\\)，\\(P(X = 0) = 1 - p\\)（\\(0 < p < 1\\)），则称 \\(X\\) 服从两点分布（又称 0-1 分布）。

二项分布：在 \\(n\\) 次独立重复试验中，每次试验只有"成功"与"失败"两种结果，且成功的概率为 \\(p\\)。设 \\(X\\) 为 \\(n\\) 次试验中成功的次数，则 \\(X\\) 服从参数为 \\(n, p\\) 的二项分布，记作 \\(X \sim B(n, p)\\)。

\\(P(X = k) = C_n^k p^k (1 - p)^{n-k}\\)，其中 \\(k = 0, 1, 2, \ldots, n\\)。

二项分布

三、超几何分布

超几何分布：在含有 \\(M\\) 件次品的 \\(N\\) 件产品中，不放回地任取 \\(n\\) 件，设其中次品件数为 \\(X\\)，则 \\(X\\) 服从超几何分布。

\\(P(X = k) = \dfrac{C_M^k C_{N-M}^{n-k}}{C_N^n}\\)，其中 \\(k = 0, 1, 2, \ldots, \min\{M, n\}\\)。

注意：二项分布对应"有放回"（各次独立）抽取，超几何分布对应"不放回"抽取。当 \\(N\\) 很大时，超几何分布可近似看作二项分布。

超几何分布

四、数学期望与方差

数学期望（均值）：离散型随机变量 \\(X\\) 的分布列为 \\(P(X = x_i) = p_i\\)，则 \\(E(X) = x_1 p_1 + x_2 p_2 + \cdots + x_n p_n = \sum_{i=1}^{n} x_i p_i\\)，它反映了随机变量取值的平均水平。

方差：\\(D(X) = \sum_{i=1}^{n} (x_i - E(X))^2 p_i\\)，它反映了随机变量取值相对于均值的离散程度。

常用结论：\\(E(aX + b) = aE(X) + b\\)；\\(D(aX + b) = a^2 D(X)\\)。

两点分布：\\(E(X) = p\\)，\\(D(X) = p(1-p)\\)。

二项分布：\\(E(X) = np\\)，\\(D(X) = np(1-p)\\)。

期望与方差公式

五、正态分布与 3σ 原则

正态分布：如果随机变量 \\(X\\) 的概率密度曲线呈"中间高、两边低"的钟形，则称 \\(X\\) 服从正态分布，记作 \\(X \sim N(\mu, \sigma^2)\\)，其中 \\(\mu\\) 为均值（对称轴），\\(\sigma\\) 为标准差。

3σ 原则：\\(P(\mu - \sigma < X < \mu + \sigma) \approx 0.6827\\)；\\(P(\mu - 2\sigma < X < \mu + 2\sigma) \approx 0.9545\\)；\\(P(\mu - 3\sigma < X < \mu + 3\sigma) \approx 0.9973\\)。

即正态变量取值几乎全部落在 \\((\mu - 3\sigma, \mu + 3\sigma)\\) 内。

分布列的两条性质是检验分布列是否正确的依据：所有概率非负且和为 1。若题目给出的分布列中某项概率为负或总和不为 1，则该分布列不成立。
判断二项分布与超几何分布："有放回"或"独立重复"用二项分布；"不放回"从有限总体中抽取用超几何分布。计算期望时，二项分布直接套 \\(E(X) = np\\)，可避免繁琐的求和。

典型例题

例题1：分布列与期望

题目

某射手射击一次命中环数 \\(X\\) 的分布列为：\\(P(X = 8) = 0.2\\)，\\(P(X = 9) = 0.3\\)，\\(P(X = 10) = 0.5\\)。求 \\(E(X)\\) 和 \\(D(X)\\)。

解析

解：\\(E(X) = 8 \times 0.2 + 9 \times 0.3 + 10 \times 0.5 = 1.6 + 2.7 + 5 = 9.3\\)。

\\(D(X) = (8 - 9.3)^2 \times 0.2 + (9 - 9.3)^2 \times 0.3 + (10 - 9.3)^2 \times 0.5\\)

\\(= 1.69 \times 0.2 + 0.09 \times 0.3 + 0.49 \times 0.5 = 0.338 + 0.027 + 0.245 = 0.61\\)。

答案

答：\\(E(X) = 9.3\\)，\\(D(X) = 0.61\\)。

例题2：二项分布

题目

某射手每次射击命中目标的概率为 0.8，连续射击 4 次，各次射击相互独立。求恰好命中 3 次的概率以及命中次数的期望。

解析

解：设命中次数为 \\(X\\)，则 \\(X \sim B(4, 0.8)\\)。

恰好命中 3 次：\\(P(X = 3) = C_4^3 \times 0.8^3 \times (1 - 0.8)^1 = 4 \times 0.512 \times 0.2 = 0.4096\\)。

期望：\\(E(X) = np = 4 \times 0.8 = 3.2\\)。

答案

答：恰好命中 3 次的概率为 0.4096，命中次数的期望为 3.2。

例题3：超几何分布

题目

一批产品共 10 件，其中 3 件次品，从中不放回地任取 4 件，求取到的次品件数 \\(X\\) 的分布列及期望。

解析

解：\\(X\\) 服从超几何分布，\\(N = 10\\)，\\(M = 3\\)，\\(n = 4\\)。

\\(P(X = k) = \dfrac{C_3^k C_7^{4-k}}{C_{10}^4}\\)，\\(k = 0, 1, 2, 3\\)。

\\(C_{10}^4 = 210\\)。

\\(P(X = 0) = \dfrac{C_3^0 C_7^4}{210} = \dfrac{35}{210} = \dfrac{1}{6}\\)；

\\(P(X = 1) = \dfrac{C_3^1 C_7^3}{210} = \dfrac{3 \times 35}{210} = \dfrac{105}{210} = \dfrac{1}{2}\\)；

\\(P(X = 2) = \dfrac{C_3^2 C_7^2}{210} = \dfrac{3 \times 21}{210} = \dfrac{63}{210} = \dfrac{3}{10}\\)；

\\(P(X = 3) = \dfrac{C_3^3 C_7^1}{210} = \dfrac{7}{210} = \dfrac{1}{30}\\)。

期望：\\(E(X) = 0 \times \dfrac{1}{6} + 1 \times \dfrac{1}{2} + 2 \times \dfrac{3}{10} + 3 \times \dfrac{1}{30} = 0 + 0.5 + 0.6 + 0.1 = 1.2\\)。

答案

答：分布列为 \\(P(X=0)=\dfrac{1}{6}\\)，\\(P(X=1)=\dfrac{1}{2}\\)，\\(P(X=2)=\dfrac{3}{10}\\)，\\(P(X=3)=\dfrac{1}{30}\\)；\\(E(X) = 1.2\\)。

例题4：正态分布 3σ 原则

题目

某班数学成绩服从正态分布 \\(N(80, 100)\\)，即均值 80、方差 100。求成绩在 70 到 90 之间的概率（结果保留两位小数）。

解析

解：\\(\mu = 80\\)，\\(\sigma = \sqrt{100} = 10\\)。

成绩在 70 到 90 之间，即 \\(\mu - \sigma < X < \mu + \sigma\\)。

由 3σ 原则：\\(P(\mu - \sigma < X < \mu + \sigma) \approx 0.6827\\)。

所以 \\(P(70 < X < 90) \approx 0.68\\)。

答案

答：成绩在 70 到 90 之间的概率约为 0.68。

练习题

1
基础
设随机变量 \\(X\\) 的分布列为 \\(P(X = 1) = 0.3\\)，\\(P(X = 2) = 0.5\\)，\\(P(X = 3) = a\\)，求 \\(a\\) 及 \\(E(X)\\)。

解：由分布列性质 \\(0.3 + 0.5 + a = 1\\)，得 \\(a = 0.2\\)。\\(E(X) = 1 \times 0.3 + 2 \times 0.5 + 3 \times 0.2 = 0.3 + 1 + 0.6 = 1.9\\)。

2
基础
掷一枚均匀硬币 3 次，设正面朝上的次数为 \\(X\\)，求 \\(P(X = 2)\\)。

解：\\(X \sim B(3, 0.5)\\)。\\(P(X = 2) = C_3^2 \times 0.5^2 \times 0.5 = 3 \times 0.125 = 0.375\\)。

3
中等
某射手命中率为 0.6，独立射击 5 次，求命中次数的期望和方差。

解：\\(X \sim B(5, 0.6)\\)。\\(E(X) = 5 \times 0.6 = 3\\)，\\(D(X) = 5 \times 0.6 \times 0.4 = 1.2\\)。

4
中等
已知 \\(E(X) = 2\\)，\\(D(X) = 1\\)，求 \\(E(3X + 1)\\) 和 \\(D(3X + 1)\\)。

解：\\(E(3X + 1) = 3E(X) + 1 = 3 \times 2 + 1 = 7\\)；\\(D(3X + 1) = 3^2 D(X) = 9 \times 1 = 9\\)。

5
进阶
袋中有 2 个红球、3 个白球，不放回地取 2 个球，设红球个数为 \\(X\\)，求 \\(X\\) 的分布列。

解：\\(X\\) 可取 0, 1, 2。\\(P(X=0) = \dfrac{C_3^2}{C_5^2} = \dfrac{3}{10}\\)；\\(P(X=1) = \dfrac{C_2^1 C_3^1}{C_5^2} = \dfrac{6}{10} = \dfrac{3}{5}\\)；\\(P(X=2) = \dfrac{C_2^2}{C_5^2} = \dfrac{1}{10}\\)。
