学习目标

  • 理解诱导公式的推导过程，掌握口诀"奇变偶不变，符号看象限"
  • 熟练运用诱导公式进行三角函数式的化简和求值
  • 能利用诱导公式证明简单的三角恒等式

一、诱导公式口诀

"奇变偶不变，符号看象限"

• 奇变偶不变：当 \\(k\\) 为奇数时，函数名改变（正弦变余弦，余弦变正弦）；当 \\(k\\) 为偶数时，函数名不变。

• 符号看象限：将 \\(\alpha\\) 视为锐角，判断 \\(k \cdot \frac{\pi}{2} \pm \alpha\\) 所在象限，原三角函数在该象限的符号决定结果的符号。

\\(2k\pi + \alpha\\)（\\(k \in \mathbb{Z}\\)）的三角函数值等于 \\(\alpha\\) 的同名三角函数值，即 \\(\sin(2k\pi + \alpha) = \sin\alpha\\)，\\(\cos(2k\pi + \alpha) = \cos\alpha\\)。

典型例题

例题1：化简

题目

化简：\\(\sin\left(\frac{3\pi}{2} - \alpha\right) + \cos(\pi + \alpha)\\)

解析

解：

\\(\frac{3\pi}{2} = 3 \times \frac{\pi}{2}\\)，\\(k=3\\) 为奇数，函数名改变。

将 \\(\alpha\\) 视为锐角，\\(\frac{3\pi}{2} - \alpha\\) 在第三象限，\\(\sin\\) 在第三象限为负。

所以 \\(\sin\left(\frac{3\pi}{2} - \alpha\right) = -\cos\alpha\\)

\\(\pi + \alpha\\)：\\(k=2\\) 为偶数，函数名不变，\\(\pi + \alpha\\) 在第三象限，\\(\cos\\) 为负。

所以 \\(\cos(\pi + \alpha) = -\cos\alpha\\)

原式 \\(= -\cos\alpha + (-\cos\alpha) = -2\cos\alpha\\)

答案

原式 \\(= -2\cos\alpha\\)

例题2：求值

题目

求值：\\(\sin\frac{8\pi}{3} \cdot \cos\frac{25\pi}{6}\\)

解析

解：

\\(\sin\frac{8\pi}{3} = \sin\left(2\pi + \frac{2\pi}{3}\right) = \sin\frac{2\pi}{3} = \sin\left(\pi - \frac{\pi}{3}\right) = \sin\frac{\pi}{3} = \frac{\sqrt{3}}{2}\\)

\\(\cos\frac{25\pi}{6} = \cos\left(4\pi + \frac{\pi}{6}\right) = \cos\frac{\pi}{6} = \frac{\sqrt{3}}{2}\\)

原式 \\(= \frac{\sqrt{3}}{2} \times \frac{\sqrt{3}}{2} = \frac{3}{4}\\)

答案

原式 \\(= \frac{3}{4}\\)

例题3：证明

题目

求证：\\(\frac{\sin(\pi - \alpha)\cos(-\alpha)}{\tan(\pi + \alpha)} = \cos^2\alpha\\)

解析

证明：

左边 \\(= \frac{\sin\alpha \cdot \cos\alpha}{\tan\alpha}\\)

\\(= \frac{\sin\alpha \cdot \cos\alpha}{\frac{\sin\alpha}{\cos\alpha}}\\)

\\(= \sin\alpha \cdot \cos\alpha \cdot \frac{\cos\alpha}{\sin\alpha}\\)

\\(= \cos^2\alpha =\\) 右边

所以等式成立。

答案

是（左边化简得 \\(\cos^2\alpha\\)，与右边相等，得证）

例题4：公式推导

题目

利用已学诱导公式，推导 \\(\sin\left(\frac{3\pi}{2} + \alpha\right)\\) 的表达式。

解析

推导：

将 \\(\frac{3\pi}{2} + \alpha\\) 拆分为 \\(\pi + \left(\frac{\pi}{2} + \alpha\right)\\)，分两步使用诱导公式。

第一步：对 \\(\frac{\pi}{2} + \alpha\\) 使用公式六（函数名改变）。

将 \\(\alpha\\) 视为锐角，\\(\frac{\pi}{2} + \alpha\\) 在第二象限，\\(\sin\\) 为正，故 \\(\sin\left(\frac{\pi}{2} + \alpha\right) = \cos\alpha\\)。

第二步：对 \\(\pi + \left(\frac{\pi}{2} + \alpha\right)\\) 使用公式二（函数名不变）。

\\(\pi + \left(\frac{\pi}{2} + \alpha\right) = \frac{3\pi}{2} + \alpha\\) 在第四象限，\\(\sin\\) 为负，故：

\\(\sin\left(\frac{3\pi}{2} + \alpha\right) = \sin\left[\pi + \left(\frac{\pi}{2} + \alpha\right)\right] = -\sin\left(\frac{\pi}{2} + \alpha\right) = -\cos\alpha\\)

亦可直接用口诀验证：\\(\frac{3\pi}{2} + \alpha = 3 \times \frac{\pi}{2} + \alpha\\)，\\(k = 3\\) 为奇数，函数名改变（正弦变余弦）；\\(\frac{3\pi}{2} + \alpha\\) 在第四象限，\\(\sin\\) 为负，所以结果为 \\(-\cos\alpha\\)，两种方法一致。

答案

\\(\sin\left(\frac{3\pi}{2} + \alpha\right) = -\cos\alpha\\)

例题5：易错辨析

题目

化简：\\(\sin(\pi - \alpha) + \cos(\pi + \alpha)\\)

解析

常见错误解法：

误认为 \\(\pi - \alpha\\) 与 \\(\pi + \alpha\\) 都是"加 \\(\pi\\)"型，统一变号：

错误地写 \\(\sin(\pi - \alpha) = -\sin\alpha\\)，\\(\cos(\pi + \alpha) = \cos\alpha\\)，

得原式 \\(= -\sin\alpha + \cos\alpha\\)（错误！）。

错误原因：混淆了 \\(\pi - \alpha\\) 与 \\(\pi + \alpha\\)。两者虽都属"函数名不变"型，但所在象限不同，符号不同。\\(\pi - \alpha\\) 在第二象限，\\(\sin\\) 为正；\\(\pi + \alpha\\) 在第三象限，\\(\cos\\) 为负。

正确解法：

\\(\sin(\pi - \alpha) = \sin\alpha\\)（第二象限，\\(\sin\\) 为正）

\\(\cos(\pi + \alpha) = -\cos\alpha\\)（第三象限，\\(\cos\\) 为负）

原式 \\(= \sin\alpha + (-\cos\alpha) = \sin\alpha - \cos\alpha\\)

答案

原式 \\(= \sin\alpha - \cos\alpha\\)

练习题

1
基础
化简：\\(\cos(\pi - \alpha) - \cos(\pi + \alpha)\\)

\\(\cos(\pi - \alpha) = -\cos\alpha\\)，\\(\cos(\pi + \alpha) = -\cos\alpha\\)，原式 \\(= -\cos\alpha - (-\cos\alpha) = 0\\)

2
基础
求 \\(\sin\frac{17\pi}{6}\\) 的值。

\\(\sin\frac{17\pi}{6} = \sin\left(2\pi + \frac{5\pi}{6}\right) = \sin\frac{5\pi}{6} = \sin\left(\pi - \frac{\pi}{6}\right) = \sin\frac{\pi}{6} = \frac{1}{2}\\)

3
中等
化简：\\(\sin\left(\frac{\pi}{2} + \alpha\right) \cdot \cos\left(\frac{\pi}{2} - \alpha\right)\\)

\\(\sin\left(\frac{\pi}{2} + \alpha\right) = \cos\alpha\\)，\\(\cos\left(\frac{\pi}{2} - \alpha\right) = \sin\alpha\\)，原式 \\(= \cos\alpha \cdot \sin\alpha = \sin\alpha\cos\alpha\\)

4
中等
已知 \\(\sin\alpha = \frac{1}{3}\，\alpha \in \left(\frac{\pi}{2}, \pi\right)\\)，求 \\(\sin(\pi + \alpha)\\) 和 \\(\cos(-\alpha)\\) 的值。

\\(\sin(\pi + \alpha) = -\sin\alpha = -\frac{1}{3}\\)。由 \\(\sin^2\alpha + \cos^2\alpha = 1\\)，\\(\cos\alpha = -\frac{2\sqrt{2}}{3}\\)（第二象限为负），\\(\cos(-\alpha) = \cos\alpha = -\frac{2\sqrt{2}}{3}\\)

5
进阶
求值：\\(\tan\frac{7\pi}{4} + \sin\frac{11\pi}{3}\\)

\\(\tan\frac{7\pi}{4} = \tan\left(2\pi - \frac{\pi}{4}\right) = -\tan\frac{\pi}{4} = -1\\)；\\(\sin\frac{11\pi}{3} = \sin\left(2\pi + \frac{5\pi}{3}\right) = \sin\frac{5\pi}{3} = \sin\left(2\pi - \frac{\pi}{3}\right) = -\sin\frac{\pi}{3} = -\frac{\sqrt{3}}{2}\\)。原式 \\(= -1 + \left(-\frac{\sqrt{3}}{2}\right) = -1 - \frac{\sqrt{3}}{2}\\)
