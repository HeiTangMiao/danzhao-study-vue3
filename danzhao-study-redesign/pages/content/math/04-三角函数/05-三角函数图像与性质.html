学习目标

  • 掌握 \\(y = \sin x\\)、\\(y = \cos x\\)、\\(y = \tan x\\) 的定义域、值域、周期性和奇偶性
  • 理解 \\(y = A\sin(\omega x + \varphi)\\) 中各参数的含义，掌握周期公式
  • 掌握图像的平移变换和伸缩变换规律
  • 能用五点法画出 \\(y = A\sin(\omega x + \varphi)\\) 的图像

一、正弦函数 \(y = \sin x\) 的性质

性质内容
定义域\\(\mathbb{R}\\)
值域\\([-1, 1]\\)
周期\\(T = 2\pi\\)
奇偶性奇函数（图像关于原点对称）
单调性增区间：\\(\left[2k\pi - \frac{\pi}{2}, 2k\pi + \frac{\pi}{2}\right]\\)；减区间：\\(\left[2k\pi + \frac{\pi}{2}, 2k\pi + \frac{3\pi}{2}\right]\\)，\\(k \in \mathbb{Z}\\)

二、余弦函数 \(y = \cos x\) 的性质

性质内容
定义域\\(\mathbb{R}\\)
值域\\([-1, 1]\\)
周期\\(T = 2\pi\\)
奇偶性偶函数（图像关于 \\(y\\) 轴对称）
单调性增区间：\\([2k\pi - \pi, 2k\pi]\\)；减区间：\\([2k\pi, 2k\pi + \pi]\\)，\\(k \in \mathbb{Z}\\)

三、正切函数 \(y = \tan x\) 的性质

性质内容
定义域\\(\left\{x \mid x \neq \frac{\pi}{2} + k\pi, k \in \mathbb{Z}\right\}\\)
值域\\(\mathbb{R}\\)
周期\\(T = \pi\\)
奇偶性奇函数
单调性增区间：\\(\left(-\frac{\pi}{2} + k\pi, \frac{\pi}{2} + k\pi\right)\\)，\\(k \in \mathbb{Z}\\)

四、函数 \(y = A\sin(\omega x + \varphi)\) 的参数意义

值域为 \\([-A, A]\\)，最大值为 \\(A\\)，最小值为 \\(-A\\)。

参数说明

五、图像变换

由 \\(y = \sin x\\) 变换得到 \\(y = A\sin(\omega x + \varphi)\\)：

• 平移变换（相位变换）：\\(y = \sin x \to y = \sin(x + \varphi)\\)，左加右减，\\(\varphi > 0\\) 左移 \\(|\varphi|\\)，\\(\varphi < 0\\) 右移 \\(|\varphi|\\)。

• 伸缩变换（周期变换）：\\(y = \sin x \to y = \sin(\omega x)\\)，横坐标变为原来的 \\(\frac{1}{\omega}\\) 倍

• 振幅变换：\\(y = \sin x \to y = A\sin x\\)，纵坐标变为原来的 \\(A\\) 倍。

先平移后伸缩与先伸缩后平移，平移量不同。若先伸缩后平移，平移量为 \\(\frac{\varphi}{\omega}\\)。

六、五点法画图

画 \\(y = A\sin(\omega x + \varphi)\\) 在一个周期内的图像，取五个关键点：

令 \\(\omega x + \varphi\\) 分别取 \\(0, \frac{\pi}{2}, \pi, \frac{3\pi}{2}, 2\pi\\)，求出对应的 \\(x\\) 值和 \\(y\\) 值，描点连线。

典型例题

例题1：求周期和最值

题目

求函数 \\(f(x) = 3\sin\left(2x + \frac{\pi}{4}\right)\\) 的周期、最大值、最小值及取最大值时的 \\(x\\) 的集合。

解析

解：

\\(\omega = 2\\)，所以周期 \\(T = \frac{2\pi}{\omega} = \frac{2\pi}{2} = \pi\\)

振幅 \\(A = 3\\)，最大值为 \\(3\\)，最小值为 \\(-3\\)

当 \\(\sin\left(2x + \frac{\pi}{4}\right) = 1\\) 时取最大值，即：

\\(2x + \frac{\pi}{4} = \frac{\pi}{2} + 2k\pi\\)，\\(k \in \mathbb{Z}\\)

\\(2x = \frac{\pi}{2} - \frac{\pi}{4} + 2k\pi = \frac{\pi}{4} + 2k\pi\\)

\\(x = \frac{\pi}{8} + k\pi\\)，\\(k \in \mathbb{Z}\\)

答案

周期 \\(T = \pi\\)，最大值 \\(3\\)，最小值 \\(-3\\)，取最大值时 \\(x = \frac{\pi}{8} + k\pi\\)（\\(k \in \mathbb{Z}\\)）

例题2：图像变换

题目

说明如何由 \\(y = \sin x\\) 的图像得到 \\(y = 2\sin\left(2x - \frac{\pi}{3}\right)\\) 的图像。

解析

解（方法一：先平移后伸缩）：

① 将 \\(y = \sin x\\) 的图像向右平移 \\(\frac{\pi}{3}\\) 个单位，得到 \\(y = \sin\left(x - \frac{\pi}{3}\right)\\)

② 将各点横坐标缩短为原来的 \\(\frac{1}{2}\\)（纵坐标不变），得到 \\(y = \sin\left(2x - \frac{\pi}{3}\right)\\)

③ 将各点纵坐标伸长为原来的 \\(2\\) 倍（横坐标不变），得到 \\(y = 2\sin\left(2x - \frac{\pi}{3}\right)\\)

解（方法二：先伸缩后平移）：

① 将 \\(y = \sin x\\) 各点横坐标缩短为原来的 \\(\frac{1}{2}\\)，得到 \\(y = \sin 2x\\)

② 向右平移 \\(\frac{\pi}{6}\\) 个单位，得到 \\(y = \sin 2\left(x - \frac{\pi}{6}\right) = \sin\left(2x - \frac{\pi}{3}\right)\\)

③ 纵坐标伸长为原来的 \\(2\\) 倍，得到 \\(y = 2\sin\left(2x - \frac{\pi}{3}\right)\\)

答案

方法一（先平移后伸缩）：右移 \\(\frac{\pi}{3}\\) → 横坐标缩为 \\(\frac{1}{2}\\) → 纵坐标伸为 \\(2\\) 倍；方法二（先伸缩后平移）：横坐标缩为 \\(\frac{1}{2}\\) → 右移 \\(\frac{\pi}{6}\\) → 纵坐标伸为 \\(2\\) 倍

例题3：由图像求解析式

题目

已知函数 \\(y = A\sin(\omega x + \varphi)\\)（\\(A > 0, \omega > 0, 0 < \varphi < \pi\\)）的图像最高点为 \\(\left(\frac{\pi}{6}, 2\right)\\)，由该点到相邻最低点时图像与 \\(x\\) 轴交于点 \\(\left(\frac{2\pi}{3}, 0\right)\\)，求该函数的解析式。

解析

解：

由最高点纵坐标为 \\(2\\)，得 \\(A = 2\\)。

从最高点到与 \\(x\\) 轴交点，经过 \\(\frac{1}{4}\\) 周期，即 \\(\frac{T}{4} = \frac{2\pi}{3} - \frac{\pi}{6} = \frac{\pi}{2}\\)，所以 \\(T = 2\pi\\)，\\(\omega = \frac{2\pi}{T} = 1\\)。

当 \\(x = \frac{\pi}{6}\\) 时取最大值，即 \\(\sin\left(\frac{\pi}{6} + \varphi\right) = 1\\)，所以 \\(\frac{\pi}{6} + \varphi = \frac{\pi}{2} + 2k\pi\\)。

\\(\varphi = \frac{\pi}{2} - \frac{\pi}{6} = \frac{\pi}{3}\\)（满足 \\(0 < \varphi < \pi\\)）

所以 \\(y = 2\sin\left(x + \frac{\pi}{3}\right)\\)

答案

\\(y = 2\sin\left(x + \frac{\pi}{3}\right)\\)

例题4：周期公式 T = 2π/ω 的推导（推导型）

题目

设 \\(\omega > 0\\)，试由周期函数的定义推导函数 \\(y = \sin(\omega x + \varphi)\\) 的最小正周期 \\(T = \dfrac{2\pi}{\omega}\\)。

解析

推导：

设 \\(f(x) = \sin(\omega x + \varphi)\\)。若存在非零常数 \\(T\\) 使 \\(f(x+T) = f(x)\\) 对一切 \\(x\\) 成立，则：

\\(\sin(\omega(x+T) + \varphi) = \sin(\omega x + \varphi)\\)

即 \\(\sin((\omega x + \varphi) + \omega T) = \sin(\omega x + \varphi)\\)

由正弦函数的周期为 \\(2\pi\\)，需 \\(\omega T = 2k\pi\\)（\\(k \in \mathbb{Z}\\)），即 \\(T = \dfrac{2k\pi}{\omega}\\)。

取最小正周期对应 \\(k = 1\\)，故 \\(T = \dfrac{2\pi}{\omega}\\)。

特别地，当 \\(\omega = 1\\) 时 \\(T = 2\pi\\)，即 \\(y = \sin x\\) 的周期；当 \\(\omega = 2\\) 时 \\(T = \pi\\)。

答案

由 \\(\omega T = 2k\pi\\) 取 \\(k=1\\) 得最小正周期 \\(T = \frac{2\pi}{\omega}\\)，得证

例题5：变换顺序中的平移量陷阱（易错型）

题目

说明如何由 \\(y = \sin x\\) 的图像得到 \\(y = \sin\left(2x + \dfrac{\pi}{3}\right)\\) 的图像。下面给出一种解法，请判断正误并纠正。

解析

常见错误解：

① 将 \\(y = \sin x\\) 各点横坐标缩短为原来的 \\(\dfrac{1}{2}\\)，得到 \\(y = \sin 2x\\)；

② 再向左平移 \\(\dfrac{\pi}{3}\\) 个单位，得到 \\(y = \sin\left(2\left(x + \dfrac{\pi}{3}\right)\right) = \sin\left(2x + \dfrac{2\pi}{3}\right)\\)。

这是错误的！原因：先伸缩后平移时，平移是针对自变量 \\(x\\) 进行的，应平移 \\(\dfrac{\varphi}{\omega}\\) 而非 \\(\varphi\\)。这里平移了 \\(\dfrac{\pi}{3}\\)（即 \\(\varphi\\)），导致相位多出 \\(\omega\\) 倍，得到 \\(2x + \dfrac{2\pi}{3}\\) 而非 \\(2x + \dfrac{\pi}{3}\\)。

正确解（先伸缩后平移）：

① 横坐标缩短为原来的 \\(\dfrac{1}{2}\\)：\\(y = \sin x \to y = \sin 2x\\)

② 向左平移 \\(\dfrac{\pi}{6}\\) 个单位（即 \\(\dfrac{\varphi}{\omega} = \dfrac{\pi/3}{2} = \dfrac{\pi}{6}\\)）：

\\(y = \sin 2\left(x + \dfrac{\pi}{6}\right) = \sin\left(2x + \dfrac{\pi}{3}\right)\\)

反思：先平移后伸缩，平移量为 \\(|\varphi|\\)；先伸缩后平移，平移量为 \\(\left|\dfrac{\varphi}{\omega}\right|\\)。二者不可混淆。

答案

原解法错误。应横坐标缩为 \\(\frac{1}{2}\\) 后，再左移 \\(\frac{\pi}{6}\\)（即 \\(\frac{\varphi}{\omega} = \frac{\pi/3}{2}\\)），得 \\(y = \sin\left(2x + \frac{\pi}{3}\right)\\)

向左平移 \\(\frac{\pi}{6}\\)：\\(y = \sin\left(x + \frac{\pi}{6}\right)\\)；纵坐标变为 \\(3\\) 倍：\\(y = 3\sin\left(x + \frac{\pi}{6}\right)\\)。
