六、共线向量定理（坐标形式）

推导过程（共线条件 \\(x_1 y_2 - x_2 y_1 = 0\\)）：

设 \\(\boldsymbol{a} = (x_1, y_1)\\)，\\(\boldsymbol{b} = (x_2, y_2) \neq \boldsymbol{0}\\)。

① 必要性（\\(\boldsymbol{a} \parallel \boldsymbol{b} \Rightarrow x_1 y_2 - x_2 y_1 = 0\\)）：若 \\(\boldsymbol{a} \parallel \boldsymbol{b}\\)，则存在实数 \\(\lambda\\) 使 \\(\boldsymbol{a} = \lambda\boldsymbol{b}\\)，即 \\((x_1, y_1) = (\lambda x_2, \lambda y_2)\\)。所以 \\(x_1 = \lambda x_2\\)，\\(y_1 = \lambda y_2\\)，两式分别乘以 \\(y_2\\)、\\(x_2\\) 后相减：

$$x_1 y_2 - x_2 y_1 = \lambda x_2 y_2 - \lambda x_2 y_2 = 0$$

② 充分性（\\(x_1 y_2 - x_2 y_1 = 0 \Rightarrow \boldsymbol{a} \parallel \boldsymbol{b}\\)）：因 \\(\boldsymbol{b} \neq \boldsymbol{0}\\)，不妨设 \\(x_2 \neq 0\\)（若 \\(x_2 = 0\\) 则 \\(y_2 \neq 0\\)，同理可证）。取 \\(\lambda = \dfrac{x_1}{x_2}\\)，则 \\(x_1 = \lambda x_2\\)；由 \\(x_1 y_2 - x_2 y_1 = 0\\) 得 \\(y_1 = \dfrac{x_1 y_2}{x_2} = \lambda y_2\\)，故 \\(\boldsymbol{a} = \lambda\boldsymbol{b}\\)，即 \\(\boldsymbol{a} \parallel \boldsymbol{b}\\)。

关键思想：把"向量共线"翻译为"坐标成比例 \\(\dfrac{x_1}{x_2} = \dfrac{y_1}{y_2}\\)"。为避免分母为零的讨论，交叉相乘改写为 \\(x_1 y_2 - x_2 y_1 = 0\\)，这正是二维叉积（行列式）为零的几何意义——两向量张成的平行四边形面积为零。

共线条件

共线条件 \\(x_1 y_2 - x_2 y_1 = 0\\) 是充要条件。注意此条件也包含了 \\(\boldsymbol{a} = \boldsymbol{0}\\) 的情况。

典型例题

例题1：坐标运算

题目

已知 \\(\boldsymbol{a} = (2, 3)\\)，\\(\boldsymbol{b} = (-1, 4)\\)，求 \\(\boldsymbol{a} + \boldsymbol{b}\\)、\\(\boldsymbol{a} - \boldsymbol{b}\\) 和 \\(2\boldsymbol{a} - 3\boldsymbol{b}\\)。

解析

解：

\\(\boldsymbol{a} + \boldsymbol{b} = (2 + (-1), 3 + 4) = (1, 7)\\)

\\(\boldsymbol{a} - \boldsymbol{b} = (2 - (-1), 3 - 4) = (3, -1)\\)

\\(2\boldsymbol{a} - 3\boldsymbol{b} = 2(2, 3) - 3(-1, 4) = (4, 6) - (-3, 12) = (4+3, 6-12) = (7, -6)\\)

答案

\\(\boldsymbol{a}+\boldsymbol{b}=(1,7)\\)，\\(\boldsymbol{a}-\boldsymbol{b}=(3,-1)\\)，\\(2\boldsymbol{a}-3\boldsymbol{b}=(7,-6)\\)

例题2：判断共线

题目

已知 \\(\boldsymbol{a} = (3, 6)\\)，\\(\boldsymbol{b} = (1, 2)\\)，判断 \\(\boldsymbol{a}\\) 与 \\(\boldsymbol{b}\\) 是否共线。若共线，求 \\(\boldsymbol{a} = \lambda\boldsymbol{b}\\) 中的 \\(\lambda\\)。

解析

解：

由共线条件：\\(x_1 y_2 - x_2 y_1 = 3 \times 2 - 1 \times 6 = 6 - 6 = 0\\)

所以 \\(\boldsymbol{a}\\) 与 \\(\boldsymbol{b}\\) 共线。

设 \\(\boldsymbol{a} = \lambda\boldsymbol{b}\\)，即 \\((3, 6) = \lambda(1, 2) = (\lambda, 2\lambda)\\)

所以 \\(\lambda = 3\\)（且 \\(2\lambda = 6\\)，一致）

答案

\\(\boldsymbol{a}\\) 与 \\(\boldsymbol{b}\\) 共线，\\(\lambda = 3\\)

例题3：求坐标

题目

已知点 \\(A(1, 2)\\)，\\(B(3, -2)\\)，点 \\(P\\) 满足 \\(\overrightarrow{AP} = 2\overrightarrow{PB}\\)，求点 \\(P\\) 的坐标。

解析

解：

设 \\(P(x, y)\\)，则 \\(\overrightarrow{AP} = (x - 1, y - 2)\\)，\\(\overrightarrow{PB} = (3 - x, -2 - y)\\)

由 \\(\overrightarrow{AP} = 2\overrightarrow{PB}\\)：

\\((x - 1, y - 2) = 2(3 - x, -2 - y)\\)

即：\\(x - 1 = 2(3 - x) = 6 - 2x\\)，解得 \\(3x = 7\\)，\\(x = \frac{7}{3}\\)

\\(y - 2 = 2(-2 - y) = -4 - 2y\\)，解得 \\(3y = -2\\)，\\(y = -\frac{2}{3}\\)

所以 \\(P\left(\frac{7}{3}, -\frac{2}{3}\right)\\)

答案

\\(P\left(\frac{7}{3}, -\frac{2}{3}\right)\\)

基础

\\(\boldsymbol{a} + 2\boldsymbol{b} = (1, -2) + 2(3, 5) = (1, -2) + (6, 10) = (7, 8)\\)

2
基础
已知 \\(A(2, 1)\\)，\\(B(-1, 3)\\)，求 \\(\overrightarrow{AB}\\) 和 \\(|\overrightarrow{AB}|\\)。

\\(\overrightarrow{AB} = (-1-2, 3-1) = (-3, 2)\\)，\\(|\overrightarrow{AB}| = \sqrt{(-3)^2+2^2} = \sqrt{9+4} = \sqrt{13}\\)

3
中等
判断向量 \\(\boldsymbol{a} = (2, 4)\\) 与 \\(\boldsymbol{b} = (-1, -2)\\) 是否共线。

\\(x_1 y_2 - x_2 y_1 = 2 \times (-2) - (-1) \times 4 = -4 + 4 = 0\\)，所以 \\(\boldsymbol{a}\\) 与 \\(\boldsymbol{b}\\) 共线。

4
中等
已知点 \\(A(-2, 3)\\)，\\(B(4, -1)\\)，求线段 \\(AB\\) 的中点 \\(M\\) 的坐标。

\\(M = \left(\frac{-2+4}{2}, \frac{3+(-1)}{2}\right) = (1, 1)\\)

5
进阶
已知 \\(\boldsymbol{a} = (2, 1)\\)，\\(\boldsymbol{b} = (m, 3)\\)，若 \\(\boldsymbol{a} \parallel \boldsymbol{b}\\)，求 \\(m\\) 的值。

由共线条件：\\(2 \times 3 - m \times 1 = 0\\)，\\(6 - m = 0\\)，\\(m = 6\\)。
