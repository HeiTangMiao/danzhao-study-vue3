学习目标

  • 掌握三角形面积公式，能求三角形的面积
  • 理解解三角形的四类基本场景，能选择合适的方法求解
  • 能运用正弦定理和余弦定理解决实际测量问题
  • 能综合运用三角公式解决解三角形的综合问题

一、三角形面积公式

其他面积公式：

• \\(S = \frac{1}{2} \times \text{底} \times \text{高}\\)

• \\(S = \frac{abc}{4R}\\)（\\(R\\) 为外接圆半径）

• \\(S = \sqrt{p(p-a)(p-b)(p-c)}\\)（海伦公式，\\(p = \frac{a+b+c}{2}\\)）

二、解三角形的四类场景

类型已知条件使用定理解的情况
SSA两边及对角正弦定理可能一解、两解或无解
SAS两边及夹角余弦定理唯一解
SSS三边余弦定理唯一解（需满足三角形不等式）
ASA/AAS两角及一边正弦定理唯一解

三、SSA情况解的判断

已知 \\(a\\)、\\(b\\)、\\(A\\)（\\(A\\) 为锐角）：

• 当 \\(a < b\sin A\\) 时，无解

• 当 \\(a = b\sin A\\) 时，一解（直角三角形）

• 当 \\(b\sin A < a < b\\) 时，两解

• 当 \\(a \geq b\\) 时，一解

当 \\(A\\) 为钝角或直角时，只有当 \\(a > b\\) 时有一解，否则无解。

四、实际应用中的常见模型

• 测量距离：两点间不可直达时，构造三角形利用正弦或余弦定理

• 测量高度：利用仰角和俯角，构造直角三角形或一般三角形

• 测量角度：利用方位角、方向角，构造三角形求解

• 航海问题：利用航行方向和速度构造三角形

典型例题

例题1：求面积

题目

在 \\(\triangle ABC\\) 中，已知 \\(a = 6\\)，\\(b = 8\\)，\\(C = 60°\\)，求三角形的面积 \\(S\\)。

解析

解：

由面积公式 \\(S = \frac{1}{2}ab\sin C\\)：

\\(S = \frac{1}{2} \times 6 \times 8 \times \sin 60° = \frac{1}{2} \times 48 \times \frac{\sqrt{3}}{2} = 12\sqrt{3}\\)

答案

答案：\\(S = 12\sqrt{3}\\)。

例题2：实际测量问题

题目

如图，为测量河对岸 \\(A\\)、\\(B\\) 两点间的距离，在河岸边选取两点 \\(C\\)、\\(D\\)，测得 \\(CD = 100\\) m，\\(\angle ACD = 60°\\)，\\(\angle BCD = 30°\\)，\\(\angle ADC = 45°\\)，\\(\angle BDC = 75°\\)。求 \\(A\\)、\\(B\\) 两点间的距离。

示意图：\\(C\\)、\\(D\\) 为河岸测量点，\\(A\\)、\\(B\\) 为河对岸目标点，基线 \\(CD = 100\\) m。

解析

解：

在 \\(\triangle ACD\\) 中：

\\(\angle CAD = 180° - 60° - 45° = 75°\\)

由正弦定理：\\(\frac{AC}{\sin 45°} = \frac{CD}{\sin 75°}\\)

\\(AC = \frac{100\sin 45°}{\sin 75°} = \frac{100 \times \frac{\sqrt{2}}{2}}{\frac{\sqrt{6}+\sqrt{2}}{4}} = \frac{50\sqrt{2} \times 4}{\sqrt{6}+\sqrt{2}} = \frac{200\sqrt{2}}{\sqrt{6}+\sqrt{2}}\\)

分母有理化：\\(\frac{200\sqrt{2}(\sqrt{6}-\sqrt{2})}{6-2} = \frac{200\sqrt{2}(\sqrt{6}-\sqrt{2})}{4} = 50\sqrt{2}(\sqrt{6}-\sqrt{2}) = 50(2\sqrt{3}-2) = 100(\sqrt{3}-1)\\)

在 \\(\triangle BCD\\) 中：

\\(\angle CBD = 180° - 30° - 75° = 75°\\)

由正弦定理：\\(\frac{BC}{\sin 75°} = \frac{CD}{\sin 75°}\\)，所以 \\(BC = CD = 100\\) m

在 \\(\triangle ABC\\) 中，\\(\angle ACB = \angle ACD - \angle BCD = 60° - 30° = 30°\\)

由余弦定理：

\\(AB^2 = AC^2 + BC^2 - 2 \cdot AC \cdot BC \cdot \cos 30°\\)

\\(= [100(\sqrt{3}-1)]^2 + 100^2 - 2 \times 100(\sqrt{3}-1) \times 100 \times \frac{\sqrt{3}}{2}\\)

\\(= 10000(4-2\sqrt{3}) + 10000 - 10000\sqrt{3}(\sqrt{3}-1)\\)

\\(= 10000(4-2\sqrt{3}) + 10000 - 10000(3-\sqrt{3})\\)

\\(= 10000(4-2\sqrt{3}+1-3+\sqrt{3}) = 10000(2-\sqrt{3})\\)

\\(AB = 100\sqrt{2-\sqrt{3}} \approx 100 \times 0.5176 \approx 51.76\\) m

答案

答案：\\(AB = 100\sqrt{2-\sqrt{3}} \approx 51.76\\) m。

例题3：综合应用

题目

在 \\(\triangle ABC\\) 中，\\(a + b = 10\\)，\\(C = 60°\\)，求 \\(\triangle ABC\\) 面积的最大值。

解析

解：

面积 \\(S = \frac{1}{2}ab\sin C = \frac{1}{2}ab\sin 60° = \frac{\sqrt{3}}{4}ab\\)

要使面积最大，需要 \\(ab\\) 最大。

由 \\(a + b = 10\\)，根据基本不等式 \\(ab \leq \left(\frac{a+b}{2}\right)^2 = 25\\)，当且仅当 \\(a = b = 5\\) 时取等号。

所以 \\(ab\\) 的最大值为 \\(25\\)。

\\(S_{\max} = \frac{\sqrt{3}}{4} \times 25 = \frac{25\sqrt{3}}{4}\\)

答案

答案：面积最大值为 \\(\frac{25\sqrt{3}}{4}\\)，当 \\(a = b = 5\\) 时取得。

例题4：推导面积公式 S = abc/(4R)

题目

在 \\(\triangle ABC\\) 中，\\(a\\)、\\(b\\)、\\(c\\) 为三边，\\(R\\) 为外接圆半径，证明：\\(S = \dfrac{abc}{4R}\\)。

解析

证明：把正弦定理与面积公式结合起来。

由正弦定理 \\(\dfrac{a}{\sin A} = 2R\\)，可得 \\(\sin A = \dfrac{a}{2R}\\)。

由三角形面积公式 \\(S = \dfrac{1}{2}bc\sin A\\)，

代入 \\(\sin A\\)：\\(S = \dfrac{1}{2}bc \cdot \dfrac{a}{2R} = \dfrac{abc}{4R}\\)。

故 \\(S = \dfrac{abc}{4R}\\)，得证。

答案

答案：\\(S = \dfrac{abc}{4R}\\) 得证。

例题5：解三角形漏解（易错题）

题目

在 \\(\triangle ABC\\) 中，已知 \\(b = 3\\)，\\(c = 3\sqrt{3}\\)，\\(B = 30°\\)，求角 \\(C\\) 和边 \\(a\\)。

解析

常见错误：由正弦定理 \\(\sin C = \dfrac{c\sin B}{b} = \dfrac{3\sqrt{3} \times \frac{1}{2}}{3} = \dfrac{\sqrt{3}}{2}\\)，直接得 \\(C = 60°\\)，再算 \\(A = 90°\\)，\\(a = \dfrac{b\sin A}{\sin B} = 6\\)。

错误分析：\\(\sin C = \dfrac{\sqrt{3}}{2}\\) 时，\\(C\\) 可为 \\(60°\\) 或 \\(120°\\)。题中 \\(c = 3\sqrt{3} > b = 3\\)，故 \\(C > B = 30°\\)，两种情况均可能，不能只取一解。

正确解法：由 \\(\sin C = \dfrac{\sqrt{3}}{2}\\)，得 \\(C = 60°\\) 或 \\(C = 120°\\)。

当 \\(C = 60°\\) 时，\\(A = 180° - 30° - 60° = 90°\\)，由正弦定理 \\(a = \dfrac{b\sin A}{\sin B} = \dfrac{3 \times 1}{\frac{1}{2}} = 6\\)；

当 \\(C = 120°\\) 时，\\(A = 180° - 30° - 120° = 30°\\)，由正弦定理 \\(a = \dfrac{b\sin A}{\sin B} = \dfrac{3 \times \frac{1}{2}}{\frac{1}{2}} = 3\\)。

故 \\(C = 60°, a = 6\\) 或 \\(C = 120°, a = 3\\)。

答案

答案：\\(C = 60°, a = 6\\) 或 \\(C = 120°, a = 3\\)（SSA 情况有两解）。

练习题

1
基础
在 \\(\triangle ABC\\) 中，\\(a = 3\\)，\\(b = 4\\)，\\(C = 45°\\)，求三角形的面积。

\\(S = \frac{1}{2}ab\sin C = \frac{1}{2} \times 3 \times 4 \times \sin 45° = 6 \times \frac{\sqrt{2}}{2} = 3\sqrt{2}\\)

2
基础
在 \\(\triangle ABC\\) 中，已知 \\(a = 2\\)，\\(b = 2\sqrt{2}\\)，\\(A = 30°\\)，求 \\(B\\) 和面积 \\(S\\)。

\\(\sin B = \frac{b\sin A}{a} = \frac{2\sqrt{2}\times\frac{1}{2}}{2} = \frac{\sqrt{2}}{2}\\)，\\(B = 45°\\) 或 \\(135°\\)。当 \\(B=45°\\) 时，\\(C=105°\\)；当 \\(B=135°\\) 时，\\(C=15°\\)。若 \\(B=45°\\)，\\(S=\frac{1}{2}ab\sin C=\frac{1}{2}\times 2\times 2\sqrt{2}\times\sin 105°=2\sqrt{2}\times\frac{\sqrt{6}+\sqrt{2}}{4}=\frac{2\sqrt{12}+2\sqrt{4}}{4}=\sqrt{3}+1\\)。

3
中等
某人在 \\(A\\) 处测得塔顶 \\(C\\) 的仰角为 \\(30°\\)，向塔方向前进 \\(100\\) m 到 \\(B\\) 处，测得仰角为 \\(60°\\)，求塔高。

设塔高为 \\(h\\)。在 \\(A\\) 处，到塔底距离为 \\(\frac{h}{\tan 30°} = \sqrt{3}h\\)；在 \\(B\\) 处，距离为 \\(\frac{h}{\tan 60°} = \frac{h}{\sqrt{3}}\\)。\\(\sqrt{3}h - \frac{h}{\sqrt{3}} = 100\\)，\\(\frac{3h-h}{\sqrt{3}} = 100\\)，\\(\frac{2h}{\sqrt{3}} = 100\\)，\\(h = 50\sqrt{3}\\) m。

4
中等
在 \\(\triangle ABC\\) 中，\\(a = 5\\)，\\(b = 3\\)，\\(\sin A = \frac{5}{6}\\)，求 \\(\sin B\\) 的值。

由正弦定理：\\(\sin B = \frac{b\sin A}{a} = \frac{3 \times \frac{5}{6}}{5} = \frac{\frac{15}{6}}{5} = \frac{15}{30} = \frac{1}{2}\\)

5
进阶
在 \\(\triangle ABC\\) 中，\\(a\cos B = b\cos A\\)，判断三角形形状。

由正弦定理 \\(a = 2R\sin A, b = 2R\sin B\\) 代入：\\(2R\sin A\cos B = 2R\sin B\cos A\\)，即 \\(\sin A\cos B - \sin B\cos A = 0\\)，\\(\sin(A-B) = 0\\)。因为 \\(A, B \in (0, \pi)\\)，所以 \\(A - B = 0\\)，即 \\(A = B\\)。三角形为等腰三角形。
