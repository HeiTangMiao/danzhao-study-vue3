学习目标

  • 区分语法错误、运行错误与逻辑错误
  • 掌握基本的程序调试方法（阅读、print 输出、逐行检查）
  • 能找出典型程序（累加、累乘、求最值、素数、数字分离、排序）中的错误并修改
  • 养成规范书写、及时测试的编程习惯

三类错误

语法错误：违反语言规则，程序无法运行。如缺少冒号、括号不匹配、缩进错误、拼写错误。

运行错误：程序能运行但执行时报错。如字符串与数字相加、除数为 0、变量未定义。

逻辑错误：程序能运行不报错，但结果不对。如累乘器初始化为 0、range 边界写错、判断条件写反。

考试要求：能找出典型程序的错误之处并加以修改，这是程序设计模块的重要考点。

逻辑错误最隐蔽！程序不报错但结果错误，必须通过运行测试、对比预期结果才能发现。考试中写完程序一定要运行验证结果是否正确。

调试方法

阅读代码：逐行阅读，检查语法、缩进、变量名、运算符是否书写正确。

print 输出中间值：在关键位置输出中间变量的值，定位出错位置。

逐行检查：用纸笔模拟程序执行，跟踪每个变量的变化，判断逻辑是否正确。

运行测试：用多组数据测试，包括边界值（如 0、最大值、负数），验证程序健壮性。

调试口诀："先看语法，再查逻辑；print 定位，边界测试"。遇到结果不对，先在循环前后加 print 看中间值。

典型例题

例题1：找错误并修改

题目

下列程序想计算 1 到 10 的累加和，但结果不对，请找出错误并修改。

sum = 1
for i in range(1, 11):
    sum += i
print(sum)

解析

解：
错误：累加器初始化为 1，导致结果多加了 1。
正确代码：

sum = 0
for i in range(1, 11):
    sum += i
print(sum)   # 输出 55

答案

累加器应初始化为 0，修改为 sum = 0。

例题2：找错误并修改

题目

下列程序想判断一个数是否为素数，但结果错误，请找出错误并修改。

n = int(input("请输入："))
for i in range(2, n):
    if n % i == 0:
        print(n, "不是素数")
    else:
        print(n, "是素数")

解析

解：
错误：在循环内直接输出结论，只要有一个 i 不能整除就输出"是素数"，判断不完整。
正确代码：

n = int(input("请输入："))
is_prime = True
for i in range(2, n):
    if n % i == 0:
        is_prime = False
        break
if is_prime and n > 1:
    print(n, "是素数")
else:
    print(n, "不是素数")

答案

用标志变量 is_prime 记录，循环结束后统一判断，而不是在循环内直接输出。

基础
下列错误中，属于语法错误的是（　）

答案：B。缺少冒号导致程序无法运行，是语法错误；结果不对是逻辑错误，除数为 0 是运行错误。

2
基础
程序能运行但不报错，结果却不对，这属于（　）

答案：C。逻辑错误是程序能运行但结果不符合预期。

3
中等
下列代码中，有错误的是（　） `` a = int(input("请输入：")) if a % 2 == 0: print("偶数") else print("奇数") ``

答案：B。else 后面必须加冒号，缺少冒号是语法错误。

中等
在程序中添加 print 输出中间值，可以帮助定位逻辑错误。

正确。print 输出中间变量是常用的调试方法。
