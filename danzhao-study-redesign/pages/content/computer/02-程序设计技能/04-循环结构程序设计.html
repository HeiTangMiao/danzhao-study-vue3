学习目标

  • 理解循环结构的执行流程：重复执行一段代码直到条件不满足
  • 掌握 for 循环与 range() 函数的用法
  • 掌握 while 循环与计数器的用法
  • 掌握 break、continue 与循环嵌套，能编写累加求和等典型程序

for 循环

for 循环：for 变量 in 序列: 依次取出序列中的每个元素执行循环体。

range 函数：range(n) 生成 0~n-1；range(开始, 结束) 生成开始~结束-1；range(开始, 结束, 步长) 按步长生成。

示例：

for i in range(1, 6):
    print(i)   # 输出 1 2 3 4 5

注意：range(1, 6) 包含 1 不包含 6，即左闭右开。

range 是左闭右开！range(1, 101) 表示 1 到 100，不包含 101。求 1 到 100 的和必须写 range(1, 101)，写 range(1, 100) 会少加 100。

while 循环

while 循环：while 条件: 条件成立就执行循环体，直到条件不成立。

计数器：while 循环通常需要计数器控制次数，如 i = 1，循环内 i += 1。

示例：

i = 1
while i <= 5:
    print(i)
    i += 1   # 计数器自增，防止死循环

死循环：如果条件永远成立且没有改变条件的语句，程序会无限循环，考试中要避免。

循环控制与嵌套

break：立即跳出整个循环，不再执行剩余循环。

continue：跳过本次循环的剩余语句，直接进入下一次循环。

循环嵌套：循环体里再写循环，外层每执行一次，内层完整执行一遍。

示例（乘法表）：

for i in range(1, 10):
    for j in range(1, i + 1):
        print(j, "*", i, "=", i * j, end="  ")
    print()
累加器模式是考试核心：先 sum = 0 初始化，循环内 sum += i 累加，循环结束后输出 sum。累乘器同理：先 product = 1，循环内 product *= i。

典型例题

例题1：累加求和（考试样题三）

题目

请计算 1 到 100 的所有整数之和，并输出结果。要求：代码有注释，保存到"考生文件夹\程序设计\试题三"。

解析

解：

# 试题三：计算 1 到 100 的和
# 初始化累加器
sum = 0
# 循环 1 到 100
for i in range(1, 101):
    sum += i   # 累加
# 输出结果
print("1 到 100 的和是：", sum)

运行结果：
1 到 100 的和是： 5050

答案

sum = 0 初始化，for i in range(1, 101) 循环，sum += i 累加，输出 5050。

例题2：while 循环累加

题目

用 while 循环计算 1 到 100 的所有整数之和。

解析

解：

# 用 while 计算 1 到 100 的和
sum = 0
i = 1
while i <= 100:
    sum += i
    i += 1   # 计数器自增
print("1 到 100 的和是：", sum)

运行结果：
1 到 100 的和是： 5050

答案

计数器 i 从 1 开始，while i <= 100 循环累加，循环内 i += 1 防止死循环。

例题3：求 1~100 中偶数的和

题目

计算 1 到 100 中所有偶数的和，并输出结果。

解析

解：
方法一（步长法）：

sum = 0
for i in range(2, 101, 2):
    sum += i
print("偶数和是：", sum)

方法二（判断法）：

sum = 0
for i in range(1, 101):
    if i % 2 == 0:
        sum += i
print("偶数和是：", sum)

运行结果：
偶数和是： 2550

答案

方法一用 range(2, 101, 2) 直接取偶数；方法二用 i % 2 == 0 判断后累加。

基础

答案：B。range(1, 101) 生成 1 到 100 共 100 个数。

3
中等
执行以下代码，输出结果是（　） `` sum = 0 for i in range(1, 5): sum += i print(sum) ``

答案：A。累加 1+2+3+4 = 10。

4
中等
在 while 循环中，防止死循环的关键是（　）

答案：B。循环内必须有改变条件（如计数器自增）的语句，否则条件永远成立形成死循环。
