一、判断题（每题 3 分，共 30 分）

1
基础
Python 变量名可以以数字开头。

错误。变量名不能以数字开头。

2
基础
input() 函数返回的数据类型一定是字符串。

正确。input() 返回字符串，需要时用 int() 或 float() 转换。

3
基础
7 // 2 的结果是 3.5。

错误。// 是整除，7 // 2 结果是 3；7 / 2 才是 3.5。

4
中等
range(1, 101) 表示 1 到 100 的整数序列。

正确。range 左闭右开，包含 1 不包含 101。

5
中等
累乘器求阶乘时应初始化为 0。

错误。累乘器应初始化为 1，初始化为 0 结果恒为 0。

6
中等
判断两个数是否相等应使用 = 运算符。

错误。= 是赋值，判断相等用 ==。

7
中等
在 while 循环中，循环体内必须有改变条件的语句，否则会形成死循环。

正确。否则条件永远成立，程序无限循环。

8
进阶
"abc".upper() 会改变原字符串的值。

错误。字符串是不可变的，upper() 返回新字符串，原字符串不变。

9
进阶
冒泡排序 n 个元素需要 n-1 轮。

正确。每轮确定一个元素位置，n 个元素需要 n-1 轮。

10
进阶
程序能运行但不报错、结果却不对，属于逻辑错误。

正确。逻辑错误是程序可运行但结果不符合预期。

二、单选题（每题 4 分，共 40 分）

1
基础
下列变量名中，合法的是（　）

答案：C。student_name 合法；for 是关键字，2num 以数字开头，my-name 含非法字符。

2
基础
表达式 10 % 3 的结果是（　）

答案：C。10 % 3 的余数是 1。

3
中等
执行 n = 10 后执行 n //= 3，此时 n 的值是（　）

答案：A。n //= 3 等价于 n = n // 3 = 10 // 3 = 3。

4
中等
执行以下代码，输出结果是（　） `` sum = 0 for i in range(1, 6): sum += i print(sum) ``

答案：A。1+2+3+4+5 = 15。

5
中等
数字 789 的百位数字是（　）

答案：A。789 // 100 = 7。

6
中等
执行以下代码，输出结果是（　） `` x = 75 if x >= 90: print("A") elif x >= 80: print("B") elif x >= 60: print("C") else: print("D") ``

答案：C。75 不满足 ≥90、≥80，满足 ≥60，输出 C。

7
进阶
"hello"[0:3] 的结果是（　）

答案：A。切片左闭右开，取下标 0、1、2 的字符 "hel"。

8
进阶
下列代码中，能正确判断 n 是偶数的条件是（　）

答案：B。能被 2 整除（余数为 0）是偶数。

9
进阶
执行以下代码，输出结果是（　） `` for i in range(1, 6): if i % 2 == 0: continue print(i, end=" ") ``

答案：B。i 为偶数时 continue 跳过，只输出奇数 1 3 5。

10
进阶
下列程序想求 1 到 100 中所有偶数的和，正确的是（　）

答案：A。A 用 i % 2 == 0 判断偶数累加，正确；B 用 range(1, 101, 2) 取的是奇数（1、3、5…），求的是奇数和；C 累加器初始化为 1 错误。

四、编程题（共 15 分）

编程题：累加求和

题目

编写程序：输入一个正整数 n，计算 1 到 n 的所有整数之和并输出。要求：输入输出有提示文字，代码有详细注释。

解析

解：

# 计算 1 到 n 的和
n = int(input("请输入一个正整数 n："))
# 初始化累加器
sum = 0
# 循环累加
for i in range(1, n + 1):
    sum += i
# 输出结果
print("1 到", n, "的和是：", sum)

运行示例：
请输入一个正整数 n：10
1 到 10 的和是： 55

答案

sum = 0 初始化，for i in range(1, n + 1) 循环，sum += i 累加后输出。
