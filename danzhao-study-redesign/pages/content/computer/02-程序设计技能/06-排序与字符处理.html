冒泡排序

思想：相邻两个元素比较，如果顺序不对就交换，每一轮把最大（或最小）的元素"冒泡"到最后。

轮数：n 个元素需要 n-1 轮；第 i 轮需要比较 n-i 次。

示例（升序）：

a = [5, 3, 8, 1]
n = len(a)
for i in range(n - 1):
    for j in range(n - 1 - i):
        if a[j] > a[j + 1]:
            a[j], a[j + 1] = a[j + 1], a[j]
print(a)   # 输出 [1, 3, 5, 8]

交换技巧：a[j], a[j+1] = a[j+1], a[j] 一行完成交换。

冒泡排序内层循环范围是 range(n - 1 - i)！因为每完成一轮，末尾就多一个已排好的元素，无需再比较。写成 range(n - 1) 虽然结果正确但效率低，考试阅卷可能扣分。

选择排序

思想：每一轮从未排序部分找出最小值，与未排序部分的第一个元素交换。

示例（升序）：

a = [5, 3, 8, 1]
n = len(a)
for i in range(n - 1):
    min_idx = i
    for j in range(i + 1, n):
        if a[j] < a[min_idx]:
            min_idx = j
    a[i], a[min_idx] = a[min_idx], a[i]
print(a)   # 输出 [1, 3, 5, 8]

与冒泡区别：选择排序每轮只交换一次，冒泡排序可能交换多次。

字符串基本操作

拼接：+ 连接字符串，如 "你" + "好" 结果为 "你好"。

重复：* 重复字符串，如 "ab" * 3 结果为 "ababab"。

索引：s[0] 取第一个字符，s[-1] 取最后一个字符，下标从 0 开始。

切片：s[开始:结束] 截取子串，左闭右开，如 "hello"[1:3] 结果为 "el"。

长度：len(s) 返回字符串长度，如 len("hello") 结果为 5。

字符串常用方法

方法作用示例结果
upper()转大写"abc".upper()"ABC"
lower()转小写"ABC".lower()"abc"
strip()去两端空格" hi ".strip()"hi"
split()按分隔符拆分"a,b,c".split(",")['a','b','c']
count()统计出现次数"hello".count("l")2
find()查找子串位置"hello".find("l")2
字符串是不可变的！s.upper() 返回新字符串，原字符串不变。要保存结果必须赋值，如 s = s.upper()。

典型例题

例题1：冒泡排序

题目

用冒泡排序法将列表 [9, 5, 7, 2, 6] 按升序排列，并输出排序结果。

解析

解：

# 冒泡排序升序
a = [9, 5, 7, 2, 6]
n = len(a)
for i in range(n - 1):
    for j in range(n - 1 - i):
        if a[j] > a[j + 1]:
            a[j], a[j + 1] = a[j + 1], a[j]
print("排序结果：", a)

运行结果：
排序结果： [2, 5, 6, 7, 9]

答案

外层 n-1 轮，内层 n-1-i 次相邻比较，逆序则交换。

例题2：字符串统计

题目

输入一个字符串，统计其中字母 'a' 出现的次数并输出。

解析

解：

s = input("请输入一个字符串：")
count = 0
# 遍历每个字符
for ch in s:
    if ch == "a":
        count += 1
print("字母 a 出现次数：", count)

运行示例：
请输入一个字符串：banana
a 出现次数： 3

答案

遍历字符串，if ch == "a" 计数累加；也可用 s.count("a")。

例题3：字符串反转

题目

输入一个字符串，将其反转后输出。

解析

解：
方法一（切片）：

s = input("请输入字符串：")
print("反转结果：", s[::-1])

方法二（循环）：

s = input("请输入字符串：")
result = ""
for ch in s:
    result = ch + result
print("反转结果：", result)

运行示例：
请输入字符串：abcde
反转结果： edcba

答案

方法一用切片 s[::-1]；方法二循环把每个字符放到结果前面。
