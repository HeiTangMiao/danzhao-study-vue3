学习目标

  • 掌握文件命名的基本规则（主名、扩展名、禁用字符、长度限制）
  • 养成"见名知意"、统一规范的命名习惯
  • 理解文件安全管理要求：权限、备份、防病毒
  • 掌握考试中文件的保存要求与提交前校对方法

文件命名规则

文件名组成：文件名由"主文件名.扩展名"组成，如 report.docx，主名是 report，扩展名是 docx，扩展名决定文件类型。

禁用字符：Windows 文件名中不能包含以下字符：\ / : * ? " < > |。

长度限制：Windows 完整路径长度一般不超过 260 个字符，文件名不宜过长。

不区分大小写：Windows 中文件名不区分大小写，但 Linux 中区分。

扩展名作用：扩展名标识文件类型，如 .txt 文本、.docx 文档、.xlsx 表格、.py Python 程序、.jpg 图片、.mp4 视频。

考试中保存文件时，扩展名不能随意更改！例如把 .py 改成 .txt 会导致程序无法运行，把 .psd 改成 .jpg 会导致文件损坏。

命名规范要求

见名知意：文件名应能反映文件内容，如 成绩统计.xlsx 比 新建文档1.xlsx 更规范。

统一格式：同一批文件采用统一的命名格式，如 01-试题一.py、02-试题二.py。

避免特殊字符：不使用空格开头、不连续使用空格，避免使用中文全角符号。

考试命名：考试中常要求以准考证号、题目编号等作为文件名，必须严格按题目要求命名。

文件安全管理

权限管理：合理设置文件访问权限，重要文件设置只读或密码保护，防止被他人修改。

数据备份：重要数据定期备份到其他磁盘、U 盘或云盘，防止磁盘损坏导致数据丢失。

防病毒：定期查杀病毒，不打开来历不明的邮件附件，不随意下载安装软件。

网络安全：不访问非法网站，不下载不明文件，防止木马病毒窃取文件。

考试操作提醒（来自考试说明）：① 考试前新建以准考证号为名称的考生文件夹；② 答题过程中注意及时保存；③ 提交前校对所有文件是否存在；④ 考试结束不得关闭计算机。

快速检测

1
基础
文件名 a/b.txt 在 Windows 中是合法的。

错误。/ 是 Windows 文件名中的禁用字符，不能出现在文件名中。

2
基础
下列文件名中，最规范的是（　）

答案：B。"成绩统计"见名知意，能反映文件内容。

3
中等
考试中保存文件时，扩展名可以随意更改。

错误。扩展名决定文件类型，随意更改会导致文件无法打开或程序无法运行。

典型例题

例题1：判断文件名合法性

题目

判断下列文件名在 Windows 中是否合法，并说明理由：
（1）考试成绩.xlsx
（2）a:b.txt
（3）我的*作业.docx
（4）report_2024.py

解析

解：
（1）合法。主名"考试成绩"、扩展名 xlsx，无禁用字符。
（2）不合法。: 是 Windows 文件名的禁用字符。
（3）不合法。* 是禁用字符。
（4）合法。下划线、数字均可使用，见名知意。

答案

答案：（1）合法；（2）不合法，含冒号；（3）不合法，含星号；（4）合法。

例题2：考试文件保存

题目

考试要求将程序保存到"考生文件夹\程序设计\试题一"文件夹中，文件名按题目要求命名。请写出正确的保存步骤。

解析

解：
① 打开"考生文件夹\程序设计\试题一"文件夹；
② 在代码编辑器中执行"文件→另存为"；
③ 选择目标文件夹，输入规范文件名（如 试题一.py）；
④ 确认扩展名正确后保存；
⑤ 提交前打开文件夹，校对该文件是否存在、内容是否完整。

答案

保存到指定文件夹 → 规范命名 → 确认扩展名 → 保存 → 提交前校对。

基础
Windows 文件名中不能包含的字符是（　）

答案：D。? 是 Windows 文件名禁用字符之一。

2
中等
重要文件应定期备份，防止磁盘损坏导致数据丢失。

正确。数据备份是文件安全管理的重要措施。

3
进阶
考试提交前，下列做法最恰当的是（　）

答案：B。提交前必须校对所有文件是否存在、保存位置是否正确、内容是否完整。
