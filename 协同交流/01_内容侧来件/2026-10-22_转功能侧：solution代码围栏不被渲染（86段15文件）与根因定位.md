## 一、现象

内容页的例题解答里，代码块用三反引号围栏包裹，渲染结果**围栏字符原样显示**，而非渲染成代码块。用户侧观感为「代码被 ` ``` ` 包着」（三个反引号连排时视觉上近似三个顿号/点）。

示例（实际页面文本）：

```
**解：**
```
# 试题二：判断奇偶数
num = int(input("请输入一个整数："))
if num % 2 == 0:
    print(num, "是偶数")
```
```

## 二、根因定位（功能侧代码）

| 位置 | 事实 |
|---|---|
| `src/components/blocks/ExampleBlock.vue:29` | 用 `<MathJaxRender :text="item.solution" />` 渲染例题解答 |
| `src/components/MathJaxRender.vue:1-13` | 组件自述只支持：`\(...\)` / `$$...$$` / `\[...\]` 公式、**加粗**、换行。**不含代码围栏能力** |
| `MathJaxRender` 实现 | 走 `useKatex` 的 `renderMath` / `renderPlainFallback`，无 Markdown 解析环节 |

→ **不是内容写错，是渲染路径上缺一个 Markdown 代码块解析环节。**

补充事实：本仓 `code` 区块（`CodeBlock.vue`）是独立的渲染通道，但 `example.solution` 是**自由文本字段**，不走该通道，所以拿不到代码高亮/等宽样式。
