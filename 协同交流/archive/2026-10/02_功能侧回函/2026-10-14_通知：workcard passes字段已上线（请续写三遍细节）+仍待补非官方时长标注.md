### 字段形状

```js
{
  type: 'workcard',
  id: 'ps-idphoto',                    // 建议保留（你方已写的四个 id 不变）
  title: 'PS-1 · 证件照换底色与规格裁剪',
  duration: 360,
  intro: '……（你方已写的总纲，保留不动）',
  passes: [                            // ← 新增，可选
    { key: 'guided',  text: '第一遍的具体步骤……' },
    { key: 'restore', text: '第二遍：只给成品要求，不给步骤……' },
    { key: 'timed',   text: '第三遍的验收标准……' }
  ]
}
```

| 项 | 说明 |
|---|---|
| `key` | 只能是 **`guided` / `restore` / `timed`** 三个值之一，对应「第一遍·对照做 / 第二遍·只看成品还原 / 第三遍·限时独立做」 |
| `text` | 字符串，该遍的步骤或验收标准 |
| 是否必填 | **可选**。不写（或只写其中一两遍）时，未覆盖的那一遍**自动回退**到组件内置描述，不会空白也不会报错 |
| 顺序 | **按 `key` 匹配，与数组顺序无关** —— 乱序写也对位，但建议按三遍顺序写便于阅读 |
| 遍次名字 | 「第X遍 · 名字」是固定骨架，**由组件渲染，你方不需要也不应该写** |

### `text` 该写什么（沿用你方自己定的验收标准）

**写学员可自查的客观物**（文件 / 参数 / 播放结果），不写无法自查的话：

| ✅ 该写 | ❌ 别写 |
|---|---|
| 「按题目给的像素尺寸裁剪，存出 psd 和 jpg 两类文件」 | 「认真做完这一步」 |
| 「导出 mp4 后打开确认能播放」 | 「要做得熟练一点」 |
| 「字幕字体、字号、字距按题设参数逐项核对」 | 「多加练习就会了」 |

### 会被拒的写法（校验由功能侧手写实现，CI 会拦）

- `key` 拼错或写成三个值之外（如 `'guidedx'`）→ **拒绝**
- 同一个 `key` 出现两次 → **拒绝**（两条互相矛盾的文案，组件取哪条属未定义）
- `text` 写成数字或数组而非字符串 → **拒绝**；空串 → **拒绝**

> 你方写完后跑一次 `npm run validate:content` 即可自查，不必等我方。
