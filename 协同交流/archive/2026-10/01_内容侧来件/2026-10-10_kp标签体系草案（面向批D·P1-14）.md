# kp 标签体系草案（内容侧备料 · 面向批 D 的 P1-14 组卷权重）

- **日期**：2026-10-10
- **发出方**：内容侧（教育内容团队）
- **依据**：实施路线图 §3 内容侧依赖表——「**D-3 P1-14**：① 题目侧 `kp` 标签（**先通知功能侧走 schema 白名单 H5，勿直接写入内容文件**）；② 先自由文本、后成字典」，性质标注为「**强依赖**：功能侧先开 schema 白名单 → 内容侧再批量补标」
- **期望**：① 请功能侧就下面的 **A 档 / B 档二选一给出取向**；② 若选 B 档，请先上 schema 白名单并确认字段命名
- **边界**：本文件**只是草案**，内容侧未向任何内容文件写入 `kp` 字段（遵守 H5）

## 一、先给结论：两档方案

| 档 | 方案 | 是否需 schema 白名单 | 内容侧改动量 | 能支撑的能力 |
|----|------|-------------------|------------|-------------|
| **A 档（零成本，推荐先上）** | **不新增字段**：用题目已有的 `fileKey` 派生「页级 kp」 | **不需要** | **0**（构建期即可派生） | 组卷权重（P1-14）、按考点统计掌握度、按考点筛题 |
| **B 档（细粒度，按需）** | 题目条目新增 `kp` 字段，取值来自「考点字典」，粒度到**页内考点** | **需要**（H5 流程） | 171 页 → 出考点字典 + 2000+ 题打标（可自动预标 + 人工复核） | 在 A 档基础上支持「同页内不同考点」的权重与筛选 |

**核心观察**：题库里每道题已经带有 `fileKey`（形如 `math_11_03-椭圆`）与 `fileIndex`，而**当前的内容组织本身就是按考点切页的**——一页 = 一个考点（如「03-椭圆」）。因此 A 档可以直接把 `fileKey` 当 kp 用：

```
kp(题目) := fileKey        // 例：math_11_03-椭圆
```

这样做有三个好处：**零 schema 变更、零内容改动、零漂移风险**（不存在"内容改了标签忘了改"的情况）。

## 三、B 档：若需要页内考点粒度

### 3.1 字段草案（供功能侧参考，最终由白名单定）

```js
// 题目条目级（quiz.items[i] / example.items[i] / exam.items[i]）
{
  difficulty: "basic",
  type: "single",
  question: "…",
  options: [...],
  correctIndex: 1,
  answer: "…",
  kp: "math/11-平面解析几何/03-椭圆/离心率"   // ← 新增（B 档）
}
```

- **形态**：字符串（单个主考点）。若需多考点，建议**不用数组**，而是再补一个 `kpTags?: string[]`（副标签，可空），主 `kp` 保持唯一，便于统计口径不歧义。
- **命名**：`<subject>/<单元文件夹>/<页面文件名>/<页内考点>`，与现有目录结构同构，可被 `fileKey` 校验脚本交叉检查。
- **取值**：必须先由内容侧产出**考点字典**（每页 2-5 条），再逐题打标；未匹配到字典的一律留空（不猜）。

### 3.2 考点字典示例（内容侧可批量产出，先给 3 页样例）

| 页面 | 页内考点（字典候选） |
|------|------------------|
| `math/11-平面解析几何/03-椭圆` | 椭圆定义与标准方程 / 长轴短轴与焦点 / 离心率 / 焦点三角形 |
| `math/09-概率/05-随机变量及其分布` | 分布列性质 / 期望 / 方差 / 期望方差的性质 |
| `computer/03-计算机网络技术/03-交换机配置与VLAN` | VLAN 创建 / 端口划分 / trunk 与 access / 查看与验证命令 |
| `chinese/01-语言文字运用/04-病句修改` | 成分残缺 / 搭配不当 / 语序不当 / 结构混乱 / 表意不明 / 逻辑不当 |

### 3.3 若走 B 档，内容侧的执行计划与工作量

1. **出字典**：171 页 × 2-5 条 ≈ **400-600 条考点**（内容侧可一次产出，作为独立文档交付）；
2. **自动预标**：`kp := 页级主考点`（每题先落到页面主考点，覆盖 100%）；
3. **人工细分**：按块标题/题干关键词把题目细到页内考点（预计 2102 题的 **60-70% 可自动细分**，其余人工）；
4. **校验**：新增校验脚本（内容侧提供口径）——`kp` 必须是字典里的合法值、每页至少有 1 条题带主 kp。

> 工作量提示：B 档是「一次性的中等工程」（约 2-3 个内容批次），建议等 A 档跑起来、确认"按考点组卷"确实需要更细粒度之后再做。
