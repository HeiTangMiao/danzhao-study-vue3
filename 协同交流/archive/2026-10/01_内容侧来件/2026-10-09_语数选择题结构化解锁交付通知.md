- **来件方**：教育内容侧（教育专家团）
- **日期**：2026-10-09
- **背景**：内容侧主动盘点发现「判分率倒挂」的新成因——语文、数学两科大量**选择题**以「选项直接写在题干里」的老格式存储（如 `……正确的是（　）\nA. xx　B. yy　C. zz　D. ww`），因缺少结构化的 `options` / `correctIndex`，学生**点不了、判不了分、进不了错题本**。本批完成 213 道现成题目的结构化改造（题目与答案内容**未改动**）。
- **期望**：请功能侧知悉并安排入库（沿用代提交模式）；无技术阻塞可不回函。
- **边界**：**纯题目形态改造**（既有页面内）——仅把题干尾部内嵌的选项拆出为 `options` 数组、补 `correctIndex` 与 `type: "single"`；不改题目文字、不改答案、不改块结构、不改 `site.js`。
- **验收**：`npm run validate:content` 全绿（162 文件）；题库重建后逐页可判分验证通过。

## 2. 改造方式（零内容改动）

```js
// 改造前（选项内嵌题干，不可判分）
{ difficulty: "basic",
  question: "记叙文的六要素中，居于核心地位的是（　）\nA. 时间和地点　B. 人物和起因　C. 经过　D. 结果",
  answer: "答案：C。……" }

// 改造后（结构化，可判分）
{ difficulty: "basic",
  type: "single",
  question: "记叙文的六要素中，居于核心地位的是（　）",
  options: ["A. 时间和地点", "B. 人物和起因", "C. 经过", "D. 结果"],
  correctIndex: 2,
  answer: "答案：C。……" }
```

- 正确项从既有答案（「答案：C。」）解析，**与原文一致**；
- 全程 dry-run 预演（213 道 100% 解析成功）+ 文件级复核；
- 题库 key 为位置型（unit/file/block/item），**不受文本变化影响**；产物（题库 + 搜索索引）均已重建。

## 3. 附带修复（1 处内容缺陷）

`chinese/01-语言文字运用/04-病句修改.js`「例题3：句式杂糅辨析」原题问「没有语病的一项」，但四个选项**全部**为句式杂糅、无正确选项（解析中自述"本题无正确选项"）。已修正：将 D 项改为规范表述（"学校以德育为中心……"），解析与答案同步更新（答案：D）。
