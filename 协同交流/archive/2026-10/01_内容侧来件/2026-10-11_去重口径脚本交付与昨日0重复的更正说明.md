漏掉的是这一类：

> **题干完全相同、正确选项完全相同，只有某个干扰项被换掉** —— 多见于「复习测验页 / 真题模拟卷」照抄正课页时顺手改了一个错误选项。学员做第二遍时等于原题重做，但按"题干+选项"口径因为选项有一个不同就漏掉了。

| 口径 | 抓到的 | 漏掉的 |
|------|--------|--------|
| 题干 + 选项（有序） | 昨天那 11 组 | **换过干扰项的照抄题** |
| **题干 + 正确项文本** | 新增 11 组 | 题干被微改的（如加"Premiere 中"） |
| 题干主干 + 正确项（模糊） | 新增 2 组 | — |

**教训**：单一口径一定会漏。所以这次交付的脚本是**三档并列**，而不是挑一个"最严"的。

## 1. 交付物：三档口径检测脚本

**路径**：`danzhao-study-vue3/scripts/check-duplicates.mjs`

**用法**：
```bash
cd danzhao-study-vue3
export PATH="/Users/iras17514/.workbuddy/binaries/node/versions/22.22.2-6/bin:$PATH"   # 必须 node v22
npm run build:practice          # 脚本依赖题库产物
node scripts/check-duplicates.mjs            # 全量，打印明细
node scripts/check-duplicates.mjs --quiet    # 只打印汇总
node scripts/check-duplicates.mjs --l3-only  # 只看疑似
```

**退出码**：L1 或 L2 有命中 → `1`（可直接当 CI 卡口）；否则 `0`。

### 三档口径设计

| 档 | 判定键 | 用途 |
|----|--------|------|
| **L1** | 题干 + 选项（有序） | 同文件内命中 = 严重重复；跨文件命中 = 重复 |
| **L2** | 题干 + 正确项文本（选项可不同） | 专抓「照抄正课页只换干扰项」，跨文件命中 = 重复 |
| **L3** | 题干主干 + 正确项（模糊匹配） | 只报**疑似**，不卡 CI，必须人工确认（题干被微改） |

**设计取舍**：
- 归一化只去掉空白，**保留 LaTeX**。去掉 LaTeX 会让"解不等式"这类题全撞车（早期踩过）。
- L3 刻意**不进退出码**，因为模糊匹配在语文"通用题干"场景下会有误报，交给人工判断更稳。
- L2 会跳过已被 L1 命中的组合，L3 会跳过已被 L1/L2 命中的组合，避免重复报。

### 建议接入方式

直接加一条 npm script 即可，不必改现有校验逻辑：
```json
"check:dup": "node scripts/check-duplicates.mjs"
```
若想让它进 CI 卡口，在流水线里跑一次看退出码；L3 疑似建议只报告不阻断。
