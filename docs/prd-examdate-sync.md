## 1. 产品目标

> **一句话**：让学员只在一个地方维护三条考试里程碑日期，换手机、换设备登录同一账号后仍是同一份，不用重填、不会串到别人账号、也不会把另一台设备填的那条冲掉。

**「跨设备」是本次的核心增量** —— 现状 `study_plan_v1` 与 `recite_state` 都是设备本地，换设备即丢；本期把它提升为账号级数据。三个正交子目标：

| # | 目标 | 可衡量 |
| --- | --- | --- |
| G1 | **真相源归一**：全应用只有一份「考试日期」业务对象，且就是三条里程碑数组 | 不存在第二处可写的考试日期；不做三条→单一 `examDate` 映射 |
| G2 | **跨设备一致**：任一设备的新增 / 修改 / 清空，登录后在其他设备一致可见 | 见用户故事 1、2、4 |
| G3 | **账号隔离 + 不回归**：切账号不串数据；旧存档平滑；背诵调度与既有同步实体零回归 | 见 P0-4 / P0-5 / P0-6 |

> 不承诺任何教育结果；教材口径与考试信息一律**以浙江省教育考试院当年发布为准**。

## 2. 用户故事（≥4 条，覆盖四种关键场景）

| # | 用户故事 | 产品期望 / 验收信号 |
| --- | --- | --- |
| **US-1** | As a 学员，I want 在 A 设备（手机）填好三条考试日期，在 B 设备（平板/新手机）登录同一账号后直接看到，so that 我不用凭记忆重填一遍 | A 写入 → B 登录后三条 `date` 逐条一致；展示与 A 相同；不要求手动「导入」 |
| **US-2** | As a 学员，I want 在某台设备清空一条误填的日期后，其他设备也同步变回「待设置」，so that 不会一台已删、另一台还挂着旧日期误导我 | 清空是一条有效变更，跨设备生效；清空后**不得复活**三条旧推定默认值；空态回到「待设置」 |
| **US-3** | As a 共用设备的学员，I want 切换到另一个账号后看不到别人的考试日期，再切回来又是我自己的，so that 我的备考安排不串给别人、也不被别人改掉 | 切账号后三条回到该账号自己的值（无数据则「待设置」）；登出/未登录不残留上一账号日期 |
| **US-4** | As a 有两台设备的学员，I want 在 A 设备改「技能操作考」、在 B 设备改「理论考」之后，两条改动都还在，so that 同步不会把我另一台上填的那条冲掉 | **产品期望（重点）**：两次修改作用于**不同里程碑**，最终三条中这两条应同时是各自设备填的新值，第三条保持原值；**不允许**出现「后同步的整行把另一台对另一条的修改静默覆盖」的结果。这是整行 LWW 最容易出事的地方，达成方式由架构师在增量设计中定档，本 PRD 不指定技术实现 |
| **US-5** | As a 老学员，I want 升级后我以前手填的日期还在、不会凭空多出一个日期或冒出旧的推定日期，so that 我不必重新核对一遍 | 旧存档（含三条旧推定默认值 / 旧 `examDate` 空字段）平滑加载；自填的非推定日期一条不丢；不出现第 4 个日期 |
| **US-6** | As a 每天做背诵的学员，I want 加了这个功能后连续天数、到期重默、每日给篇都照旧，so that 我熟悉的节奏不被打乱 | 完成一次自评后 streak 正常推进、队列不变；三条日期不因自评被抹掉 |

| 位置 | 是否改 | 结论 |

| `PlanView.vue`（学习计划 → 里程碑倒计时） | **改（最小）** | 保留为**唯一写入口**：三条 `<input type="date">` 全展示、逐条编辑 / 清空、三态倒计时全部不动；只**新增**两处说明文案（官方口径 + P1 同步状态），不改交互骨架 |

### 4.4 禁词红线（硬性，逐条核查）

- ❌ 不得出现：提分 / 保过 / 录取 / 上岸 / 稳过 / 包过 / 必过 / 保证通过 / 高效提分 等**结果与录取承诺**类词。
- ❌ 不得出现任何对考试结果、分数线、录取概率的推断或暗示；不承诺任何教育结果。
- ❌ 不得把三条自填日期表述为「官方已公布 / 官方确定」；不得自动填充推定日期作为默认展示值。
- ✅ 所有考试信息文案统一口径：**以浙江省教育考试院当年发布为准**；教材口径同样以官方当年发布为准。
- ✅ 无数据不占位（呼应 `prd-mobile.md` §6.6 第 9 条）：空态用说明文案，不用示例数字、不用假数据。
- ✅ 视觉沿用 `prd-mobile.md` §6（B1–B6）：陶土橙仅用于关键数字、单屏主色点位受控；触控区 ≥44px；`type="date"` 输入框 16px 不触发缩放。
