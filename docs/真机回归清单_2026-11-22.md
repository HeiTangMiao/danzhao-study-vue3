# 单招学习打卡 · 真机回归清单（2026-11-22）

> 这份清单是给你本人拿手机照着点的，不用懂技术。
> 每一节都写清楚了：**点哪里 → 看到什么算过 → 看到什么算问题 → 出问题要记下什么**。
> 全部测完大约需要 30～40 分钟（其中有一项要干等 5 分钟，可以穿插着做别的）。
>
> 说明：这款软件的考试日期只作你自己记录用，**考试信息以浙江省教育考试院当年发布为准**。

## 测之前准备

**1. 设备**
- 一台 Android 手机（这次重点是 Android 8 这类比较老的系统，越老越有价值）。
- 确认手机上浏览器内核（WebView）是最新的：打开手机「应用商店 / 设置 → 应用管理」，把「Android 系统 WebView」「Chrome」更新到可用版本。更新不了也没关系，照测即可。
- 一台电脑或另一台手机（用来看这份清单、填结果表格）。
- 准备一支笔或备忘录，随手记下面的结果。

**2. 安装包**
- 拿到这一版的 APK 安装包（文件名里一般带版本号），装到手机上。
- 装的时候如果弹出「未知来源 / 允许安装」提示，选允许（这是正常的安全提醒，针对所有非应用商店的软件包）。

**3. 账号和网络**
- 准备好一个能正常登录的账号和密码（跨设备那一项必须要有账号）。
- 手机连上稳定的网络（Wi-Fi 最好）。跨设备那一项两台设备都要能上网。
- **两台设备要登录同一个账号**：可以是两台手机，也可以是「一台手机 + 电脑浏览器打开同一个网址」；如果只有一台手机，就「先登录 A 账号测 → 退出 → 换 B 账号 → 再退出切回 A 账号」来模拟。

**4. 手机设置（两项测试要用）**
- 记一下机型和 Android 版本：「设置 → 关于手机」，把「型号」和「Android 版本」抄下来，比如「某某机型 / Android 8.1.0」。
- 字体调大测试（场景 5 用）：先不用调，等测到那一步再按说明调。

**5. 统一口径：一旦发现问题，请记这 5 样**
> 每个场景最后都会提醒你，这里先说清楚，届时照抄即可：
> ① 手机机型　② Android 版本　③ 发生的准确时间　④ 在哪个页面（能看到网址就把 `#` 后面那段也抄上）　⑤ 截图（能录屏更好）。
> **不用自己想办法修，也不用反复试，记下来发我就行。**

## 真机回归场景（共 8 项，按顺序做即可）

### 场景 1 · 冷启动不白屏（把应用彻底关掉再打开，首页能正常出来）

> 「冷启动」就是把应用完全关掉后第一次打开；「白屏」就是屏幕一片空白、什么都不显示。这一步专门验证老系统（Android 8）上会不会一打开就白屏。

**怎么走**
1. 如果应用正开着，先按 Home 键回到桌面，再从「最近使用的应用」列表里把它划掉（彻底关掉）。
2. 回到桌面，点应用图标，重新打开。
3. 盯着屏幕看首页是不是正常加载出来，等 3～5 秒。
4. 再重复一次第 1～3 步，一共开两次，两次都正常才算过。

**✅ 通过标准**
- 首页正常显示出内容（能看到底部一排导航按钮、首页的卡片，其中有一张写着「考试日期待设置 · 以浙江省教育考试院当年发布为准」或倒计时天数）。
- 没有出现整屏空白、卡在加载中转圈不动、或者直接闪退回桌面。

**❌ 问题长什么样**
- 打开后屏幕全白 / 全黑，什么都没有。
- 一直转圈超过 10 秒，或提示加载失败又没有任何按钮可以点。
- 打开瞬间闪一下就退回桌面。

**出问题记什么信息**
① 机型　② Android 版本　③ 发生时间　④ 页面路径（一般就是「刚打开、还没进任何页面」）　⑤ 白屏截图（最好连着录一段开屏过程的视频）。

### 场景 2 · 切后台 5 分钟再回来（背到一半走开，回来进度还在）

> 「切后台」就是按 Home 键回到桌面，应用没有关掉、只是退到后面去了。这一步验证：背到一半走开再回来，不会白屏、不会把你做的题弄丢、也不会把已经交过的题又算一遍。

**怎么走**
1. 打开应用，进入「背诵」，随便开始背一篇，翻到正文、但先**不要**点底部的「已能背诵 / 还需练习」。
2. 记住你背的是哪一篇（比如第几单元哪一篇），以及当时大概翻到哪一段。
3. 按手机 Home 键回到桌面（不要划掉应用）。
4. 放下手机，等满 5 分钟（这段时间可以做别的场景，但别把这个应用划掉）。
5. 5 分钟后点图标回到应用，看刚才那一篇和进度。
6. 再看一眼有没有弹出「已经背完了 / 完成」这类本不该出现的提示。

**✅ 通过标准**
- 回到应用后不白屏，页面还在。
- 刚才那一篇还在，能接着往下看，不用从头重新找。
- 没有把已经交过的结果再算一次（不会突然多出「已背次数」、连续天数也不会莫名变化）。

**❌ 问题长什么样**
- 回来变成白屏或直接被踢回首页。
- 应用到「背诵」里，刚才那篇不见了 / 又变成没开始的状态。
- 明明之前交过，回来又让你重新点「已能背诵」，或者连续天数、已背次数平白多了一次。

**出问题记什么信息**
① 机型　② Android 版本　③ 发生时间（切走和回来各记一次）　④ 页面路径（你背的是哪一篇，能看到网址就抄 `#` 后面那段）　⑤ 回来之后的截图。

### 场景 3 · 连续天数同一天只加一次（点很多次「已能背诵」，连续天数不会乱涨）

> 软件首页 / 背诵页上写着「连续 N 天」。这个数字按「天」算：**同一天里背多少篇，最多也只算这一天 1 天**，不能点一篇就 +1。这一步就验证它不会重复加。

**怎么走**
1. 进入「背诵」，找一个还没背过的篇目，背完后点「已能背诵」。
2. 回到背诵页顶部，看「连续 N 天」的数字，把它记下来（假设是 A）。
3. 在同一天里，再找另外 1～2 篇没背过的，照样背完点「已能背诵」。
4. 每点完一篇就回来看一眼「连续 N 天」，都记下来。
5. 顺手再点开已经交过的那一篇看一眼，确认它不会再让你重新点一次自评。

**✅ 通过标准**
- 只要还在**同一天**，不管你点几次「已能背诵」，「连续 N 天」始终是 A，不会变成 A+1、A+2。
- 已经交过的篇目不会再次让你自评。

**❌ 问题长什么样**
- 点一篇「已能背诵」，连续天数就 +1，一天之内涨了好几。
- 已经交过的篇目又能重新点一遍，且连续天数跟着涨。

**出问题记什么信息**
① 机型　② Android 版本　③ 发生时间（每次点自评的时间）　④ 页面路径（背诵页 / 具体哪一篇）　⑤ 每次的「连续 N 天」数字截图（连着截几张，能看出它涨了最好）。

> 小提示：跨到第二天再背，数字才应该 +1。这一步只测「同一天」的情况，别跨零点测。

### 场景 4 · 自评结果写住了（交完之后把应用杀掉重启，记录和连续天数都在）

> 「杀掉」就是从最近使用的应用列表里把应用划掉，让它彻底退出。这一步验证：你点的自评真的存下来了，不是只在屏幕上显示一下。

**怎么走**
1. 先在「背诵」里背完一篇并点「已能背诵」，记住这篇的名字和当时「连续 N 天」的数字。
2. 按 Home 键回桌面，从「最近使用的应用」列表里把应用划掉（彻底杀掉，不是切后台）。
3. 重新点图标打开应用，进「背诵」页。
4. 找到刚才那篇，看它的状态；再看「连续 N 天」。

**✅ 通过标准**
- 刚才那篇的状态还在（例如显示「已背 1 次」/ 不再出现在今天要新背的篇目里，具体字样以实际界面为准）。
- 「连续 N 天」和你杀掉之前记的数字一样，没有变回 0 或变小。

**❌ 问题长什么样**
- 重启后那篇又变回「未开始」/「还需练习」，像没背过一样。
- 连续天数清零、或明显变小。
- 重启后提示进度读取失败、要求重试。

**出问题记什么信息**
① 机型　② Android 版本　③ 发生时间（杀掉前后各记一次）　④ 页面路径（背诵页 / 那篇的名字）　⑤ 重启后的截图。

### 场景 5 · 窄屏和大字体下的注音（拼音挤在字上，要看得清、别被切掉）

> 背诵课里有逐字注音，就是每个汉字上方的小拼音（例如字上面标着 `pīn yīn` 这样）。这一步验证：屏幕窄一点、或者字调大以后，拼音不要糊成一团、也不要被屏幕边切掉。如果手机开了朗读功能（TalkBack / 读屏），顺便确认能读出来。

**怎么走**
1. 进「背诵」，打开一篇带注音的课文 / 古诗文（语文类篇目一般都有）。
2. 正着拿手机（竖屏）看正文，重点看字上方的小拼音。
3. 去手机「设置 → 显示 → 字体大小 / 显示大小」，把字体调到最大，回到这篇再看一遍。
4. 找一句字比较多的长句，凑近看：拼音是不是贴着对应的字、有没有互相压在一起、有没有被屏幕两侧切掉半个。
5. （如果手机开了 TalkBack / 读屏）用手指在正文上滑过朗读，听它会不会把正文和拼音读出来。没开这个功能就跳过这一步。

**✅ 通过标准**
- 每个拼音都在它对应的字正上方，不串到别的字上。
- 拼音之间不重叠、不糊；屏幕两侧没有被切掉的半个拼音。
- 字调到最大后，一行放不下时会正常换行，而不是挤出屏幕。
- 开了读屏的话，能读到正文；拼音能被读到或作为正文的一部分读出来即可。

**❌ 问题长什么样**
- 拼音跑到别的字头上、几个拼音叠在一起看不清。
- 拼音被屏幕边缘切掉，或字太大后整行挤出屏幕、需要左右拖才能看全。
- 读屏时正文一片空白读不出来，或直接读出一堆奇怪的符号。

**出问题记什么信息**
① 机型　② Android 版本　③ 发生时间　④ 页面路径（哪一篇、哪一句）　⑤ 出问题那一屏的截图；字体调到最大的截图也一起发。

### 场景 6 · 学习计划与首页倒计时（填日期出天数、清空回「待设置」、首页卡片能点进去）

> 「学习计划」里有三条可以填日期的框（就是三个里程碑）。填了日期就会显示还有几天；清掉又变回「待设置」。首页那张橙色的倒计时卡片点一下，应该跳到学习计划页。
> 提醒：这里填的日期只是你自己记录，**以浙江省教育考试院当年发布为准**。

**怎么走**
1. 从底部导航找到并进入「学习计划」页（首页那张倒计时卡片也能进，本步先按导航进）。
2. 找到「里程碑倒计时」这一块，下面有 3 个日期框。先确认一条都没填过时，每条旁边写的是「待设置 · 以当年官方通知为准」。
3. 点第一个日期框，随便选一个**未来的日期**（比如 90 天后），选好后看它旁边变成什么。
4. 把刚填的日期再清空（点进日期框找「清除 / 清空」，或把已选日期删掉），看它是不是又变回「待设置 · 以当年官方通知为准」。
5. 回到首页，找到那张写着倒计时 / 「考试日期待设置」的橙色卡片，用手指点一下它。

**✅ 通过标准**
- 没填日期时，每条都显示「待设置 · 以当年官方通知为准」。
- 填了未来日期后，那条旁边显示「还有 N 天」（N 是你选的那天离今天的天数）。
- 清空后，那条又变回「待设置 · 以当年官方通知为准」。
- 页面下方常驻一句说明：「考试日期以浙江省教育考试院当年发布的通知为准……」。
- 点首页的倒计时卡片，会跳到「学习计划」页。

**❌ 问题长什么样**
- 填了日期旁边还是「待设置」，或者显示的天数明显不对（比如 date 明明在 90 天后却显示 1 天）。
- 清空日期后还留着旧天数，不回「待设置」。
- 点首页卡片没反应、跳错地方，或者点了直接报错。
- 界面上出现任何关于考试结果预测的承诺性字样（这不是本软件该有的内容）。

**出问题记什么信息**
① 机型　② Android 版本　③ 发生时间　④ 页面路径（「学习计划」页 / 首页）　⑤ 填日期、清空、点卡片这三个动作各自的截图。

### 场景 7 · 跨设备同步（同一账号换台设备，三条日期要跟着走）—— 重点

> 你在这台设备上填的三条考试日期，登录同一个账号后，在另一台设备上也要能看到；一边改了，另一边也要跟上。
> **手机上没有单独的「同步」按钮**（那个按钮只在电脑版的顶栏才有）。手机上是靠这几种方式触发同步的：**登录账号时自动同步一次、重新打开应用时自动同步一次、之后每 5 分钟自动同步一次**。所以每次改完，重新打开一下应用（或退出再登录一次）再看，就当于「刷新」。

**怎么走**
1. 在设备 A（你的手机）登录账号，进「学习计划」，把三条日期框都填上不同的未来日期，记下具体是哪三天。
2. 等一小会儿（或把应用关掉再打开一次），让 A 把数据传上去。
3. 在设备 B 上登录**同一个账号**（另一台手机，或电脑浏览器打开同一个网址）。
4. 进设备 B 的「学习计划」，看那三条日期。
5. 回到设备 A，把其中一条日期改成一个不同的日子；关掉再打开 A（或在 B 上关掉再打开），等它同步。
6. 在 B 上关掉再打开应用，看那条日期是不是变成了 A 刚改的新日子。
7. 再把 A 上那一条日期**清空**；同样关掉重开让 A 同步。
8. 在 B 上关掉重开，看那条是不是也变回「待设置 · 以当年官方通知为准」。
9. （只有一台手机时）退出账号 → 换成另一个账号登录 → 再退出 → 切回原账号，进「学习计划」看三条日期是否还在。

**✅ 通过标准**
- B 第一次登录就能看到和 A 一样的三条日期。
- A 改了一条，B 重开后显示的是**新**日期，不是旧的。
- A 清空一条，B 重开后那条也变成「待设置 · 以当年官方通知为准」。
- 换账号再切回来，三条日期没有丢、也没有变成另一个账号的内容。

**❌ 问题长什么样**
- B 上三条还是「待设置」，看不到 A 填的。
- B 显示的是很早以前的旧日期，怎么重开都不更新。
- A 清空了，B 上那条还留着旧日期（删不掉）。
- 换了账号再切回来，日期串到别的账号上或全没了。
- 页面出现「同步失败 / 离线」的提示一直不消失。

**出问题记什么信息**
① 机型（两台都记）　② Android 版本（两台都记）　③ 发生时间（A 改动、B 查看各记一次，精确到分钟）　④ 页面路径（「学习计划」页）　⑤ A 和 B 两屏的截图（并排放最好，能直接看出两边不一样）。
> 报问题时请说明：是「B 看不到」「B 是旧的」还是「删不掉」，这几种问题的原因不一样。

### 场景 8 · 代码显示（行内代码有样式、大段代码不显示反引号）

> 计算机类课文里有代码内容。用一个反引号（\`）夹起来的短词（行内代码）要显示成代码的样式；用三个反引号（\`\`\`）围起来的一大段代码，只显示里面的代码，不显示那几个反引号本身。这一步验证这两点在手机上是对的。

**怎么走**
1. 进「课程内容」，找一篇计算机 / 程序设计类的课文（比如讲 Python 基础语法、循环、选择结构的那些），打开它。
2. 找一段正文里夹着反引号包起来的短词（比如写成 \`print\` 这种），看它显示得跟普通文字有没有区别。
3. 再往下找一个用三个反引号围起来的大段代码块（就像平常写代码那样，上下各一行三个反引号），看它渲染出来的样子。
4. 贴着代码块左右边缘看，确认没有多出反引号字符，代码也没有被挤到屏幕外面。

**✅ 通过标准**
- 行内那小段代码有明显的代码样式（通常是灰色底、等宽字体），跟周围正文一眼能区分开，并且**不显示**包着它的反引号。
- 大段代码块显示成一块代码区域，缩进还在（比如 Python 的空格缩进没乱），**上下那三反引号本身不显示出来**。
- 代码块没有被屏幕边缘截断，可以正常阅读。

**❌ 问题长什么样**
- 屏幕上直接看到 \` 或 \`\`\` 这种反引号字符被当成普通文字显示出来。
- 行内代码和普通字完全一样，看不出是代码。
- 大段代码挤成一坨、缩进全丢，或被切到屏幕外要看不全。
- 一进这篇课文就白屏 / 报错。
